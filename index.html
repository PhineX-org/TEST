المسارات

كل مسار بيبدأ من الصفر ومقسّم لوحدات، وفي آخر كل وحدة اختبار ومشروع. ابدأ بالأساسيات وكمّل بالترتيب.

HTML

هيكل أي صفحة ويب

العناوين والروابط والصور والجداول والفورمز والـ Semantic، وتبني صفحتك الشخصية وصفحة وصفة ومطعم.

CSS

الشكل والتخطيط والحركة

الألوان والخطوط وFlexbox وGrid والتصميم المتجاوب والـ animations، وتبني Landing Page وصفحات تسجيل دخول.

JavaScript

برمجة الويب

من المتغيرات لحد الـ DOM والـ async. وتبني كروت نكت وTo-do وكويز وتسجيل دخول بـ localStorage.

Tailwind CSS

واجهات حديثة بسرعة

الـ utility classes والـ responsive والـ dark mode بالنسخة الرابعة، ومشاريع أسعار وLanding ولوحة تحكم.

Python

لغة سهلة وقوية

الأساسيات والدوال والـ OOP والملفات، وتطبيقات سطر أوامر بتشغّلها في المتصفح.

PHP

برمجة السيرفر

أساسيات PHP والفورمز والجلسات وقواعد البيانات، وتبني نظام تسجيل دخول.

React

واجهات تفاعلية

الـ components والـ props والـ state والـ hooks، وتبني تطبيقات صغيرة بتتحدّث لحظياً.

إزاي بتتعلّم هنا؟

مفيش فيديوهات طويلة ومفيش حفظ. بتتعلّم بالطريقة اللي بيتعلّم بيها المبرمجين فعلاً: تقرا، تجرّب، تغلط، وتصلّح.

  1. 📖
    اقرا الدرسشرح بالمصري بيحكي ليه الحاجة دي موجودة، مع تشبيهات وأمثلة تشتغل قدامك.
  2. ⚡
    جرّب بإيدكعدّل على الكود في محرر حقيقي وشوف النتيجة لحظياً من غير ما تثبّت أي حاجة.
  3. 🧩
    ابني المشروعخطوات صغيرة من ملف فاضي. كل خطوة ليها اختبارات تقولك صح ولا لأ وتديك تلميح.
  4. 🏆
    اختبر نفسكاختبار في آخر كل درس ووحدة، وتقدّمك بيتحفظ في متصفحك تلقائياً.
