HTML و CSS من الصفر

تعلّم HTML و CSS خطوة بخطوة بالعربي، وابنِ صفحات حقيقية من الصفر لحد الاحتراف.

الدروس

  1. البداية من الصفر الكاملكيف يعمل الويب؟ ما هو HTML؟ إعداد VS Code خطوة بخطوة
  2. أساسيات HTML — كل شيء من الصفرh1–h6، p، strong، em، ul، ol، a، img، Semantic HTML
  3. موسوعة جميع عناصر HTMLكل عنصر بشرح + مثال + بحث فوري — المرجع الدائم
  4. سمات HTML (Attributes) — شرح كل سمةid, class, style, href, src, alt, data-*, السمات العامة
  5. HTML مع CSS — من رمادي لجميلBox Model، Selectors، الألوان، الخطوط، CSS Variables
  6. النماذج والتحقق من البياناتform، input، select، textarea، التحقق بـ JS وRegEx
  7. SEO لـ HTML — تصدّر نتائج البحثmeta tags، Open Graph، Twitter Cards، defer/async
  8. HTML مع JavaScript — أضف الحياةDOM، تعديل العناصر، الأحداث، إنشاء المحتوى ديناميكياً

تطبيق ومرجع

  1. 🎮مشاريع HTML التطبيقيةطبّق كل ما تعلمته في مشاريع حقيقية خطوة بخطوة
  2. 📚مرجع HTML الكامل258 صفحة بالمصري مع أمثلة تفاعلية لكل عنصر وخاصية
  3. 🎨مرجع CSS الكامل366 صفحة: الخصائص والدوال والـ selectors بأمثلة تجرّبها
