## intro

اسم `<address>` بيخدع ناس كتير: بيفتكروا إنه عشان أي «عنوان» (عنوان شارع أو منزل). لكن الحقيقة إنه **للتواصل مع صاحب المحتوى** مش لأي عنوان. يعني معناه «لو عايز تكلم اللي كتب الصفحة دي أو المقال ده، دي بياناته».

القاعدة الذهبية: اسأل نفسك «هل ده عنوان **للتواصل مع كاتب أو مالك** الصفحة؟». لو أيوه (إيميل الكاتب، تليفون الشركة، عنوان المكتب، حسابه على السوشيال) فـ `<address>`. لو لأ، مثلاً إنت بتكتب مقال عن مطعم وبتقول «المطعم في شارع التحرير رقم 5» فده **مش** `<address>` لأنه مش عنوان تواصل معاك، ده معلومة جوه الكلام، فاستخدم `<p>` عادي.

نطاقه بيتحدد بمكانه: لو الـ `<address>` جوه `<article>` فهو بيانات صاحب **المقال ده**. ولو برّه أي `<article>` (مثلاً في `<footer>` الصفحة) فهو بيانات صاحب **الصفحة كلها**. وعشان كده أشهر مكان ليه: `<footer>` الصفحة أو المقال.

وهو **ما بيعملش** أسطر جديدة لوحده: لو عايز كل جزء في سطر لازم تستخدم `<br>` أو تقسّمه لعناصر. وفيه قيد: مينفعش يحتوي عناوين (`<h1>`…) ولا عناصر أقسام (`<section>` وغيره) ولا `<header>` أو `<footer>` ولا `<address>` تاني. والمتصفحات بترسمه **مائل (italic)** افتراضياً، وده بس شكل افتراضي تقدر تغيّره بالـ CSS.

> [!analogy] تخيّل كارت شخصي (Business Card) في آخر ورقة مقال في مجلة: «الكاتب: أحمد، تليفون كذا، إيميل كذا». ده `<address>`. أما لو الكاتب بيحكي عن مطعم وبيدّي عنوانه جوه كلامه فده مش كارت تواصل، ده جزء من المقال.

> [!key] `<address>` = بيانات **التواصل مع الكاتب أو المالك**، مش أي عنوان بريدي. نطاقه أقرب `<article>` أو الصفحة كلها.

## try

دي بيانات تواصل جوه `<footer>`. لاحظ إن الخط مائل لوحده. جرّب تضيف رابط لواتساب.

```html
<footer>
  <address>
    تواصل مع الكاتب:<br>
    <a href="mailto:ahmed@example.com">ahmed@example.com</a><br>
    <a href="tel:+201000000000">01000000000</a>
  </address>
</footer>
```

## syntax

```html nolive
<address>
  اسم الشخص أو الشركة<br>
  <a href="mailto:name@example.com">name@example.com</a>
</address>
```

- `<address>` — **الوسم الافتتاحي**.
- المحتوى — اسم، إيميل (`mailto:`)، تليفون (`tel:`)، عنوان، روابط سوشيال.
- `<br>` — لكسر الأسطر لو عايز.
- `</address>` — **الوسم الختامي** إجباري.

## use

- لبيانات الاتصال بكاتب المقال (داخل `<article>` أو `<footer>` بتاعه).
- لبيانات التواصل بصاحب الموقع في `<footer>` الصفحة.
- لعنوان الشركة أو المكتب لو ده عنوان التواصل بيها.
- لروابط التواصل: إيميل، تليفون، واتساب، سوشيال.

## avoid

- متستخدمهوش لأي عنوان بريدي مش للتواصل (عنوان مطعم أو مكان في حكاية).
- متحطش جواه عناوين `<h1>`…`<h6>` أو أقسام.
- متحطش `<header>` أو `<footer>` أو `<address>` تاني جواه.
- متستخدمهوش لتاريخ نشر أو معلومات غير الاتصال.
- متحطش جواه نص طويل: هو بيانات تواصل مش مقال.

## attributes

مالوش خصائص خاصة، بيقبل **الخصائص العامة** ([[global-attributes]]) فقط.

### class
للتنسيق (مثلاً شيل الخط المائل).

### id
اسم فريد لو عايز تستهدفه.

## examples

### 1) أبسط address
اسم وإيميل.

```html
<address>
  أحمد الجوهري<br>
  <a href="mailto:ahmed@example.com">ahmed@example.com</a>
</address>
```

- الخط مائل افتراضياً لأن المتصفح بيدّيه `font-style: italic`.
- الـ `<br>` بينزّل الإيميل لسطر جديد.
- الرابط `mailto:` بيفتح تطبيق الإيميل لما تضغط عليه.

### 2) تليفون وواتساب
روابط `tel:` بتفتح الاتصال على الموبايل.

```html
<address>
  <a href="tel:+201000000000">اتصل: 01000000000</a><br>
  <a href="https://wa.me/201000000000">واتساب</a>
</address>
```

- `tel:` على الموبايل بيفتح تطبيق الاتصال مباشرةً.
- رابط `wa.me` بيفتح محادثة واتساب مع الرقم.
- الأرقام بصيغة دولية (`+20` لمصر) عشان تشتغل من أي مكان.

### 3) address في تذييل مقال
بيانات صاحب المقال ده بس.

```html
<article>
  <h2>مقال عن HTML</h2>
  <p>نص المقال…</p>
  <footer>
    <address>
      بقلم: <a href="mailto:sara@example.com">سارة</a>
    </address>
  </footer>
</article>
```

- لأنه جوه `<article>` فبيمثّل بيانات كاتب المقال ده، مش صاحب الموقع.
- الـ `<footer>` هو المكان الشائع ليه.
- كاتب تاني في مقال تاني هيبقى له `<address>` خاص.

### 4) address في تذييل الصفحة
بيانات صاحب الموقع كله.

```html
<footer>
  <address>
    شركة PhineX Group<br>
    القاهرة، مصر<br>
    <a href="mailto:hello@example.com">hello@example.com</a>
  </address>
  <p>© 2026</p>
</footer>
```

- برّه أي `<article>` فبيمثّل صاحب الصفحة كلها.
- ده الاستخدام الأشهر: تذييل الموقع بعنوان الشركة.
- حقوق النشر في `<p>` لأنها مش بيانات اتصال.

### 5) تغيير الخط المائل
الشكل الافتراضي مائل، تقدر تغيّره.

```html
<style>
  address { font-style: normal; border-right: 4px solid #39ff14; padding-right: 10px; line-height: 1.8; }
</style>
<address>
  PhineX Academy<br>
  <a href="mailto:hi@example.com">hi@example.com</a>
</address>
```

- `font-style: normal` بيشيل الميل.
- الحد الأخضر على اليمين زينة بس.
- ده تنسيق مش تغيير معنى: العنصر لسه `<address>`.

### 6) address مع أيقونات
أيقونات إيموجي زخرفية مخفية عن قارئ الشاشة.

```html
<address>
  <p><span aria-hidden="true">📧</span> <a href="mailto:a@b.com">a@b.com</a></p>
  <p><span aria-hidden="true">📞</span> <a href="tel:+201000000000">01000000000</a></p>
</address>
```

- `aria-hidden="true"` بيخلّي قارئ الشاشة يتجاهل الأيقونة ويقرا النص بس.
- الأيقونة بتسهّل المسح البصري للي بيشوف.
- لازم يبقى النص موجود: الأيقونة وحدها مش كفاية.

### 7) عنوان في مقال: مش address
مثال لحالة «ده مش address».

```html
<p>
  المطعم موجود في شارع التحرير رقم 5 بالقاهرة، وهو مفتوح للساعة 12.
</p>
<address>
  لو عايز تتواصل معايا: <a href="mailto:me@example.com">me@example.com</a>
</address>
```

- عنوان المطعم معلومة في الكلام فاتحط في `<p>`.
- الإيميل هو اللي للتواصل معايا فاتحط في `<address>`.
- ده الفرق: عنوان **بتتكلم عنه** مقابل عنوان **تتواصل بيه**.

## rules

- parents: أي عنصر بيقبل **Flow content**، لكن مش جوه `<address>` تاني.
- children: **Flow content**، لكن **مينفعش** عناوين (`<h1>`…) ولا عناصر أقسام (`<article>` `<section>` `<nav>` `<aside>`) ولا `<header>` أو `<footer>` أو `<address>`.
- closing: الوسم الختامي `</address>` إجباري.
- role: `group`.
- dom: `HTMLElement`.
- layout: `display: block`، وبيتعرض مائل افتراضياً.

## mistakes

### address لعنوان بتتكلم عنه
```html bad
<address>
  مطعم الشرق: شارع الهرم 12
</address>
```
```html good
<p>مطعم الشرق في شارع الهرم 12.</p>
```
ليه؟ ده مش عنوان تواصل بالكاتب، ده معلومة جوه نص.

### عناوين جوه address
```html bad
<address>
  <h2>تواصل معانا</h2>
  <p>01000000000</p>
</address>
```
```html good
<h2>تواصل معانا</h2>
<address>
  <p>01000000000</p>
</address>
```
ليه؟ العناوين ممنوعة جوه `<address>`، حطّها قبله.

### address جوه address
```html bad
<address>
  <address>قسم المبيعات</address>
</address>
```
```html good
<address>
  قسم المبيعات: <a href="tel:+20100">0100</a>
</address>
```
ليه؟ `<address>` ممنوع يتداخل.

## a11y

- الروابط جوه `<address>` لازم يبقى لها نص واضح: «ahmed@example.com» أحسن من «اضغط هنا».
- حط أرقام التليفون كروابط `tel:` عشان المستخدم على الموبايل يضغط ويتصل.
- لو استخدمت أيقونات، اخفيها بـ `aria-hidden="true"` واكتب النص.

## tips

- شيل الميل بـ `font-style: normal` لو مش عايزه.
- استخدم `mailto:` و `tel:` للروابط عشان تتفتح بالتطبيق المناسب.
- اكتب الأرقام بالصيغة الدولية.
- لو بتعرض عنوان بالتفصيل فكّر في Microdata أو JSON-LD لمحركات البحث.
