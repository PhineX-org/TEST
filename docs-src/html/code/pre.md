## intro

اتعلمنا إن HTML بيتجاهل المسافات الزيادة وأسطر الكود: لو كتبت «أنا      بحب     HTML» بمسافات كتير، المتصفح هيعرضها بمسافة واحدة بين كل كلمة، والأسطر الجديدة كمان بتتحول لمسافة. ده كويس للكلام العادي، لكنه كارثة في **الكود** أو **الفن النصي** أو **الجداول النصية** اللي المسافة فيها جزء من المعنى.

العنصر `<pre>` (اختصار **Preformatted**: منسّق مسبقاً) بيقول للمتصفح: «النص اللي جوايا متنسّق بالفعل، سيبه زي ما هو». يعني **كل مسافة وكل سطر جديد** هيتعرضوا بالظبط، وبيستخدم خط ثابت العرض (Monospace) علشان الحروف تتراص تحت بعض بدقة.

أشهر استخدامين: **الكود متعدد الأسطر**، ووقتها بنحط جواه `<code>`: `<pre><code>…</code></pre>`. والتاني **الفن النصي** (ASCII Art) أو أي تنسيق بالمسافات زي جداول نصية وخرج أوامر.

وفيه تفاصيل مهمة: **أول سطر جديد** بعد `<pre>` مباشرةً بيتجاهله المتصفح (عشان تقدر تبدأ المحتوى في سطر جديد من غير فراغ). وكمان لو فيه `<` أو `&` في النص لازم تكتبهم `&lt;` و`&amp;`. ولو السطر طويل جداً بيطلع Scroll أفقي، وتقدر تخليه يلف بـ CSS: `white-space: pre-wrap`.

> [!analogy] تخيّل بتطبع جدول على آلة كاتبة قديمة: كل حرف في مكانه بالظبط والمسافات محسوبة. لو الورقة اتصوّرت بأي طريقة، الجدول لازم يفضل زي ما هو. ده الـ `<pre>`: يحافظ على الشكل كما كُتب.

> [!key] `<pre>` = **احتفظ بالمسافات والأسطر**. للكود: `<pre><code>`. الـ `<` تتكتب `&lt;`.

## try

قارن بين الفقرة العادية والـ `<pre>`. الأسطر والمسافات متحفظة في التانية بس.

```html
<p>
  سطر أول
      سطر تاني بمسافات
</p>
<pre>
  سطر أول
      سطر تاني بمسافات
</pre>
```

## syntax

```html nolive
<pre>
سطر أول
    سطر بمسافة
</pre>
```

- `<pre>` — **الوسم الافتتاحي**.
- المحتوى — نص بمسافات وأسطر محفوظة.
- `</pre>` — **الوسم الختامي** إجباري.

## use

- لكود متعدد الأسطر (مع `<code>`).
- للفن النصي (ASCII Art).
- لعرض خرج أوامر أو سجلات (Logs) مع `<samp>`.
- لجداول نصية أو شعر بمسافات مضبوطة.

## avoid

- متستخدمهوش لتنسيق عادي: استخدم `<p>` و CSS.
- متستخدمهوش للتخطيط (Layout).
- متنساش تحوّل `<` لـ `&lt;`.
- متستخدمهوش لنص طويل جداً من غير Scroll.

## attributes

مالوش خصائص حديثة خاصة، بيقبل **الخصائص العامة** ([[global-attributes]]).

### width {deprecated}
كانت بتحدد العرض بالأحرف. **قديمة**: استخدم `width` أو `max-width` في CSS.

### wrap {deprecated}
كانت بتخلّي السطر يلف. **قديمة**: استخدم `white-space: pre-wrap`.

### class
للتنسيق.

## examples

### 1) أبسط pre
مسافات وأسطر محفوظة.

```html
<pre>
أنا
    في
        سلّم
</pre>
```

- المسافات في بداية الأسطر ظهرت كما هي.
- لو استخدمت `<p>` كل ده هيتدمج في سطر واحد.

### 2) كود متعدد الأسطر
`<pre><code>`.

```html
<pre><code>for (let i = 1; i &lt;= 3; i++) {
  console.log("عدد: " + i);
}</code></pre>
```

- الكود بيتعرض بمسافات الإزاحة (Indentation) زي ما كتبتها.
- لاحظ إننا كتبنا `&lt;=` بدل `<=`: الأضمن دايماً تحوّل علامة `<` لـ entity حتى لو مش بتكوّن وسم.
- الـ `<code>` بيدّي معنى الكود.

### 3) الفن النصي
ASCII Art.

```html
<pre>
  /\_/\
 ( o.o )
  > ^ <
</pre>
```

- كل حرف في مكانه بالظبط بفضل الخط ثابت العرض.
- من غير `<pre>` كان هيبوّظ شكل القطة.

### 4) لف السطر الطويل
`pre-wrap` للسطور الطويلة.

```html
<style>
  pre { white-space: pre-wrap; background: #0f172a; color: #e2e8f0; padding: 10px; border-radius: 8px; }
</style>
<pre>هذا سطر طويل جداً جداً جداً جداً جداً جداً جداً جداً جداً جداً جداً بيلف بدل ما يعمل scroll أفقي لأننا استخدمنا pre-wrap.</pre>
```

- `pre-wrap` بيحافظ على المسافات والأسطر لكن بيسمح باللف.
- بدل الـ Scroll الأفقي المزعج على الموبايل.

### 5) خرج أمر مع samp
عرض ناتج برنامج.

```html
<pre><samp>$ node --version
v22.0.0</samp></pre>
```

- `<samp>` بيعلّم إن ده خرج برنامج.
- `<pre>` بيحافظ على الأسطر.

### 6) ملاحظة السطر الأول
السطر الأول بعد `<pre>` بيتشال.

```html
<pre>
هنا أول سطر فعلي (السطر الفاضي اللي قبله اتتجاهل)
</pre>
```

- المتصفح بيتجاهل أول سطر جديد بعد `<pre>` مباشرةً.
- فتقدر تبدأ المحتوى في سطر جديد من غير فراغ ظاهر.

## rules

- parents: أي عنصر بيقبل **Flow content**.
- children: **Phrasing content**.
- closing: الوسم الختامي `</pre>` إجباري.
- role: `generic`.
- dom: `HTMLPreElement`.
- layout: `display: block`، و`white-space: pre`، وخط ثابت العرض.

## mistakes

### نسيان entities
```html bad
<pre><div>صندوق</div></pre>
```
```html good
<pre>&lt;div&gt;صندوق&lt;/div&gt;</pre>
```
ليه؟ الوسم هيتنفّذ بدل ما يتعرض.

### pre للتخطيط
```html bad
<pre>
عمود 1        عمود 2
</pre>
```
```html good
<div style="display:flex; gap:20px"><div>عمود 1</div><div>عمود 2</div></div>
```
ليه؟ التخطيط شغل CSS.

### كود من غير code
```html bad
<pre>const x = 5;</pre>
```
```html good
<pre><code>const x = 5;</code></pre>
```
ليه؟ `<code>` بيدّي المعنى.

## a11y

- قارئ الشاشة بيقرا محتوى `<pre>` بشكل متفاوت.
- الفن النصي (ASCII Art) مش مفيد لقارئ الشاشة: ضيف وصف `aria-label` أو نص بديل.
- خلّي `tabindex="0"` لو الـ `<pre>` فيه Scroll عشان مستخدم الكيبورد يوصله.

## tips

- جرّب `tab-size` للتحكم في عرض الـ Tab.
- للتلوين استخدم Prism أو highlight.js.
- لو الـ `<pre>` عريض، `overflow-x: auto`.
