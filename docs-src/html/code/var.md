## intro

في معادلة زي «المساحة = الطول × العرض»، الكلمات «الطول» و«العرض» **قيم بتتغير** من حالة لحالة. وفي الرياضة: x و y و n رموز بتمثّل أرقام مجهولة. وفي البرمجة: `userName` و`count` أسماء متغيرات بتشيل قيم. العنصر `<var>` (اختصار **Variable**) بيعلّم على الأسماء دي: «ده متغير مش قيمة ثابتة».

المتصفح بيعرضه **مائل** (Italic) افتراضياً، زي ما بنكتب المتغيرات الرياضية في الكتب (*x* و *y*). وده بيساعد القارئ يفرّق بين المتغير والنص العادي. وبنستخدمه في **الشروحات الرياضية** و**التوثيق التقني** و**الصيغ**: «استخدم `<var>name</var>` عشان تحط اسم الملف».

وتقدر تستخدمه كمان كـ **Placeholder** في توثيق الأوامر: «`git commit -m "<var>رسالة</var>"`» معناها «حط هنا رسالتك». وبيتحط جوه `<code>` أو `<samp>` أو `<kbd>` لو مناسب. وبيتكامل مع `<sub>` للفهرسة (x₁ و x₂).

وفرّق بينه وبين `<code>`: الـ `<code>` للكود كله، والـ `<var>` بس لاسم المتغير جواه (لو بتفرّق). وفي أغلب الحالات المبسطة هتستخدم `<code>`، و`<var>` لما بتشرح **معادلات** أو **صيغ عامة** بمتغيرات.

> [!analogy] تخيّل استمارة فيها مكان فاضي مكتوب تحته «اسم الطالب». المكان ده بيتملي بقيمة مختلفة كل مرة. «اسم الطالب» هو `<var>`: مكان محجوز لقيمة بتتغير.

> [!key] `<var>` = **اسم متغير** (رياضة أو برمجة أو Placeholder). بيظهر مائل.

## try

جرّب تغيّر المتغيرات في المعادلة.

```html
<p>مساحة المستطيل = <var>الطول</var> × <var>العرض</var></p>
<p>المعادلة: <var>y</var> = <var>m</var><var>x</var> + <var>b</var></p>
```

## syntax

```html nolive
<p>الصيغة: <var>x</var> + <var>y</var> = <var>z</var></p>
```

- `<var>` — **الوسم الافتتاحي**.
- النص — اسم المتغير.
- `</var>` — **الوسم الختامي** إجباري.

## use

- لمتغيرات المعادلات الرياضية والعلمية.
- لمتغيرات البرمجة في الشرح.
- كـ Placeholder في توثيق الأوامر.
- لرموز عامة في الصيغ.

## avoid

- متستخدمهوش لقيم ثابتة.
- متستخدمهوش للتأكيد: `<em>`.
- متستخدمهوش للكود كله: `<code>`.
- متستخدمهوش للمعادلات المعقدة: `<math>`.

## attributes

مالوش خصائص خاصة، بيقبل **الخصائص العامة** ([[global-attributes]]).

### class
للتنسيق.

### title
ممكن تشرح بيها معنى المتغير.

```html nolive
<var title="طول المستطيل">L</var>
```

## examples

### 1) معادلة رياضية
متغيرات بسيطة.

```html
<p>سرعة = <var>مسافة</var> ÷ <var>زمن</var></p>
```

- كل كلمة متغيرة مميّزة بخط مائل.
- القارئ يعرف إنها قيم بتتغير.

### 2) متغيرات برمجية
جوه كود.

```html
<p>الدالة بتاخد <code><var>a</var>, <var>b</var></code> وبترجّع مجموعهم.</p>
```

- `<var>` جوه `<code>` لتمييز أسماء المتغيرات.
- شائع في توثيق الدوال.

### 3) Placeholder في أمر
مكان لقيمة المستخدم.

```html
<p>اكتب: <kbd>git commit -m "<var>رسالتك هنا</var>"</kbd></p>
```

- `<var>` بيوضّح إن الجزء ده هتبدّله بقيمتك.
- `<kbd>` لأن ده أمر بيكتبه المستخدم.

### 4) مع الفهرسة
متغيرات مفهرسة.

```html
<p><var>x</var><sub>1</sub> + <var>x</var><sub>2</sub> = <var>S</var></p>
```

- `<sub>` بيعمل الفهرسة، و`<var>` بيعلّم المتغير.
- ده نمط معتاد في الرياضيات.

### 5) تنسيق مخصص
لون للمتغيرات.

```html
<style>
  var { font-style: normal; color: #7c3aed; font-weight: bold; }
</style>
<p>الربح = <var>الإيراد</var> − <var>التكلفة</var></p>
```

- شلنا الميل ولوّنا المتغير.
- المعنى لسه «متغير».

## rules

- parents: أي عنصر بيقبل **Phrasing content**.
- children: **Phrasing content**.
- closing: الوسم الختامي `</var>` إجباري.
- role: `generic`.
- dom: `HTMLElement`.
- layout: `display: inline`، و`font-style: italic`.

## mistakes

### var لقيمة ثابتة
```html bad
<p>الرقم <var>5</var> أصغر من 10.</p>
```
```html good
<p>الرقم 5 أصغر من 10.</p>
```
ليه؟ 5 قيمة ثابتة مش متغير.

### var للتأكيد
```html bad
<p>ده <var>مهم</var>.</p>
```
```html good
<p>ده <strong>مهم</strong>.</p>
```
ليه؟ المتغير مش بيعني «مهم».

## a11y

- قارئ الشاشة بيقراه كنص عادي.
- للمعادلات المعقدة استخدم MathML.

## tips

- في التوثيق، استخدم `<var>` كـ Placeholder متّسق.
- لو الرموز كتير، فكّر في KaTeX أو `<math>`.
