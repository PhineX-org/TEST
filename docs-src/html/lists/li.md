## intro

الـ `<li>` (اختصار **List Item**: عنصر قايمة) هو **الوحدة** اللي بتتكوّن منها أي قايمة. كل نقطة في `<ul>` وكل رقم في `<ol>` هو `<li>`. هو بيعرض علامة (نقطة أو رقم أو حرف) قدامه تلقائياً بحسب نوع القايمة، وده شغل الخاصية `display: list-item` في CSS.

قاعدة أساسية: الـ `<li>` **لازم يبقى ابن مباشر** لـ `<ul>` أو `<ol>` أو `<menu>`. مينفعش تحطه في أي مكان تاني. وفي المقابل، **اللي جوه الـ `<li>` حر تماماً**: نص، فقرات، صور، روابط، قوايم تانية، عناوين، أي حاجة (Flow content). وده اللي بيخليه مرن جداً: كارت منتج كامل ممكن يبقى `<li>`.

وبما إن الـ `<li>` نفسه عنصر Block-ish (list-item)، فلو عايز قايمة متداخلة (قايمة جوه عنصر)، بتحط الـ `<ul>` أو `<ol>` الفرعي **جوه** الـ `<li>`، مش بعده.

وفيه خاصية واحدة مهمة بس: **`value`** (جوه `<ol>` بس) بتغيّر رقم العنصر ده، والباقي بيكمل منه.

> [!analogy] القايمة زي علبة بيض، والـ `<li>` هو كل بيضة جواها. لكن العلبة (الـ `ul` أو `ol`) مش بتقبل غير بيض (li)، أما البيضة نفسها (الـ `li`) فممكن تحط فيها أي حاجة.

> [!key] `<li>` لازم يبقى جوه `ul`/`ol`/`menu`. جواه أي محتوى. القايمة المتداخلة جواه مش جنبه.

## try

جرّب تحط رابط أو صورة جوه `<li>`.

```html
<ul>
  <li>عنصر نصي</li>
  <li><a href="#">عنصر رابط</a></li>
  <li><strong>عنصر</strong> بتنسيق <em>مختلط</em></li>
</ul>
```

## syntax

```html nolive
<ol>
  <li value="5">العنصر الخامس</li>
</ol>
```

- `<li>` — **الوسم الافتتاحي**.
- `value` — رقم العنصر (جوه `<ol>` بس).
- المحتوى — أي Flow content.
- `</li>` — **الوسم الختامي** (ممكن يتحذف في حالات لكن اكتبه دايماً).

## use

- لكل عنصر في `<ul>` أو `<ol>` أو `<menu>`.
- لتغليف عناصر المنيو (رابط في كل `<li>`).
- لكروت متكررة.
- لقوايم متداخلة.

## avoid

- متحطش `<li>` برّه قايمة.
- متحطش `<li>` جوه `<li>` مباشرةً.
- متنساش وسم الإغلاق.
- متستخدمهوش لتنسيق من غير قايمة.

## attributes

### value
رقم العنصر في `<ol>`. العناصر بعده بتكمل منه. مالوش تأثير في `<ul>`.

```html nolive
<ol><li value="10">عاشر</li><li>حادي عشر</li></ol>
```

### type {deprecated}
كانت بتحدد شكل العلامة. **قديمة**: استخدم `list-style-type`.

### class
للتنسيق.

## examples

### 1) li بسيط
عناصر نصية.

```html
<ul>
  <li>الأول</li>
  <li>التاني</li>
</ul>
```

- كل `<li>` بياخد نقطة.
- ده الشكل الأساسي لأي قايمة: الأب `<ul>` والأبناء `<li>`.
- المتصفح بيضيف النقطة والمسافة من الجنب لوحده.
- لو غيّرت الأب لـ `<ol>` النقط هتبقى أرقام من غير ما تغيّر الـ `<li>`.

### 2) li فيه محتوى غني
أي حاجة جواه.

```html
<ul>
  <li>
    <h4>HTML</h4>
    <p>لغة بناء الصفحات.</p>
    <a href="#">اقرأ المزيد</a>
  </li>
</ul>
```

- جوه `<li>` عنوان وفقرة ورابط.
- مسموح لأن `<li>` بيقبل Flow content.

### 3) value
تغيير الترقيم.

```html
<ol>
  <li>أول</li>
  <li value="5">خامس</li>
  <li>سادس</li>
</ol>
```

- بعد `value="5"` الباقي بيكمل 6.
- مفيد لقوائم مقسّمة أو لتكملة ترقيم من قايمة سابقة.
- لاحظ إن «سادس» اتحسب أوتوماتيك بعد «خامس» من غير ما تكتب رقمه.
- الخاصية دي بتشتغل بس جوه `<ol>`، وفي `<ul>` بتتجاهل.

### 4) li كمنيو
رابط في كل `<li>`.

```html
<nav>
  <ul style="display:flex; gap:12px; list-style:none; padding:0">
    <li><a href="#">الرئيسية</a></li>
    <li><a href="#">الكورسات</a></li>
  </ul>
</nav>
```

- كل رابط في `<li>` عشان قارئ الشاشة يعلن «قايمة».
- ده الشكل المتعارف عليه.

### 5) تنسيق علامة li
`::marker`.

```html
<style>
  li::marker { color: #39ff14; font-size: 1.2em; }
</style>
<ul>
  <li>نقطة خضرا</li>
  <li>نقطة خضرا</li>
</ul>
```

- `::marker` بيتحكم في النقطة أو الرقم لوحده.
- من غير تغيير الـ HTML.
- مدعوم في المتصفحات الحديثة ويدعم اللون والحجم.
- ممكن كمان تغيّر المحتوى بـ `content` في حالات معينة.

## rules

- parents: `<ul>` أو `<ol>` أو `<menu>`.
- children: **Flow content**.
- closing: الوسم الختامي `</li>` (يفضّل تكتبه).
- role: `listitem`.
- dom: `HTMLLIElement`.
- layout: `display: list-item`.

## mistakes

### li برّه قايمة
```html bad
<li>عنصر</li>
```
```html good
<ul><li>عنصر</li></ul>
```
ليه؟ الـ `<li>` لازم يبقى جوه قايمة.

### قايمة فرعية جنب li
```html bad
<ul>
  <li>أ</li>
  <ul><li>ب</li></ul>
</ul>
```
```html good
<ul>
  <li>أ
    <ul><li>ب</li></ul>
  </li>
</ul>
```
ليه؟ الفرعية لازم تبقى جوه `<li>`.

## a11y

- `role="listitem"` تلقائي لما يبقى جوه قايمة.
- لو شلت دلالة القايمة بـ CSS، ضيف `role="list"` على الأب.

## tips

- اكتب وسم الإغلاق دايماً.
- `::marker` للتحكم في العلامة.
- متحطش `<li>` بدون سبب.
