## intro

لو بتكتب وصفة طبخ: «1. اخلط البيض. 2. ضيف الدقيق. 3. اخبز»، الترتيب هنا **مش اختياري**: لو بدّلت الخطوات الطبخة هتبوظ. القايمة دي اسمها **قايمة مرتبة**، والعنصر بتاعها `<ol>` (اختصار **Ordered List**). بيعرض كل عنصر برقم قدامه تلقائياً (1, 2, 3…).

زي `<ul>` بالظبط، أبناؤه المباشرين لازم يبقوا `<li>`. الفرق الوحيد إن الـ `<ol>` بيضيف **ترقيم** و**معنى الترتيب**. والمتصفح بيحسب الأرقام لوحده، فلو شلت عنصر من النص الباقيين بيتعدّلوا تلقائياً، من غير ما تكتب الأرقام بإيدك (ومتكتبهاش!).

وفيه خصائص شاطرة: **`start`** عشان تبدأ من رقم غير 1، **`reversed`** عشان تعدّ تنازلي (10، 9، 8…)، **`type`** عشان تغيّر نوع الترقيم (أرقام `1` أو حروف `a`/`A` أو رومانية `i`/`I`). والـ `<li>` نفسه بيقبل `value` لو عايز تقفز لرقم معين.

استخدامه الأشهر: **خطوات** (تعليمات التثبيت)، **ترتيب** (أفضل 10 أفلام)، **ملخص** (مراحل مشروع). ولو الترتيب مش مهم، ارجع لـ [[ul]].

> [!analogy] تخيّل طابور في بنك: كل واحد معاه رقم (1, 2, 3…). لو شلت رقم 2 الطابور بيتحرك والأرقام بتتظبط. الأرقام جزء من المعنى (مين الأول). ده `<ol>`.

> [!key] `<ol>` لما **الترتيب مهم**. الأرقام تلقائية: متكتبهاش بإيدك. `start` و`reversed` و`type` للتحكم.

## try

جرّب تغيّر `start` أو أضف `reversed`.

```html
<h3>إزاي تعمل شاي</h3>
<ol>
  <li>سخّن الماية</li>
  <li>ضيف الشاي</li>
  <li>استنى 3 دقايق</li>
  <li>صفّي وقدّم</li>
</ol>
```

## syntax

```html nolive
<ol start="1" reversed type="1">
  <li>الخطوة الأولى</li>
  <li>الخطوة التانية</li>
</ol>
```

- `<ol>` — **الوسم الافتتاحي**.
- `start` / `reversed` / `type` — اختيارية.
- `<li>` — كل عنصر.
- `</ol>` — **الوسم الختامي** إجباري.

## use

- لخطوات متسلسلة (تعليمات، وصفات، دروس).
- لترتيب (Top 10، ترتيب فرق).
- لمراحل مشروع.
- لمواد قانونية أو بنود مرقّمة.

## avoid

- متكتبش الأرقام بإيدك جوه `<li>`.
- متستخدمهوش لو الترتيب مش مهم: `<ul>`.
- متحطش حاجة غير `<li>` مباشرةً.

## attributes

### start
الرقم اللي تبدأ منه القايمة (عدد صحيح، ممكن سالب).

```html nolive
<ol start="5"><li>خامس</li><li>سادس</li></ol>
```

### reversed {boolean}
بتخلّي العدّ تنازلي. خاصية Boolean (وجودها كفاية).

```html nolive
<ol reversed><li>تالت</li><li>تاني</li><li>أول</li></ol>
```

### type
نوع الترقيم: `1` (أرقام، افتراضي)، `a` (حروف صغيرة)، `A` (حروف كبيرة)، `i` (رومانية صغيرة)، `I` (رومانية كبيرة). الأفضل CSS `list-style-type`، لكن `type` مسموح في HTML5 بمعنى «الترقيم جزء من المعنى».

```html nolive
<ol type="a"><li>أ</li><li>ب</li></ol>
```

### class
للتنسيق.

## examples

### 1) قايمة خطوات
الاستخدام الأساسي.

```html
<ol>
  <li>افتح المحرر</li>
  <li>اكتب الكود</li>
  <li>احفظ الملف</li>
  <li>افتحه في المتصفح</li>
</ol>
```

- الأرقام اتحسبت أوتوماتيك.
- لو شلت خطوة، الباقيين بيتعدّلوا.

### 2) start
نبدأ من رقم مختلف.

```html
<p>الخطوات من 4:</p>
<ol start="4">
  <li>نشر الموقع</li>
  <li>اختبار الموقع</li>
</ol>
```

- بيستفيد لو القايمة أكمل لقايمة قبلها.
- الأرقام هتبقى 4 و5.

### 3) reversed
عدّ تنازلي.

```html
<h3>أفضل 3 لغات</h3>
<ol reversed>
  <li>Python</li>
  <li>JavaScript</li>
  <li>HTML</li>
</ol>
```

- الأرقام 3 و2 و1 من فوق لتحت.
- مفيد لترتيب التنازلي (Top 10 → 1).

### 4) أنواع الترقيم
`type` و`list-style-type`.

```html
<ol type="A"><li>أ</li><li>ب</li></ol>
<ol type="i"><li>واحد</li><li>اتنين</li></ol>
<ol style="list-style-type: arabic-indic"><li>عربي</li><li>عربي</li></ol>
```

- حروف كبيرة ورومانية وأرقام هندية-عربية (`arabic-indic`).
- الأخيرة CSS لأنها مش في `type`.

### 5) value في li
قفز لرقم معين.

```html
<ol>
  <li>أول</li>
  <li value="10">عاشر</li>
  <li>حادي عشر</li>
</ol>
```

- الخاصية `value` على `<li>` بتغيّر رقمه، والباقي بيكمل بعده.

### 6) قايمة متداخلة مرقّمة
أقسام وأقسام فرعية.

```html
<ol>
  <li>المقدمة</li>
  <li>الدروس
    <ol type="a">
      <li>HTML</li>
      <li>CSS</li>
    </ol>
  </li>
  <li>الخاتمة</li>
</ol>
```

- القايمة الفرعية بحروف عشان تتفرّق.
- متداخلة جوه `<li>` مش جنبه.

## rules

- parents: أي عنصر بيقبل **Flow content**.
- children: صفر أو أكتر `<li>` (وعناصر الدعم).
- closing: الوسم الختامي `</ol>` إجباري.
- role: `list`.
- dom: `HTMLOListElement`.
- layout: `display: block`، و`list-style-type: decimal`.

## mistakes

### كتابة الأرقام يدوياً
```html bad
<ol>
  <li>1. أول</li>
  <li>2. تاني</li>
</ol>
```
```html good
<ol>
  <li>أول</li>
  <li>تاني</li>
</ol>
```
ليه؟ الأرقام تلقائية، فهتظهر مكررة (1. 1. أول).

### ol لقايمة مش مرتبة
```html bad
<ol><li>تفاح</li><li>موز</li></ol>
```
```html good
<ul><li>تفاح</li><li>موز</li></ul>
```
ليه؟ الترتيب مش مهم.

### start بقيمة نصية
```html bad
<ol start="خمسة">…</ol>
```
```html good
<ol start="5">…</ol>
```
ليه؟ `start` عدد صحيح.

## a11y

- قارئ الشاشة بيعلن «قايمة مرتبة من N عناصر».
- الأرقام الأوتوماتيكية بتتقرا صح.
- لو بتشيل الترقيم بـ CSS، ضيف `role="list"`.

## tips

- في الخطوات الطويلة قسّم لأجزاء بعناوين.
- استخدم `reversed` لقوائم التنازلي بدل ما تكتب الأرقام.
- `list-style-type` أكتر مرونة من `type`.
