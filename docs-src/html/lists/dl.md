## intro

عندك بيانات على شكل **أزواج: اسم وقيمة**: «الاسم: أحمد»، «السن: 25»، «المدينة: القاهرة». أو مصطلح وتعريفه: «HTML: لغة بناء الصفحات». أو سؤال وجوابه. دي بالظبط **قايمة الوصف** (Description List)، والعنصر `<dl>` هو الحاوية بتاعتها. جواه بتحط **أزواج** من عنصرين: `<dt>` (**Description Term**: المصطلح/الاسم) و`<dd>` (**Description Details**: التعريف/القيمة).

الشكل الكلاسيكي: `<dt>` بيجي وبعده `<dd>` (أو أكتر). المتصفح بيعرض الـ `<dd>` **بإزاحة** (مسافة من الجنب) تحت الـ `<dt>`. وتقدر تعمل **أكتر من `<dd>`** لنفس `<dt>` (مصطلح له أكتر من تعريف)، أو **أكتر من `<dt>`** لنفس `<dd>` (أكتر من اسم لنفس القيمة).

والنقطة الحلوة في HTML الحديثة: تقدر تلف كل مجموعة (`<dt>` و`<dd>`) في `<div>` عشان تنسّقها سوا (زي كارت لكل زوج) وده **مسموح بس** كابن مباشر للـ `<dl>`، وهو ما يمنعش المعنى.

استخداماته: **القواميس والـ Glossary**، **الأسئلة الشائعة (FAQ)**، **مواصفات المنتجات**، **البيانات الوصفية** (تاريخ، مؤلف، تصنيف). وبديله الجدول `<table>` لو البيانات فعلاً ليها صفوف وأعمدة متعددة.

> [!analogy] تخيّل قاموس: كل كلمة بخط عريض (dt) وتحتها شرحها (dd). أو فاتورة: «الإجمالي: 500». ده بالظبط الـ `<dl>`: أزواج اسم وقيمة.

> [!key] `<dl>` = أزواج `<dt>` (المصطلح) + `<dd>` (التعريف). تقدر تلف كل زوج في `<div>` للتنسيق.

## try

جرّب تضيف مصطلح جديد.

```html
<dl>
  <dt>HTML</dt>
  <dd>لغة ترميز بتبني هيكل الصفحة.</dd>
  <dt>CSS</dt>
  <dd>لغة بتنسّق شكل الصفحة.</dd>
</dl>
```

## syntax

```html nolive
<dl>
  <dt>المصطلح</dt>
  <dd>التعريف</dd>
</dl>
```

- `<dl>` — **الوسم الافتتاحي**.
- `<dt>` — المصطلح أو الاسم.
- `<dd>` — التعريف أو القيمة.
- `</dl>` — **الوسم الختامي** إجباري.

## use

- لقواميس ومصطلحات (Glossary).
- لأسئلة شائعة (FAQ).
- لمواصفات منتج أو بيانات (اسم: قيمة).
- لبيانات وصفية (تاريخ، كاتب).

## avoid

- متستخدمهوش لقايمة عادية: `<ul>`.
- متستخدمهوش للجداول المعقدة: `<table>`.
- متحطش جواه غير `<dt>` و`<dd>` (و`<div>`).

## examples

### 1) قاموس بسيط
مصطلح وتعريف.

```html
<dl>
  <dt>الوسم</dt>
  <dd>جزء من الكود بين &lt; و &gt;.</dd>
  <dt>الخاصية</dt>
  <dd>معلومة إضافية على الوسم.</dd>
</dl>
```

- كل `<dd>` بيظهر بإزاحة تحت `<dt>`.
- ده الشكل الكلاسيكي للقاموس.

### 2) مواصفات منتج
اسم: قيمة.

```html
<dl>
  <dt>الاسم</dt><dd>لابتوب Dell</dd>
  <dt>الذاكرة</dt><dd>16 جيجا</dd>
  <dt>السعر</dt><dd>25,000 جنيه</dd>
</dl>
```

- كل خاصية ليها قيمتها.
- ده بديل مناسب للجدول لو البيانات بسيطة.

### 3) أكتر من dd لنفس dt
مصطلح بتعريفين.

```html
<dl>
  <dt>Java</dt>
  <dd>لغة برمجة.</dd>
  <dd>جزيرة في إندونيسيا.</dd>
</dl>
```

- نفس المصطلح له معنيين، وكل معنى في `<dd>` لوحده.
- كل `<dd>` ليه إزاحته تحت الـ `<dt>`.
- ده الشكل المعتاد للقواميس اللي الكلمة فيها أكتر من معنى.

### 4) تغليف الأزواج بـ div
علشان التنسيق.

```html
<style>
  .row { display:flex; gap:12px; border-bottom:1px solid #ddd; padding:6px 0; }
  dt { font-weight:bold; min-width:80px; }
  dd { margin:0; }
</style>
<dl>
  <div class="row"><dt>الاسم</dt><dd>أحمد</dd></div>
  <div class="row"><dt>المدينة</dt><dd>القاهرة</dd></div>
</dl>
```

- كل زوج جوه `<div>` عشان نخلّيه صف.
- الـ `<div>` مسموح كابن مباشر للـ `<dl>`.

### 5) أسئلة شائعة FAQ
سؤال وجواب.

```html
<dl>
  <dt>الكورسات مجانية؟</dt>
  <dd>أيوه، كلها مجانية.</dd>
  <dt>محتاج خبرة؟</dt>
  <dd>لأ، من الصفر.</dd>
</dl>
```

- السؤال `<dt>` والجواب `<dd>`.
- بديل مناسب لـ `<details>` لو عايز الكل ظاهر.

## rules

- parents: أي عنصر بيقبل **Flow content**.
- children: `<dt>` و`<dd>` (أو `<div>` بيلفّ مجموعة منهم) وعناصر الدعم.
- closing: الوسم الختامي `</dl>` إجباري.
- role: `generic` (في بعض المتصفحات).
- dom: `HTMLDListElement`.
- layout: `display: block`.

## mistakes

### dd من غير dt
```html bad
<dl>
  <dd>تعريف من غير مصطلح</dd>
</dl>
```
```html good
<dl>
  <dt>المصطلح</dt>
  <dd>التعريف</dd>
</dl>
```
ليه؟ كل `<dd>` لازم يبقى قبله `<dt>`.

### dl لقايمة عادية
```html bad
<dl><dd>تفاح</dd><dd>موز</dd></dl>
```
```html good
<ul><li>تفاح</li><li>موز</li></ul>
```
ليه؟ القايمة العادية `<ul>`.

## a11y

- بعض قارئات الشاشة بتعلن عدد الأزواج.
- حافظ على الأزواج واضحة (dt ثم dd).
