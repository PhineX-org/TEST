## intro

بعد ما قسّمت الصفحة لأقسام رئيسية بـ `<h2>`، ساعات القسم الواحد بيحتاج يتقسم لأجزاء أصغر. هنا بييجي دور `<h3>`: **عنوان فرعي** جوه قسم `<h2>`. مثلاً قسم «الكورسات» (`<h2>`) فيه «HTML» و«CSS» و«JavaScript»، وكل واحد منهم `<h3>`.

القاعدة زي اللي قبلها: الـ `<h3>` بييجي **بعد `<h2>`** مباشرةً من غير قفز، وتحته لو احتجت `<h4>`. والمستوى هيكل، والحجم CSS. الحجم الافتراضي لـ `<h3>` هو `1.17em` وعريض.

نقطة مفيدة: مش لازم كل `<h2>` يبقى فيه `<h3>`. ولا لازم تستخدم كل المستويات الستة. في معظم الصفحات `h1` و `h2` و `h3` كفاية جداً، ولو لقيت نفسك محتاج `h5` و `h6` كتير، غالباً الصفحة محتاجة إعادة تنظيم أو تقسيم لصفحات.

> [!analogy] في الكتاب: الفصل «الحيوانات» (h2)، وجواه «الثدييات» و«الطيور» و«الأسماك» (h3). كل واحد تفصيلة جوه الفصل.

> [!key] `<h3>` = قسم **فرعي** جوه `<h2>`. بييجي بعده مباشرةً.

## try

جرّب تضيف `<h3>` تالت جوه نفس القسم.

```html
<h2>الكورسات</h2>
<h3>HTML</h3>
<p>أساس الويب.</p>
<h3>CSS</h3>
<p>تنسيق الصفحة.</p>
```

## syntax

```html nolive
<h3>عنوان القسم الفرعي</h3>
```

- `<h3>` — **الوسم الافتتاحي**.
- النص — عنوان القسم الفرعي.
- `</h3>` — **الوسم الختامي** إجباري.

## use

- لتقسيم قسم `<h2>` لأجزاء فرعية.
- لعناوين كروت جوه قسم (كل كارت عنوانه `<h3>`).
- لعناوين أسئلة في صفحة أسئلة شائعة.
- لعناوين تعليقات أو بنود جوه مقال.

## avoid

- متستخدمهوش من غير `<h2>` قبله.
- متقفزش لـ `<h5>` بعده.
- متستخدمهوش للتكبير فقط.

## attributes

مالوش خصائص خاصة، بيقبل **الخصائص العامة** ([[global-attributes]]).

### align {deprecated}
قديمة، استخدم `text-align` في CSS.

### id
بتخلّيه هدف لرابط.

## examples

### 1) h3 تحت h2
قسم فرعي.

```html
<h2>لغات الويب</h2>
<h3>HTML</h3>
<p>الهيكل.</p>
<h3>CSS</h3>
<p>الشكل.</p>
<h3>JavaScript</h3>
<p>التفاعل.</p>
```

- التلات `<h3>` تحت `<h2>` واحد.
- كل واحد بيوصف جزء من القسم الأب.
- قارئ الشاشة بيعلنهم «عنوان مستوى 3».

### 2) كروت بـ h3
كل كارت عنوانه `<h3>`.

```html
<style>
  .c { border:1px solid #ccc; border-radius:8px; padding:8px; margin:6px 0; }
  .c h3 { margin:0 0 4px; font-size:16px; }
</style>
<h2>الكورسات المميزة</h2>
<div class="c"><h3>HTML</h3><p>للمبتدئين</p></div>
<div class="c"><h3>CSS</h3><p>للمبتدئين</p></div>
```

- العناوين في الكروت `<h3>` تحت عنوان القسم `<h2>`.
- الحجم صغّرناه بـ CSS من غير تغيير المستوى.

### 3) أسئلة شائعة
كل سؤال h3.

```html
<h2>أسئلة شائعة</h2>
<h3>الكورسات مجانية؟</h3>
<p>أيوه.</p>
<h3>محتاج خبرة؟</h3>
<p>لأ، من الصفر.</p>
```

- الأسئلة هي أقسام فرعية من قسم الأسئلة.
- المستخدم بقارئ الشاشة ينط على أي سؤال من قايمة العناوين.

### 4) h3 مع h4
تدرّج أعمق.

```html
<h2>CSS</h2>
<h3>الألوان</h3>
<h4>الأسماء</h4>
<p>red و blue.</p>
<h4>HEX</h4>
<p>#ff0000.</p>
```

- `<h4>` تحت `<h3>` مباشرةً.
- مش لازم تنزل لمستويات أعمق من اللي محتاجه.

### 5) h3 بأيقونة
أيقونة زخرفية قبل العنوان.

```html
<style>
  h3 { display: flex; gap: 8px; align-items: center; font-size: 18px; }
</style>
<h2>المميزات</h2>
<h3><span aria-hidden="true">⚡</span> سريع</h3>
<p>بيحمّل في أقل من ثانية.</p>
<h3><span aria-hidden="true">🔒</span> آمن</h3>
<p>بياناتك محمية.</p>
```

- الأيقونة جوه `<span aria-hidden="true">` فقارئ الشاشة بيتجاهلها ويقرا النص بس.
- التنسيق (Flexbox) على العنوان نفسه بيحط الأيقونة جنب النص.
- المستوى لسه `h3` والهيكل سليم.

## rules

- parents: أي عنصر بيقبل **Flow content**، أو `<hgroup>`.
- children: **Phrasing content**.
- closing: الوسم الختامي `</h3>` إجباري.
- role: `heading` (مستوى 3).
- dom: `HTMLHeadingElement`.
- layout: `display: block`، خط عريض وحجم `1.17em` افتراضياً.

## mistakes

### h3 من غير h2
```html bad
<h1>الصفحة</h1>
<h3>قسم</h3>
```
```html good
<h1>الصفحة</h1>
<h2>قسم</h2>
```
ليه؟ متقفزش المستوى التاني.

### h3 للتنسيق
```html bad
<h3>نص صغير مميز</h3>
```
```html good
<p><strong>نص صغير مميز</strong></p>
```
ليه؟ لو مش عنوان قسم، متستخدمش عنصر عنوان.

## a11y

- المستخدم بيتنقل بين عناوين `<h3>` بسرعة. اكتب عناوين واضحة.
- متقفزش مستويات.

## tips

- لو الصفحة بسيطة، `h1` و `h2` و `h3` كفاية.
- متنزلش لمستوى أعمق من محتاج.
