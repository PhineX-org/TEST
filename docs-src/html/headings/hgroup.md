## intro

أوقات العنوان بيبقى ليه **تابع**: عنوان رئيسي وتحته سطر صغير بيشرحه. مثلاً فيلم اسمه «الرحلة» وتحته «قصة حقيقية عن الشجاعة». أو كتاب اسمه «تعلّم HTML» وتحته «من الصفر للاحتراف». السطر التاني ده **مش عنوان تاني** في هيكل الصفحة، هو بس عنوان فرعي (Subtitle) أو شعار (Tagline) للأول.

المشكلة إنك لو حطيت `<h1>` وبعده `<h2>` للسطر الصغير ده، هتلخبط هيكل الصفحة: قارئ الشاشة هيفتكر إن «الشعار» ده قسم جديد اسمه كذا وله محتوى تحته. وده غلط، لأنه مجرد تابع للعنوان.

الحل هو `<hgroup>`: **مجموعة عنوان**. بتلفّ جواها عنوان واحد بس (`<h1>` لحد `<h6>`) ومعاه فقرات `<p>` فيها العنوان الفرعي أو الشعار أو العنوان البديل. وبكده المتصفح وقارئ الشاشة يفهموا إن الفقرات دي تابعة للعنوان، مش بتفتح قسم جديد.

التعريف الحديث في المواصفة (اتغيّر في 2022): الـ `<hgroup>` ممكن يحتوي **صفر أو أكتر `<p>`، بعدين عنوان واحد، بعدين صفر أو أكتر `<p>`**. وده بيحل محل الاستخدام القديم اللي كان بيسمح بأكتر من عنوان جواه. وفي الواقع هو **ما بيغيّرش الشكل** (مجرد حاوية Block)، ودوره دلالي بس.

> [!analogy] تخيّل غلاف كتاب: اسم الكتاب بخط كبير، وتحته بخط صغير «رواية». الاتنين بيمثّلوا «عنوان واحد» مش عنوانين مستقلين. ده الـ `<hgroup>`.

> [!key] `<hgroup>` = **عنوان واحد** + `<p>` توابعه (شعار، عنوان فرعي). متحطش جواه أكتر من عنوان.

## try

بدّل ترتيب الفقرة والعنوان وشوف، أو ضيف `<p>` تاني بعد العنوان.

```html
<style>
  hgroup { border-right: 5px solid #39ff14; padding-right: 12px; }
  hgroup h1 { margin: 0; }
  hgroup p { margin: 4px 0 0; color: #64748b; }
</style>
<hgroup>
  <h1>تعلّم HTML</h1>
  <p>من الصفر للاحتراف في أسبوع</p>
</hgroup>
```

## syntax

```html nolive
<hgroup>
  <h1>العنوان الرئيسي</h1>
  <p>العنوان الفرعي أو الشعار</p>
</hgroup>
```

- `<hgroup>` — **الوسم الافتتاحي**.
- `<h1>`…`<h6>` — عنوان واحد بس.
- `<p>` — صفر أو أكتر، قبل العنوان أو بعده.
- `</hgroup>` — **الوسم الختامي** إجباري.

## use

- لعنوان معاه عنوان فرعي (Subtitle) أو شعار (Tagline).
- لعنوان معاه «سوبر تايتل» فوقه (زي تصنيف أو رقم حلقة).
- لعنوان بديل (اسم بلغتين مثلاً).
- جوه `<header>` المقال أو الصفحة.

## avoid

- متحطش جواه أكتر من عنوان واحد.
- متحطش جواه محتوى تاني غير `<p>` والعنوان.
- متستخدمهوش لو مفيش عنوان فرعي: العنوان لوحده كفاية.
- متحطش `<hgroup>` ورا `<h2>` لو مفيش داعي.

## attributes

مالوش خصائص خاصة، بيقبل **الخصائص العامة** ([[global-attributes]]).

### class
للتنسيق، زي `class="title-group"`.

### id
اسم فريد لو عايز تستهدفه.

## examples

### 1) عنوان وعنوان فرعي
الحالة الأشهر.

```html
<hgroup>
  <h1>مدونة PhineX</h1>
  <p>كل ما يخص البرمجة بالعربي</p>
</hgroup>
```

- العنوان هو `<h1>` اللي بيحدد الصفحة.
- الفقرة تابعة له، مش قسم جديد.
- قارئ الشاشة هيقرا العنوان والفقرة كمجموعة واحدة.

### 2) عنوان معاه سوبر تايتل
الفقرة بتيجي **قبل** العنوان.

```html
<hgroup>
  <p>الحلقة 5</p>
  <h2>إزاي تبني أول صفحة ويب</h2>
</hgroup>
```

- الفقرة اللي قبل العنوان بتدّي سياق (رقم الحلقة).
- ده مسموح لأن المواصفة بتسمح بـ `<p>` قبل أو بعد العنوان.

### 3) جوه header المقال
المكان الشائع.

```html
<article>
  <header>
    <hgroup>
      <h2>HTML5</h2>
      <p>الإصدار اللي غيّر الويب</p>
    </hgroup>
    <p>بقلم أحمد</p>
  </header>
  <p>نص المقال…</p>
</article>
```

- `<hgroup>` للعنوان وتوابعه بس، و`<p>` الكاتب برّاه لأنه مش من توابع العنوان.
- الـ `<header>` بيجمّع كل ده كمقدمة للمقال.

### 4) عنوان بلغتين
العنوان البديل.

```html
<hgroup>
  <h1>مرحباً</h1>
  <p lang="en" dir="ltr">Welcome</p>
</hgroup>
```

- الفقرة بتحمل العنوان بالإنجليزي، و`lang="en"` بيعرّف لغتها.
- `dir="ltr"` بيضبط اتجاه الكلمة الإنجليزي.

### 5) تنسيق مجموعة العنوان
شكل جذاب بالـ CSS.

```html
<style>
  hgroup { text-align: center; padding: 16px; background: #0f172a; color: #fff; border-radius: 12px; }
  hgroup h1 { margin: 0; color: #39ff14; }
  hgroup p { margin: 6px 0 0; color: #94a3b8; }
</style>
<hgroup>
  <h1>PhineX Academy</h1>
  <p>تعلّم، جرّب، ابدع</p>
</hgroup>
```

- التنسيق كله CSS، والـ `<hgroup>` حاوية دلالية فقط.
- لو شلت CSS هيفضل العنوان والفقرة منطقيين.

## rules

- parents: أي عنصر بيقبل **Heading content** أو Flow زي `<header>` و `<article>` و `<section>` و `<div>` و `<body>`.
- children: صفر أو أكتر `<p>`، ثم عنوان واحد (`<h1>`…`<h6>`)، ثم صفر أو أكتر `<p>`، (وممكن عناصر دعم زي `<script>` و `<template>`).
- closing: الوسم الختامي `</hgroup>` إجباري.
- role: `group`.
- dom: `HTMLElement`.
- layout: `display: block`.

## mistakes

### أكتر من عنوان جوه hgroup
```html bad
<hgroup>
  <h1>الصفحة</h1>
  <h2>العنوان الفرعي</h2>
</hgroup>
```
```html good
<hgroup>
  <h1>الصفحة</h1>
  <p>العنوان الفرعي</p>
</hgroup>
```
ليه؟ المواصفة الحديثة بتسمح بعنوان واحد بس، والباقي `<p>`.

### محتوى تاني جوه hgroup
```html bad
<hgroup>
  <h1>العنوان</h1>
  <div>معلومات</div>
  <img alt="" src="a.jpg">
</hgroup>
```
```html good
<hgroup>
  <h1>العنوان</h1>
  <p>شعار</p>
</hgroup>
<img alt="" src="a.jpg">
```
ليه؟ الـ `<hgroup>` لعنوان وفقرات توابعه بس.

### hgroup بدون سبب
```html bad
<hgroup>
  <h2>قسم</h2>
</hgroup>
```
```html good
<h2>قسم</h2>
```
ليه؟ من غير عنوان فرعي مفيش فايدة من `<hgroup>`.

## a11y

- بعض قارئات الشاشة بتقرا الـ `<hgroup>` كمجموعة، وبعضها بيقرا العنوان والفقرة منفصلين: متعتمدش على سلوك معيّن.
- لو العنوان الفرعي مهم للفهم، خلّيه واضح ومقروء بصرياً.
- متحطش كل حاجة في `<hgroup>`: العنوان لازم يبقى مفهوم لوحده.

## tips

- لو العنوان الفرعي ملوش علاقة فعلية بالعنوان، خلّيه `<p>` برّا الـ `<hgroup>`.
- الـ `<hgroup>` ما بيأثرش على مستوى العنوان: `h1` جواه لسه `h1`.
- في الاستخدامات القديمة كانوا بيحطوا `h1` و `h2` جواه، ودلوقتي استبدل الثاني بـ `<p>`.
