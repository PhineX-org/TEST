## intro

الـ `<h6>` هو **آخر مستوى** من مستويات العناوين في HTML: مفيش `<h7>`. بيجي تحت `<h5>` مباشرةً وبيمثّل أدق تفصيلة ممكن تتعنون. عملياً **نادراً جداً** هتشوفه، وغالباً في توثيقات ضخمة أو كتب أكاديمية.

حجمه الافتراضي `0.67em`، وده **أصغر من الفقرة** بشكل واضح وعريض، فشكله ممكن يبان غريب لو سبته من غير تنسيق. وزي أي عنوان، المستوى معنى، والحجم CSS. ولو وصلت للمستوى السادس فده تقريباً دليل إن هيكل الصفحة معقد زيادة عن اللزوم وإنك تحتاج تبسّطه.

وعلى جانب الوصولية: قارئ الشاشة بيعلن المستوى، فالعناوين العميقة زي `<h6>` بتتعمل بنفس الدقة. فاتبع الترتيب وما تقفزش.

> [!key] `<h6>` = أدنى مستوى عناوين. لو محتاجه، راجع هيكل الصفحة.

## try

```html
<h5>الخطوط</h5>
<h6>التفاصيل الدقيقة</h6>
<p>مستوى سادس: أدق تفصيلة.</p>
```

## syntax

```html nolive
<h6>أدق عنوان</h6>
```

- `<h6>` — **الوسم الافتتاحي**.
- `</h6>` — **الوسم الختامي** إجباري.

## use

- كأدق مستوى في توثيق أو كتاب عميق.
- لعناوين دقيقة جداً جوه `<h5>`.

## avoid

- متستخدمهوش كنص صغير مميز.

## attributes

مالوش خصائص خاصة، بيقبل **الخصائص العامة** ([[global-attributes]]).

### align {deprecated}
قديمة، استخدم `text-align` في CSS.

## examples

### 1) السلسلة الكاملة
كل المستويات الستة.

```html
<h1>مستوى 1</h1>
<h2>مستوى 2</h2>
<h3>مستوى 3</h3>
<h4>مستوى 4</h4>
<h5>مستوى 5</h5>
<h6>مستوى 6</h6>
```

- بتلاحظ إن الحجم بيصغر تدريجياً من `h1` لـ `h6`.
- `h4` بحجم الفقرة تقريباً، و`h5` و`h6` أصغر منها.
- ده الشكل الافتراضي، وتقدر تغيّره كله بالـ CSS.

### 2) مقارنة الأحجام مع الفقرة
عشان تفهم ليه بنظبط الشكل.

```html
<h6>عنوان h6</h6>
<p>فقرة عادية للمقارنة.</p>
```

- العنوان `<h6>` شكله أصغر من الفقرة (لكن عريض).
- لو ده مش مناسب بنظبطه بـ CSS.

### 3) ضبط الشكل
نخلّي `h6` مقروء.

```html
<style>
  h6 { font-size: 13px; text-transform: uppercase; letter-spacing: 1px; color: #64748b; }
</style>
<h5>الخطوط</h5>
<h6>Font Family</h6>
<p>font-family: Cairo;</p>
```

- الحجم والـ letter-spacing بيخلّوه مقروء وأنيق.
- المعنى لسه مستوى 6.

## rules

- parents: أي عنصر بيقبل **Flow content**، أو `<hgroup>`.
- children: **Phrasing content**.
- closing: الوسم الختامي `</h6>` إجباري.
- role: `heading` (مستوى 6).
- dom: `HTMLHeadingElement`.
- layout: `display: block`، عريض وحجم `0.67em` افتراضياً.

## mistakes

### h7 مش موجود
```html bad
<h7>عنوان أعمق</h7>
```
```html good
<h6>أعمق مستوى متاح</h6>
```
ليه؟ مفيش `<h7>` في HTML، والمتصفح هيعامله كعنصر غير معروف من غير معنى عنوان.

## a11y

- قارئ الشاشة بيعلن «عنوان مستوى 6»، فاتبع الترتيب.
- ممنوع تقفز مستويات.

## tips

- لو وصلت `h6` راجع هيكل الصفحة.
- استخدم ARIA (`role="heading" aria-level="7"`) في حالات نادرة جداً لو لازم تعمل مستوى أعمق، لكن الأفضل تبسّط.
