## intro

لو الـ `<h1>` هو اسم الكتاب، فالـ `<h2>` هو **اسم الفصل**. بيستخدم لعناوين الأقسام الرئيسية جوه الصفحة: «المقدمة»، «المميزات»، «الأسعار»، «تواصل معانا». كل قسم كبير ليه `<h2>`، وتحته تفاصيله وعناوينه الفرعية `<h3>`.

القاعدة: الـ `<h2>` دايماً بيجي **بعد `<h1>`** وبيتبعه محتوى القسم. وإحنا مش بنقفز: بعد `<h1>` ييجي `<h2>`، مش `<h3>`. وفي صفحة فيها مقالات كتير، كل مقال ممكن ياخد `<h2>` كعنوان له لو الصفحة نفسها (مثلاً «المدونة») ليها `<h1>`.

كل اللي اتقال عن `<h1>` في الشكل ينطبق هنا: المستوى **معنى** والحجم شغل CSS. الـ `<h2>` بيتعرض افتراضياً بحجم `1.5em` وعريض. لو عايزه يبان أصغر، صغّره بالـ CSS وسيب المستوى زي ما هو.

وبما إن الـ `<h2>` بيقابل «قسم»، فغالباً بيبقى أول حاجة جوه `<section>` أو `<article>`. ولو الـ `<section>` ليه `aria-labelledby` فبيشاور على الـ `<h2>` بتاعه، وبكده القسم بيبقى Landmark بإسم واضح (راجع [[section]]).

> [!analogy] تخيّل كتاب طبخ: اسم الكتاب (h1)، وكل باب «شوربة» و«مشويات» و«حلويات» (h2)، وجوه كل باب أسماء الوصفات (h3). الـ `<h2>` هو اسم الباب.

> [!key] `<h2>` = عنوان **القسم الرئيسي** تحت `<h1>`. متقفزش مستوى.

## try

جرّب تضيف قسم تالت بـ `<h2>` جديد.

```html
<h1>كورس HTML</h1>
<h2>المقدمة</h2>
<p>يعني إيه HTML وليه بنتعلمه.</p>
<h2>الأمثلة</h2>
<p>أمثلة عملية على كل عنصر.</p>
```

## syntax

```html nolive
<h2>عنوان القسم</h2>
```

- `<h2>` — **الوسم الافتتاحي**.
- النص — عنوان القسم.
- `</h2>` — **الوسم الختامي** إجباري.

## use

- لعناوين الأقسام الرئيسية تحت `<h1>`.
- لعنوان كل `<article>` في صفحة قايمة مقالات.
- لعنوان كل `<section>`.
- لعناوين الشرايح أو التبويبات الرئيسية.

## avoid

- متستخدمهوش قبل `<h1>` في الصفحة.
- متقفزش من `<h2>` لـ `<h4>`.
- متستخدمهوش للتكبير فقط.
- متحطش `<h2>` من غير محتوى تحته.

## attributes

مالوش خصائص خاصة، بيقبل **الخصائص العامة** ([[global-attributes]]).

### align {deprecated}
كانت بتحدد المحاذاة. **قديمة**: استخدم `text-align` في CSS.

### id
بتخلّي العنوان هدف لرابط (`#features`)، وبتستخدم في `aria-labelledby`.

## examples

### 1) h2 تحت h1
الهيكل الأساسي.

```html
<h1>موقع PhineX</h1>
<h2>الكورسات</h2>
<p>قايمة الكورسات.</p>
<h2>المدونة</h2>
<p>آخر المقالات.</p>
```

- كل `<h2>` بيبدأ قسم جديد تحت عنوان الصفحة.
- الشكل افتراضياً أصغر من `<h1>` وأكبر من `<h3>`.
- قارئ الشاشة بيعلن كل واحد «عنوان مستوى 2».

### 2) h2 جوه section
القسم بيتعرّف بعنوانه.

```html
<section aria-labelledby="f">
  <h2 id="f">المميزات</h2>
  <p>سريع ومجاني.</p>
</section>
```

- `aria-labelledby="f"` بيربط القسم بعنوانه فيبقى Landmark.
- ده الربط الأنضف بين القسم وعنوانه.

### 3) h2 جوه article
في صفحة قايمة مقالات.

```html
<h1>المدونة</h1>
<article>
  <h2>إزاي تتعلم HTML</h2>
  <p>ملخص المقال…</p>
</article>
<article>
  <h2>أساسيات CSS</h2>
  <p>ملخص المقال…</p>
</article>
```

- عنوان الصفحة `h1`، وكل مقال `h2` تحته.
- لو فتحت صفحة المقال لوحده، عنوانه هيبقى `<h1>` هناك.

### 4) تنسيق h2
تغيير الشكل من غير تغيير المعنى.

```html
<style>
  h2 { font-size: 20px; color: #7c3aed; border-right: 5px solid #7c3aed; padding-right: 10px; }
</style>
<h2>قسم بشكل مميز</h2>
<p>الشكل CSS والمعنى لسه عنوان مستوى 2.</p>
```

- الحد الجانبي واللون من الـ CSS.
- العنصر لسه `h2` فالهيكل سليم.

### 5) h2 مع h3 تحته
أقسام فرعية.

```html
<h2>الكورسات</h2>
<h3>HTML</h3>
<p>أساس الويب.</p>
<h3>CSS</h3>
<p>التنسيق.</p>
```

- `<h3>` بيجي بعد `<h2>` مباشرةً، مش `<h4>`.
- كل `<h3>` تفصيلة داخل قسم «الكورسات».

## rules

- parents: أي عنصر بيقبل **Flow content**، أو `<hgroup>`.
- children: **Phrasing content**.
- closing: الوسم الختامي `</h2>` إجباري.
- role: `heading` (مستوى 2).
- dom: `HTMLHeadingElement`.
- layout: `display: block`، خط عريض وحجم `1.5em` افتراضياً.

## mistakes

### h2 للتنسيق
```html bad
<h2>نص عادي كبير</h2>
```
```html good
<p style="font-size:24px">نص عادي كبير</p>
```
ليه؟ لو مش عنوان قسم، متخليهوش `<h2>`.

### القفز لـ h4
```html bad
<h1>الصفحة</h1>
<h2>قسم</h2>
<h4>تفصيلة</h4>
```
```html good
<h1>الصفحة</h1>
<h2>قسم</h2>
<h3>تفصيلة</h3>
```
ليه؟ القفز بيكسر الهيكل.

### h2 قبل h1
```html bad
<h2>قسم</h2>
<h1>الصفحة</h1>
```
```html good
<h1>الصفحة</h1>
<h2>قسم</h2>
```
ليه؟ الـ `<h1>` أول عنوان.

## a11y

- مستخدم قارئ الشاشة بينط بين عناوين `<h2>` لتصفح الأقسام.
- خلّي نص العنوان واضح ويوصف القسم.
- متكررش نفس العنوان في أقسام مختلفة.

## tips

- اكتب `<h2>` لكل قسم تحس إنه «يستاهل عنوان».
- اقرا عناوين `h1` و `h2` بس: لازم يلخّصوا الصفحة.
- لو القسم ملوش عنوان طبيعي، شوف لو محتاج `<section>` أصلاً.
