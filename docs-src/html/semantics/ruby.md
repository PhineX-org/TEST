## intro

لما بتقرا نص ياباني، بتلاقي فوق بعض الحروف الصعبة (الكانجي) حروف صغيرة بتوضّح نطقها. الحروف الصغيرة دي اسمها **Ruby** أو **Furigana**. وفي الصينية بتبقى **Pinyin** (نطق بالحروف اللاتينية) أو **Zhuyin**. الفكرة إن في **نص أساسي** و**نص صغير** مرتبط بيه فوقه أو تحته بيشرحه. العنصر اللي بيعمل ده في HTML هو `<ruby>`.

الـ `<ruby>` حاوية، وجواها بتحط **النص الأساسي** (Base) ثم `<rt>` (**Ruby Text**: النص الصغير اللي هيظهر فوق)، وممكن `<rp>` (**Ruby Parentheses**: أقواس تظهر **بس** في المتصفحات اللي مش بتدعم ruby). مثال: `<ruby>漢<rt>han</rt></ruby>`: الحرف «漢» فوقه «han» صغير.

مع إنه معمول للغات الآسيوية، تقدر تستخدمه في **أي لغة**: نطق كلمة إنجليزية بحروف عربية («HTML» وفوقها «إتش تي إم إل»)، أو شرح مصطلح فوق الكلمة، أو تشكيل. وده مفيد جداً في المواقع التعليمية بالعربي اللي بتشرح كلمات أجنبية.

وفي المتصفحات الحديثة (كلها تقريباً) الـ `<ruby>` بيتعرض صح، وبتتحكم في مكان النص الصغير بـ CSS (`ruby-position: over` أو `under`). والمتصفحات اللي مش بتدعم بتعرض النص الصغير بين قوسين (من `<rp>`) بدل ما يضيع.

> [!analogy] تخيّل كتاب أطفال بيكتب كلمة صعبة وفوقها كلمة صغيرة بتقولك تنطقها إزاي. الكلمة الكبيرة هي النص الأساسي، والصغيرة هي `<rt>`، والكل جوه `<ruby>`.

> [!key] `<ruby>` = حاوية. النص الأساسي + `<rt>` (النص الصغير) + `<rp>` (أقواس احتياطية).

## try

جرّب تضيف كلمة تانية بنطقها. ولاحظ إن الشرح الصغير بيظهر فوق الكلمة.

```html
<p style="font-size:28px; line-height:2.4">
  <ruby>HTML<rt>إتش تي إم إل</rt></ruby>
  و<ruby>CSS<rt>سي إس إس</rt></ruby>
  أساس الويب.
</p>
```

## syntax

```html nolive
<ruby>
  漢字
  <rp>(</rp><rt>kanji</rt><rp>)</rp>
</ruby>
```

- `<ruby>` — **الوسم الافتتاحي**.
- النص الأساسي — اللي بيتعرض بحجمه العادي.
- `<rp>(</rp>` — قوس افتتاحي احتياطي (مخفي في المتصفحات الداعمة).
- `<rt>…</rt>` — النص الصغير (النطق).
- `<rp>)</rp>` — قوس ختامي احتياطي.
- `</ruby>` — **الوسم الختامي** إجباري.

## use

- لنطق الكلمات الصعبة في اليابانية (Furigana) والصينية (Pinyin).
- لنطق كلمات أجنبية بحروف عربية في الدروس.
- لتشكيل أو شرح مختصر فوق كلمة.
- للمواقع التعليمية اللي بتعلّم لغات.

## avoid

- متستخدمهوش لتفسيرات طويلة: النص الصغير لازم يبقى قصير.
- متستخدمهوش لحاجة مش «تعليق على النص»: ده مش تلميح (Tooltip).
- متنساش `<rp>` لو عايز دعم المتصفحات القديمة.
- متستخدمهوش للتزيين.

## attributes

مالوش خصائص خاصة، بيقبل **الخصائص العامة** ([[global-attributes]]).

### lang
مهمة: بتحدد لغة النص الأساسي، والـ `<rt>` ممكن يبقى بلغة تانية.

```html nolive
<ruby lang="ja">漢字<rt lang="ja-Latn">kanji</rt></ruby>
```

### class
للتنسيق.

## examples

### 1) أبسط ruby
نص أساسي ونطقه.

```html
<p style="font-size:30px; line-height:2.5">
  <ruby>東京<rt>とうきょう</rt></ruby>
</p>
```

- «東京» (طوكيو) هو النص الأساسي، و«とうきょう» نطقه بالهيراغانا.
- النص الصغير بيظهر فوق النص الأساسي تلقائياً.
- لو جهازك مفيهوش خطوط يابانية ممكن تشوف مربعات، وده مش مشكلة في الكود.

### 2) مع rp للمتصفحات القديمة
الأقواس بتظهر لو ruby مش مدعوم.

```html
<p style="font-size:28px; line-height:2.4">
  <ruby>
    漢字<rp>(</rp><rt>kanji</rt><rp>)</rp>
  </ruby>
</p>
```

- في المتصفحات الحديثة `<rp>` مخفي، فالنطق بيظهر فوق.
- في القديمة بتظهر «漢字(kanji)» وده أفضل من ضياع المعلومة.

### 3) نطق بالعربي لكلمات إنجليزية
استخدام عملي لمدرّس عربي.

```html
<p style="font-size:26px; line-height:2.4">
  اتعلم <ruby>JavaScript<rt>جافا سكريبت</rt></ruby>
  و<ruby>Python<rt>بايثون</rt></ruby>.
</p>
```

- كل كلمة إنجليزية فوقها نطقها بالعربي.
- بيفيد المبتدئين اللي مش متعودين على النطق.

### 4) كذا كلمة في ruby واحد
نص أساسي بأجزاء، وكل جزء ليه نطق.

```html
<p style="font-size:28px; line-height:2.5">
  <ruby>
    أ<rt>a</rt>
    ب<rt>b</rt>
    ت<rt>t</rt>
  </ruby>
</p>
```

- كل حرف ليه `<rt>` بعده مباشرة، فبيظهر فوق الحرف اللي قبله.
- بيخلّي لك تحكم دقيق في كل جزء.

### 5) نص تحت الكلمة
تغيير مكان النص الصغير بالـ CSS.

```html
<style>
  ruby { ruby-position: under; }
  rt { font-size: 0.6em; color: #0ea5e9; }
</style>
<p style="font-size:28px; line-height:2.4">
  <ruby>الجاذبية<rt>gravity</rt></ruby>
</p>
```

- `ruby-position: under` بتنزّل النص الصغير تحت.
- بتلوّن النص الصغير وتصغّره بـ CSS.

### 6) ruby بدون دعم: النص الاحتياطي
فاهم إيه اللي بيحصل لو مش مدعوم.

```html
<style>
  /* محاكاة متصفح مش بيدعم ruby */
  ruby, rt, rp { display: inline; }
  rp { display: inline; }
  rt { font-size: 0.8em; }
</style>
<p style="font-size:24px">
  <ruby>漢字<rp>(</rp><rt>kanji</rt><rp>)</rp></ruby>
</p>
```

- لما `display` بيتحول لـ inline النص بيتعرض متتابع بالأقواس: «漢字(kanji)».
- ده بالظبط اللي بيحصل في متصفح قديم، والأقواس بتحفظ المعنى.

## rules

- parents: أي عنصر بيقبل **Phrasing content**.
- children: **Phrasing content** مع `<rt>` و`<rp>` (النص الأساسي ثم `<rt>`).
- closing: الوسم الختامي `</ruby>` إجباري.
- role: `generic`.
- dom: `HTMLElement`.
- layout: `display: ruby`.

## mistakes

### نسيان rt
```html bad
<ruby>漢字</ruby>
```
```html good
<ruby>漢字<rt>kanji</rt></ruby>
```
ليه؟ من غير `<rt>` مفيش حاجة تظهر فوق النص، فالعنصر ملوش فايدة.

### rt خارج ruby
```html bad
<p>漢字<rt>kanji</rt></p>
```
```html good
<p><ruby>漢字<rt>kanji</rt></ruby></p>
```
ليه؟ الـ `<rt>` لازم يبقى جوه `<ruby>`.

### نص طويل في rt
```html bad
<ruby>HTML<rt>لغة ترميز النص التشعبي هي اللغة الأساسية لبناء الصفحات</rt></ruby>
```
```html good
<abbr title="لغة ترميز النص التشعبي">HTML</abbr>
```
ليه؟ الـ `<rt>` للنطق القصير، لا للشرح الطويل.

## a11y

- قارئ الشاشة بيقرا النص الأساسي والنص الصغير (حسب الدعم).
- حدد `lang` للنص الأساسي والنطق.
- متعتمدش على `<rt>` لوحده لمعلومة أساسية.

## tips

- خلي حجم `<rt>` أصغر بشوية (الافتراضي نصف الحجم تقريباً).
- ضيف `line-height` أكبر عشان النص الصغير ماياخدش من السطر اللي فوق.
- جرّب `ruby-position` و`ruby-align`.
