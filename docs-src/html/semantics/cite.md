## intro

كل ما تذكر كتاب أو فيلم أو أغنية أو بحث في كلامك، بتحتاج تعلّم إن ده **عنوان عمل**. العنصر المخصوص ليه هو `<cite>` (اختصار **Citation**: استشهاد). بيظهر مائل افتراضياً، لكن معناه الحقيقي: «ده اسم عمل إبداعي اتذكر كمرجع».

أهم نقطة وأكتر حاجة بيغلط فيها الناس: الـ `<cite>` هو **لعنوان العمل** (كتاب، فيلم، لوحة، أغنية، مقال، بحث، مسرحية، لعبة، برنامج…) **مش لاسم الشخص**. يعني «قرأت `<cite>مقدمة ابن خلدون</cite>`» صح، لكن «قال `<cite>ابن خلدون</cite>`» غلط حسب المواصفة الحالية (WHATWG). كانت نسخ قديمة من HTML بتسمح بأسماء الأشخاص، لكن اتغيّرت. اسم الشخص بيتكتب كنص عادي (أو `<span>` لو محتاج).

بيتحط عادةً في مكانين: داخل `<figcaption>` بتاع اقتباس (للمصدر)، أو داخل جملة بتذكر فيها عمل («شاهدت `<cite>الفيل الأزرق</cite>` امبارح»). وبيشتغل كويس مع `<blockquote>` و`<q>` لتحديد مصدر الاقتباس.

وفرّق بينه وبين `<i>` و`<em>`: الـ `<i>` لنص بنبرة مختلفة، والـ `<em>` لتأكيد، أما `<cite>` فـ**معناه محدد**: عنوان عمل. والمتصفح بيعرضهم كلهم مائل، لكن المعنى مختلف.

> [!analogy] تخيّل قائمة المراجع في آخر بحث: «الأيام – طه حسين». عنوان الكتاب بيتكتب مميّز (مائل). ده `<cite>`: بيعلّم على «اسم العمل» اللي رجعنا له.

> [!key] `<cite>` = **عنوان عمل** (كتاب/فيلم/أغنية…). مش اسم شخص.

## try

جرّب تضيف مصدر تاني بـ `<cite>`.

```html
<p>قرأت رواية <cite>الأيام</cite> وشاهدت فيلم <cite>الفيل الأزرق</cite>.</p>
<p>استمعت لأغنية <cite>أنا هنا</cite> وزرت لوحة <cite>الموناليزا</cite>.</p>
```

## syntax

```html nolive
<p>اقرأ كتاب <cite>مقدمة ابن خلدون</cite>.</p>
```

- `<cite>` — **الوسم الافتتاحي**.
- النص — عنوان العمل.
- `</cite>` — **الوسم الختامي** إجباري.

## use

- لعناوين الكتب والروايات والمقالات.
- لعناوين الأفلام والمسلسلات والأغاني والألبومات.
- لعناوين اللوحات والأعمال الفنية والألعاب.
- لمصدر اقتباس في `<figcaption>`.
- لعناوين الأبحاث والدراسات.

## avoid

- متستخدمهوش لأسماء الأشخاص.
- متستخدمهوش للتأكيد: `<em>`.
- متستخدمهوش لكلمات أجنبية: `<i>`.
- متستخدمهوش لعناوين الصفحة: `<h1>`.
- متستخدمهوش لمجرد الميل: CSS.

## attributes

مالوش خصائص خاصة، بيقبل **الخصائص العامة** ([[global-attributes]]).

### class
للتنسيق.

### lang
لو عنوان العمل بلغة مختلفة.

## examples

### 1) كتاب
أبسط حالة.

```html
<p>من أجمل ما قرأت: <cite>أولاد حارتنا</cite>.</p>
```

- العنوان بيتعرض مائل.
- المعنى: ده عنوان عمل مرجعي.
- لو شلت `<cite>` الجملة لسه مفهومة، لكنها خسرت المعنى الدلالي.

### 2) فيلم وأغنية
أنواع أعمال تانية.

```html
<p>
  شاهدت <cite>الإرهاب والكباب</cite> وسمعت <cite>نور العين</cite>.
</p>
```

- كل الأعمال الإبداعية ينفع تتعلّم بـ `<cite>`.
- ده بيساعد محركات البحث والأدوات على فهم المراجع.

### 3) مصدر اقتباس
مع `<blockquote>` و`<figcaption>`.

```html
<figure>
  <blockquote>
    <p>العلم نور والجهل ظلام.</p>
  </blockquote>
  <figcaption>— من كتاب <cite>حكم ومأثورات</cite></figcaption>
</figure>
```

- `<cite>` جوه `<figcaption>` بيعلّم على عنوان الكتاب.
- اسم القائل (لو مكتوب) نص عادي برّه `<cite>`.

### 4) اسم شخص: الاستخدام الصح
الاسم نص عادي والعمل `<cite>`.

```html
<p>
  كتب نجيب محفوظ رواية <cite>الثلاثية</cite>.
</p>
```

- «نجيب محفوظ» اسم شخص فهو نص عادي.
- «الثلاثية» عنوان عمل فهو `<cite>`.

### 5) cite مع رابط
العنوان يبقى رابط لمصدر.

```html
<p>
  اقرأ <cite><a href="https://example.com/book">عنوان الكتاب</a></cite> للمزيد.
</p>
```

- `<cite>` برّه و`<a>` جواه عشان العنوان يبقى رابط.
- الترتيب ده بيحافظ على المعنى والرابط.

### 6) إلغاء الميل
تغيير الشكل.

```html
<style>
  cite { font-style: normal; font-weight: bold; color: #7c3aed; }
</style>
<p>اقرأ <cite>كليلة ودمنة</cite> للعبرة.</p>
```

- شلنا الميل ولوّنا العنوان.
- المعنى (عنوان عمل) لسه زي ما هو.

## rules

- parents: أي عنصر بيقبل **Phrasing content**.
- children: **Phrasing content**.
- closing: الوسم الختامي `</cite>` إجباري.
- role: `generic`.
- dom: `HTMLElement`.
- layout: `display: inline`، و`font-style: italic`.

## mistakes

### cite لاسم شخص
```html bad
<p>قال <cite>أينشتاين</cite> كلمة جميلة.</p>
```
```html good
<p>قال أينشتاين كلمة جميلة.</p>
```
ليه؟ `<cite>` للعنوان فقط، مش للأشخاص.

### cite للتأكيد
```html bad
<p>ده <cite>مهم</cite> جداً.</p>
```
```html good
<p>ده <strong>مهم</strong> جداً.</p>
```
ليه؟ الأهمية `<strong>`.

### cite بدل attribute cite
```html bad
<blockquote><cite>https://example.com</cite>اقتباس</blockquote>
```
```html good
<blockquote cite="https://example.com"><p>اقتباس</p></blockquote>
```
ليه؟ رابط المصدر للآلات في خاصية `cite`، مش في عنصر.

## a11y

- مفيش دور خاص لـ `<cite>`، فقارئ الشاشة بيقراه عادي.
- ضيف سياق «من كتاب…» عشان المعنى يوصل.
- لو العنوان بلغة تانية حط `lang`.

## tips

- اسأل: «هل ده عنوان عمل؟» لو أيوه `<cite>`.
- مش لازم تستخدمه في كل مرة بتذكر عمل: استخدمه لما المرجع مهم.
- مع الأعمال الأجنبية، حط `lang`.
