## intro

الإنسان بيفهم «الخميس الجاي» أو «3 أيام فاتت» أو «الساعة 9 بالليل»، لكن الكمبيوتر محتاج تاريخ دقيق زي `2026-10-29` عشان يفهم. العنصر `<time>` بيجمع الاتنين: بتكتب النص اللي يظهر للمستخدم بأي شكل مريح، وبتحط في خاصية `datetime` القيمة **بصيغة قياسية** (ISO 8601) اللي الآلات بتفهمها.

فايدته الحقيقية: محركات البحث بتعرض تاريخ المقال الدقيق في نتايج البحث، وأدوات التقويم بتقدر تضيف الحدث لوحدها، وقارئات الشاشة ممكن تنطق التاريخ صح، وسكربتاتك تقدر تحوّل التاريخ لأي لغة أو توقيت. وكمان لو كتبت التاريخ كتابة عربية («29 أكتوبر 2026») مش بتفرق، لأن `datetime` هو المرجع.

وهو بيقبل أشكال كتير من القيم: **سنة** (`2026`)، **شهر** (`2026-10`)، **تاريخ** (`2026-10-29`)، **أسبوع** (`2026-W44`)، **وقت** (`14:30`)، **تاريخ ووقت** (`2026-10-29T14:30`)، **مع منطقة زمنية** (`2026-10-29T14:30+03:00`)، و**مدة** (`PT2H30M` يعني ساعتين ونص). ولو الـ `datetime` مش موجود، النص نفسه لازم يبقى بصيغة صحيحة.

استخدامات شائعة: **تاريخ نشر مقال**، **موعد حدث**، **ساعات العمل**، **مدة فيديو أو وصفة**. ومتستخدمهوش لتواريخ غير دقيقة («زمان»، «قديماً») لأنها مش بتتحوّل لقيمة آلية.

> [!analogy] تخيّل بطاقة هوية: بتكتب فيها «ولد في أكتوبر 1990» لكن الكمبيوتر في السجل المدني محتاج «1990-10-xx». النص للبشر والرقم للسيستم. ده `<time>`.

> [!key] `<time datetime="2026-10-29">29 أكتوبر</time>`. الصيغة: سنة-شهر-يوم، والوقت بعد T.

## try

جرّب تغيّر `datetime` وشوف الكود بيقرا إيه.

```html
<p>
  اتنشر المقال في
  <time id="t" datetime="2026-10-29T14:30:00+03:00">29 أكتوبر 2026</time>
</p>
<p id="out"></p>
<script>
  out.textContent = 'التاريخ الآلي: ' + t.dateTime + ' → ' + new Date(t.dateTime).toISOString();
</script>
```

## syntax

```html nolive
<time datetime="2026-10-29T14:30+03:00">29 أكتوبر 2026 الساعة 2:30 م</time>
```

- `<time>` — **الوسم الافتتاحي**.
- `datetime` — القيمة القياسية (يفضّل تكتبها).
- النص — الصيغة اللي المستخدم هيشوفها.
- `</time>` — **الوسم الختامي** إجباري.

## use

- لتاريخ نشر مقال أو تعليق.
- لموعد حدث أو مناسبة.
- لساعات العمل.
- لمدة (فيديو، وصفة).

## avoid

- متستخدمهوش لتواريخ غير دقيقة.
- متكتبش `datetime` بصيغة غير صحيحة.
- متستخدمهوش لقياس عام: `<meter>`.
- متحطش جواه `<time>` تاني.

## attributes

### datetime
القيمة القياسية للتاريخ أو الوقت. لو مش موجودة، لازم محتوى العنصر نفسه يبقى بصيغة صحيحة.

```html nolive
<time datetime="2026-10-29">النهاردة</time>
```

### class
للتنسيق.

### lang
لغة النص المعروض.

## examples

### 1) تاريخ بسيط
النص حر والقيمة قياسية.

```html
<p>اتولد في <time datetime="1990-05-12">12 مايو 1990</time>.</p>
```

- النص بالعربي، والقيمة بالصيغة القياسية.
- لو غيّرت النص لـ «من 36 سنة»، القيمة لسه صحيحة.
- أدوات القراءة بتستخدم `datetime` مش النص.

### 2) تاريخ ووقت
مع منطقة زمنية.

```html
<p>
  بداية البث:
  <time datetime="2026-10-29T20:00+03:00">الخميس 8 مساءً بتوقيت الرياض</time>
</p>
```

- `T` بتفصل التاريخ عن الوقت.
- `+03:00` منطقة زمنية (الرياض).
- ده بيمنع اللبس لما الناس في أماكن مختلفة.

### 3) مدة
`PT` للمدد.

```html
<p>
  مدة الوصفة:
  <time datetime="PT1H30M">ساعة ونص</time>
</p>
<p>
  مدة الفيديو: <time datetime="PT4M32S">4:32</time>
</p>
```

- `PT1H30M` = ساعة و30 دقيقة، `PT4M32S` = 4 دقايق و32 ثانية.
- الحرف `P` للمدة، و`T` للوقت.

### 4) سنة أو شهر
مش لازم يوم كامل.

```html
<p>الإصدار الأول سنة <time datetime="2014">2014</time>.</p>
<p>التقرير الشهري: <time datetime="2026-10">أكتوبر 2026</time>.</p>
<p>الأسبوع: <time datetime="2026-W44">الأسبوع 44</time>.</p>
```

- كل مستوى تفصيل بصيغة مختلفة.
- اختار المناسب لمعلومتك.

### 5) تاريخ نشر مقال
الاستخدام الأشهر.

```html
<article>
  <h2>إزاي تتعلم HTML</h2>
  <p>
    نُشر في <time datetime="2026-10-29">29 أكتوبر 2026</time>
    بواسطة أحمد.
  </p>
</article>
```

- محركات البحث بتقرا `datetime` وتعرض التاريخ في النتايج.
- مفيد لتقارير الأخبار والمدونات.

### 6) تنسيق التاريخ بالجافاسكربت
نحوّل `datetime` لتاريخ بصيغة المستخدم المحلية.

```html
<time id="t2" datetime="2026-10-29T14:30:00+03:00">…</time>
<script>
  t2.textContent = new Date(t2.dateTime).toLocaleString('ar-EG', { dateStyle: 'full', timeStyle: 'short' });
</script>
```

- `toLocaleString('ar-EG')` بيعرض التاريخ بالعربي المصري.
- القيمة الآلية ثابتة والنص بيتغير حسب اللغة.

## rules

- parents: أي عنصر بيقبل **Phrasing content**.
- children: **Phrasing content** (لكن مفيش `<time>` تاني).
- closing: الوسم الختامي `</time>` إجباري.
- role: `time`.
- dom: `HTMLTimeElement`.
- layout: `display: inline`، من غير تنسيق افتراضي.

## mistakes

### datetime بصيغة غير صحيحة
```html bad
<time datetime="29/10/2026">29 أكتوبر</time>
```
```html good
<time datetime="2026-10-29">29 أكتوبر</time>
```
ليه؟ الصيغة القياسية سنة-شهر-يوم.

### تاريخ غير دقيق
```html bad
<time datetime="زمان">زمان</time>
```
```html good
<p>من زمان.</p>
```
ليه؟ مفيش تاريخ آلي لـ «زمان».

### نسيان T
```html bad
<time datetime="2026-10-29 14:30">…</time>
```
```html good
<time datetime="2026-10-29T14:30">…</time>
```
ليه؟ الأفضل `T` بين التاريخ والوقت (المسافة مقبولة في المواصفة لكن `T` أضمن).

## a11y

- قارئ الشاشة بيقرا النص مش `datetime`، فالنص لازم يبقى واضح.
- لو التاريخ مهم، اكتب اليوم والشهر والسنة بالكامل.
- المنطقة الزمنية بتفيد لما الجمهور عالمي.

## tips

- حط `datetime` دايماً حتى لو النص بصيغة صحيحة.
- لو الصفحة متعددة اللغات، اترجم النص وسيب `datetime` زي ما هو.
- متنساش المنطقة الزمنية لأحداث البث المباشر.
