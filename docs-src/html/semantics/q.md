## intro

لما بتنقل جملة قصيرة من مصدر جوه كلامك («قال أينشتاين: **الخيال أهم من المعرفة**»)، فده اقتباس قصير بيتحط جوه الجملة. العنصر المخصوص ليه هو `<q>` (اختصار **Quotation**). الميزة الكبيرة: **المتصفح بيحط علامات التنصيص لوحده**.

يعني بدل ما تكتب `"الخيال أهم"` بإيدك، بتكتب `<q>الخيال أهم</q>` والمتصفح بيضيف علامات التنصيص المناسبة **حسب لغة الصفحة** (`lang`). في العربي «»، وفي الإنجليزي ""، وفي الفرنساوي « ». وده شغال بخاصية CSS اسمها `quotes` وعناصر `::before` و`::after`. فلو غيّرت `lang` هتتغيّر العلامات تلقائياً.

وعشان كده **ماينفعش تكتب علامات التنصيص بإيدك جوه `<q>`** وإلا هتبقى مكررة («« الجملة »»). ولو عايز تغيّر شكل العلامات، بتعدّل CSS: `q { quotes: "«" "»"; }`.

الفرق بينه وبين `<blockquote>`: الـ `<q>` Inline للقصير جوه جملة، والـ `<blockquote>` Block للطويل المنفصل. وزيه بيقبل خاصية `cite` للمصدر (رابط، مش بيظهر). ولو عايز تنسب الاقتباس لشخص، اكتب اسمه في النص أو `<cite>` لعنوان العمل.

> [!analogy] تخيّل بتكتب على الكمبيوتر وكل ما تنوّه إن ده كلام حد تاني بيحط الكمبيوتر العلامات اللي مناسبة للغتك لوحده. من غير ما تفكر في شكلها. ده `<q>`.

> [!key] `<q>` = اقتباس **قصير** جوه جملة. علامات التنصيص **أوتوماتيك**، متكتبهاش.

## try

جرّب تغيّر `lang` من `ar` لـ `en` أو `fr` وشوف علامات التنصيص بتتغيّر.

```html
<p lang="ar">
  قال أينشتاين: <q>الخيال أهم من المعرفة</q>.
</p>
<p lang="en">
  Einstein said: <q>Imagination is more important than knowledge</q>.
</p>
```

## syntax

```html nolive
<p>قال: <q cite="https://example.com">الجملة المقتبسة</q>.</p>
```

- `<q>` — **الوسم الافتتاحي**.
- `cite` — رابط المصدر (اختياري).
- النص — الاقتباس من غير علامات تنصيص.
- `</q>` — **الوسم الختامي** إجباري.

## use

- لجملة أو عبارة قصيرة منقولة جوه فقرة.
- لنقل كلام شخص في سياق الجملة.
- لعناوين أو شعارات اتقالت قبل كده.

## avoid

- متكتبش علامات التنصيص بإيدك.
- متستخدمهوش لاقتباس طويل: `<blockquote>`.
- متستخدمهوش للتأكيد أو التزيين.
- متحطش `<q>` على كلامك أنت.

## attributes

### cite
رابط (URL) لمصدر الاقتباس. المتصفح مش بيعرضه، لكنه بيتخزن في الـ DOM.

```html nolive
<q cite="https://example.com/quote">اقتباس</q>
```

### lang
لغة الاقتباس: بتتحكم في علامات التنصيص.

```html nolive
<q lang="fr">Bonjour</q>
```

### class
للتنسيق.

## examples

### 1) أبسط q
علامات التنصيص أوتوماتيك.

```html
<p>قال المعلم: <q>الصبر مفتاح الفرج</q>.</p>
```

- المتصفح أضاف علامات التنصيص قبل وبعد النص.
- لو شلت `<q>` العلامات هتختفي.
- مش لازم تكتبها بنفسك.

### 2) اختلاف حسب اللغة
نفس العنصر، علامات مختلفة.

```html
<p lang="ar"><q>مرحباً</q></p>
<p lang="en"><q>Hello</q></p>
<p lang="fr"><q>Bonjour</q></p>
<p lang="de"><q>Hallo</q></p>
```

- كل لغة بتستخدم علامات مختلفة (« » و “ ” و « » و „ “).
- ده بيتحدد بخاصية `lang` على العنصر أو الأب.

### 3) تغيير العلامات بالـ CSS
اختار الشكل اللي تعوزه.

```html
<style>
  q { quotes: "«" "»" "‹" "›"; color: #0ea5e9; }
</style>
<p>قال: <q>الكلام <q>الداخلي</q> هنا</q>.</p>
```

- أول زوج من العلامات للمستوى الخارجي، والتاني للداخلي.
- لازم يبقى فيه قيمتين على الأقل لكل مستوى.

### 4) q مع cite
نسب المصدر.

```html
<p>
  <q cite="https://example.com/speech">لدي حلم</q>
  عبارة شهيرة من خطاب مارتن لوثر كينج.
</p>
```

- الـ `cite` مخزّن في الـ DOM لكن مش ظاهر.
- لو عايز مصدر ظاهر استخدم `<a>` أو `<cite>`.

### 5) اقتباس متداخل
`<q>` جوه `<q>`.

```html
<p>قال: <q>سمعته بيقول <q>مش هروح</q> ومشي.</q></p>
```

- المتصفح بيستخدم علامات مختلفة للمستوى الداخلي أوتوماتيك.
- ده بيوضّح قوة العنصر مقارنة بكتابة العلامات يدوياً.

## rules

- parents: أي عنصر بيقبل **Phrasing content**.
- children: **Phrasing content**.
- closing: الوسم الختامي `</q>` إجباري.
- role: `generic`.
- dom: `HTMLQuoteElement`.
- layout: `display: inline`، وعلامات التنصيص من `::before` و`::after`.

## mistakes

### كتابة علامات التنصيص يدوياً
```html bad
<p>قال: <q>"الخيال أهم"</q>.</p>
```
```html good
<p>قال: <q>الخيال أهم</q>.</p>
```
ليه؟ المتصفح بيضيف العلامات، فهتبقى مكررة.

### q لاقتباس طويل
```html bad
<p><q>فقرة طويلة جداً من كتاب فيها كلام كتير…</q></p>
```
```html good
<blockquote><p>فقرة طويلة جداً من كتاب…</p></blockquote>
```
ليه؟ الاقتباس الطويل `<blockquote>`.

### q للتزيين
```html bad
<p>الكورس <q>مجاني</q> للأبد.</p>
```
```html good
<p>الكورس «مجاني» للأبد.</p>
```
ليه؟ مفيش اقتباس فعلي هنا.

## a11y

- بعض قارئات الشاشة بتنطق علامات التنصيص، وبعضها لأ (لأنها من CSS).
- حدد `lang` صح عشان العلامات والنطق يبقوا مضبوطين.
- لو مهم إن القارئ يعرف إنه اقتباس، اكتب «قال فلان:» قبله.

## tips

- متكتبش علامات التنصيص: سيب المتصفح.
- اضبط `quotes` في CSS للتحكم الكامل.
- ضبط `lang` على الصفحة كلها مرة واحدة.
