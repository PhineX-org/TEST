## intro

الـ **Ruby** هي طريقة تكتب بيها **تلميح نطق** صغير فوق أو جنب حروف (زي الكانجي اليابانية والهانزي الصينية). في HTML: العنصر [[ruby]] بيلف الحرف الأساسي، و[[rt]] بيكتب التلميح، و[[rp]] بيعرض أقواس لو المتصفح مش بيدعم ruby. وكان فيه مقترح إن **الحرف الأساسي** نفسه يتلف في `<rb>`.

لكن HTML5 قررت إن `<rb>` **مش لازم**: الحرف الأساسي بيتكتب **مباشرة** جوه `<ruby>` قبل `<rt>`. فاتشال `<rb>` من المعيار، رغم إن بعض المتصفحات بتعامله كعنصر `ruby-base`. فمتحطوش، وخلّي النص الأساسي من غير `<rb>`.

> [!warn] ده عنصر قديم، اتجنّبه في الكود الجديد واستخدم البديل الحديث.

> [!key] `<rb>` مش ضروري. اكتب الحرف الأساسي مباشرة جوه `<ruby>` قبل `<rt>`.

## try

```html
<ruby><rb>漢</rb><rt>kan</rt><rb>字</rb><rt>ji</rt></ruby>
```

## syntax

```html nolive
<ruby>
  <rb>漢</rb><rt>kan</rt>
</ruby>
```

- `<rb>` — **النص الأساسي** (قديم).
- `<rt>` — **تلميح النطق**.
- بيتحطوا جوه `<ruby>`.

## use

- لفهم كود Ruby قديم أو من مواصفات مسودة.

## avoid

- متستخدمهوش: اكتب النص مباشرة جوه ruby.

## instead

اكتب النص الأساسي مباشرة جوه [[ruby]] وبعده [[rt]]، ولو عايز بديل للمتصفحات اللي مش بتدعم استخدم [[rp]] حوالين التلميح.

```html
<ruby>漢<rt>kan</rt>字<rt>ji</rt></ruby>
```

## examples

### 1) rb مقابل الحديث
نفس المعنى.

```html
<p>القديم: <ruby><rb>東</rb><rt>tou</rt></ruby></p>
<p>الحديث: <ruby>東<rt>tou</rt></ruby></p>
```

- النتيجة نفس الشكل: النطق فوق الحرف.
- في الحديث الحرف مباشرة بدون `<rb>`.
- اتشال `<rb>` من المعيار.

### 2) تلميح بأقواس احتياطية
rp.

```html
<ruby>
  明日 <rp>(</rp><rt>ashita</rt><rp>)</rp>
</ruby>
```

- `<rp>` بيظهر الأقواس لو المتصفح مش بيدعم ruby.
- المتصفحات الحديثة بتخفي الأقواس وتعرض التلميح فوق.
- ده الأسلوب المعتمد.

### 3) أكتر من حرف
كل حرف ليه تلميحه.

```html
<ruby>
  日<rt>ni</rt>本<rt>hon</rt>語<rt>go</rt>
</ruby>
```

- كل حرف بعده `<rt>` يخصه.
- ممكن تعمل نطق لكلمة كاملة بعد مجموعة حروف.
- مفيش داعي لـ `<rb>` خالص.

## mistakes

### لف الحرف الأساسي بـ rb
```html bad
<ruby><rb>字</rb><rt>ji</rt></ruby>
```
```html good
<ruby>字<rt>ji</rt></ruby>
```
ليه؟ `<rb>` مش في المعيار الحالي، والنص الأساسي بيتكتب مباشرة.
