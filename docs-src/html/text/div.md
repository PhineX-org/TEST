## intro

عنصر `<div>` (اختصار **Division** يعني «قسم») هو **صندوق كرتون فاضي**. مفيش له أي شكل أو معنى لوحده: لو كتبت `<div>مرحباً</div>` من غير أي ستايل، الناتج بيبان زي نص عادي بالظبط. فايدته الحقيقية إنه **بيجمّع** عناصر مع بعض في مكان واحد، عشان بعد كده تقدر تنسّق المجموعة دي كلها (بالـ CSS) أو تتحكم فيها (بالجافاسكربت) كوحدة واحدة.

هو عنصر **Block**: يعني بياخد عرض السطر كله وبينزل في سطر جديد قبله وبعده، حتى لو الكلام اللي جواه قليل. لو عايز تفهم الفرق بين Block و Inline اقرا [[block-inline]]. وبيقبل جواه تقريباً أي حاجة: نص، صور، فقرات، عناوين، وكمان `<div>` تانية (وده اللي بيخلّي الصفحات عبارة عن علب جوه علب).

السؤال المهم: **إمتى أستخدمه؟** القاعدة الذهبية: استخدمه لما **مفيش عنصر تاني يعبّر عن المعنى**. لو اللي جواه «رأس الصفحة» فاستخدم `<header>`. لو «قائمة تنقل» فاستخدم `<nav>`. لو «مقال» فاستخدم `<article>`. أما لو محتاج صندوق بس عشان تنسّق أو تظبّط الشكل، فهنا `<div>` هو الاختيار الصح. لو بتستخدم `<div>` في كل حتة تقريباً، ده بنسميه **"div soup"** (شوربة الـ div) وبيخلّي الصفحة صعبة الفهم لقارئات الشاشة ومحركات البحث. اقرا [[semantic-html]] للتفصيل.

حاجة أخيرة: لو محتاج حاوية **جوه السطر** (جوه جملة مثلاً) استخدم `<span>` بدل `<div>`، لأن الـ `<div>` هيكسر السطر.

> [!analogy] تخيّل علب كرتون في مخزن. العلبة الفاضية مالهاش معنى، لكن لما تكتب عليها «ملابس شتوي» وتحط فيها حاجات، بتبقى مفيدة. الـ `<div>` هو العلبة، والـ `class` اللي بتكتبه عليه هو اللصاقة.

> [!key] الـ `<div>` = **صندوق بدون معنى**. لو فيه عنصر بيعبّر عن المعنى (header, nav, section, article, footer...) استخدمه الأول.

## try

غيّر الألوان أو ضيف `<div>` جديد جوه الصندوق الكبير. لاحظ إن كل `<div>` بياخد سطر لوحده.

```html
<div style="border: 3px solid #1565c0; padding: 10px;">
  <div style="background: #bbdefb; padding: 6px;">
    صندوق صغير 1
  </div>
  <div style="background: #c8e6c9; padding: 6px; margin-top: 6px;">
    صندوق صغير 2
  </div>
</div>
```

## syntax

```html nolive
<div class="card" id="box1">
  <h2>عنوان</h2>
  <p>فقرة جوه الصندوق.</p>
</div>
```

- `<div ...>` — **الوسم الافتتاحي**: بيفتح الصندوق. بنضيف عليه غالباً `class` أو `id`.
- المحتوى — أي عناصر تانية، حتى `<div>` تانية.
- `</div>` — **الوسم الختامي**: لازم تكتبه عشان الصندوق يقفل.

## use

- لتجميع مجموعة عناصر عشان تنسّقها كلها مع بعض (كارت، صندوق، حاوية).
- لعمل تخطيط (Layout) بالـ CSS زي Grid و Flexbox، حيث الـ `<div>` هو عنصر الحاوية.
- لما محتاج تلف عنصر عشان تستهدفه بالجافاسكربت.
- لما مفيش عنصر دلالي أنسب (مثلاً صندوق ديكور بحت).
- لأي مكون بتبنيه من أجزاء كتير (مودال، قائمة منسدلة، سلايدر).

## avoid

- متستخدمهوش مكان `<header>` و `<nav>` و `<main>` و `<footer>` و `<section>` و `<article>`: دول بيدّوا معنى.
- متستخدمهوش مكان `<p>` للنصوص: الفقرة ليها عنصرها.
- متستخدمهوش مكان `<ul>` للقوائم أو `<table>` للجداول.
- متحطهوش جوه `<p>`: غير صالح، المتصفح هيقفل الفقرة قبله.
- لا تعمل تداخل عميق أوي من غير داعي (10 مستويات div)، هيخلّي الكود مش مفهوم.
- لو محتاج حاجة جوه السطر استخدم `<span>`.

## attributes

عنصر `<div>` ما ليهوش خصائص خاصة بيه، لكنه بيقبل **الخصائص العامة** (راجع [[global-attributes]])، وأهمهم ليه:

### class
اسم (أو أسماء) بنسمّي بيها الصندوق عشان ننسّقه بالـ CSS. ممكن نسمّي أكتر من عنصر بنفس الاسم.

```html nolive
<div class="card featured">...</div>
```

### id
اسم **فريد** في الصفحة كلها للصندوق، بنستخدمه للقفز له بالروابط أو الوصول له بالجافاسكربت.

```html nolive
<div id="comments">...</div>
```

### style
تنسيق مباشر على الصندوق (Inline). بيتنصح تستخدم `class` وملف CSS بدله في المشاريع الحقيقية.

### data-*
خصائص مخصصة بتخزّن بيانات على الصندوق، وتقراها الجافاسكربت. زي `data-id="42"`.

### align {deprecated}
كانت بتحدد محاذاة المحتوى (`left`, `center`, `right`). **قديمة**: استخدم CSS (`text-align` أو Flexbox).

## examples

### 1) أبسط div
الصندوق من غير ستايل مش بيبان. ده بيوريك إنه بيتصرف كنص عادي، بس كل `<div>` بينزل في سطر.

```html
<div>الصندوق الأول</div>
<div>الصندوق التاني</div>
<div>الصندوق التالت</div>
```

- كل `<div>` في سطر جديد لأنه Block.
- لاحظ إننا ما حطّيناش ستايل، فمفيش شكل مميز.

### 2) نخلّي الصناديق باينة
بنستخدم ستايل صغير عشان نشوف حدود كل صندوق.

```html
<style>
  .box { border: 2px dashed #e65100; padding: 8px; margin: 6px 0; }
</style>
<div class="box">أنا div</div>
<div class="box">وأنا div تاني</div>
```

- `class="box"` مجرد اسم، و `.box` في الستايل بيختار كل عنصر عليه الاسم ده.
- الـ `<div>` ياخد عرض الصفحة كله، لاحظ إن الحدود بتمتد على عرض المعاينة.

### 3) div جوه div
الصناديق ممكن تتداخل. الصندوق الخارجي بيحتوي الداخلي.

```html
<style>
  .outer { background: #e3f2fd; padding: 12px; }
  .inner { background: #fff59d; padding: 10px; margin-top: 8px; }
</style>
<div class="outer">
  الصندوق الخارجي
  <div class="inner">الصندوق الداخلي</div>
</div>
```

- الداخلي جزء من الخارجي. لو غيّرت خلفية الخارجي هيتغيّر اللي حواليه بس.
- ده الأساس اللي بنبني منه التصميمات المعقدة.

### 4) كارت بسيط (مثال عملي)
أشهر استخدام: كارت (بطاقة منتج أو مقال) فيه صورة وعنوان ووصف.

```html
<style>
  .card { width: 240px; border: 1px solid #ccc; border-radius: 10px;
          padding: 12px; font-family: sans-serif; }
  .card h3 { margin: 0 0 6px; }
  .card .price { color: #2e7d32; font-weight: bold; }
</style>
<div class="card">
  <h3>كتاب HTML</h3>
  <p>كتاب للمبتدئين بالعربي.</p>
  <div class="price">50 جنيه</div>
</div>
```

- الصندوق الرئيسي `.card` بيجمّع العنوان والفقرة والسعر.
- السعر جوه `<div>` عشان ياخد سطر لوحده ونحط له ستايل.

### 5) تخطيط عمودين بـ Flexbox
`<div>` هو اللي بيتحط عليه التخطيط. هنا حاوية بتقسّم محتواها لعمودين.

```html
<style>
  .row { display: flex; gap: 10px; }
  .col { flex: 1; padding: 10px; color: white; }
  .a { background: #1976d2; }
  .b { background: #388e3c; }
</style>
<div class="row">
  <div class="col a">العمود الأول</div>
  <div class="col b">العمود التاني</div>
</div>
```

- `.row` هو الحاوية الأب، و `.col` الأبناء.
- `display: flex` على الأب بيرتب الأبناء جنب بعض بدل فوق بعض.

### 6) div مع جافاسكربت
`<div>` ممكن نوصله بالـ `id` ونغيّر محتواه.

```html
<div id="msg" style="padding:10px;background:#eee">قبل الضغط</div>
<button onclick="document.getElementById('msg').textContent='اتغيّرت!'">
  غيّر
</button>
```

- `getElementById('msg')` بيجيب الـ `<div>` من خلال الـ `id` بتاعه.
- `textContent` بيغيّر النص اللي جواه.

### 7) div soup مقابل Semantic
نفس الصفحة مرتين: مرة بـ div بس (مش واضحة المعنى) ومرة بعناصر دلالية.

```html nolive
<!-- div soup: مفيش معنى -->
<div class="header">...</div>
<div class="nav">...</div>
<div class="main">...</div>
<div class="footer">...</div>

<!-- Semantic: كل عنصر بيقول هو إيه -->
<header>...</header>
<nav>...</nav>
<main>...</main>
<footer>...</footer>
```

- النسخة التانية مفهومة لقارئ الشاشة ومحرك البحث من غير أي class.

## rules

- parents: أي عنصر بيقبل **Flow content** زي `<body>` و `<div>` و `<section>` و `<li>` و `<td>`. (جوه `<dl>` مسموح كمان كحاوية لـ `<dt>` و `<dd>`.)
- children: أي Flow content: نص، `<p>`، `<h1>`، `<img>`، `<div>` تانية... تقريباً أي حاجة.
- closing: الوسم الختامي `</div>` إجباري.
- role: `generic` (من غير دور خاص).
- dom: `HTMLDivElement`.
- layout: `display: block` (بياخد عرض السطر كله).

## mistakes

### div جوه p
```html bad
<p>
  فقرة
  <div>صندوق جواها</div>
</p>
```
```html good
<div>
  <p>فقرة</p>
  <div>صندوق</div>
</div>
```
ليه؟ الـ `<p>` مينفعش يحتوي `<div>` (Block جوه فقرة). المتصفح بيقفل الفقرة لوحده وبيطلع كود مش زي ما كتبته.

### استخدام div لكل حاجة
```html bad
<div class="title">عنوان المقال</div>
<div class="text">نص المقال</div>
```
```html good
<h1>عنوان المقال</h1>
<p>نص المقال</p>
```
ليه؟ العناوين والفقرات ليها عناصرها اللي بتوصّل المعنى. استخدم `<div>` لما مفيش بديل.

### نسيان وسم الإغلاق
```html bad
<div class="card">
  <p>نص</p>
<div class="card">
  <p>نص 2</p>
</div>
```
```html good
<div class="card">
  <p>نص</p>
</div>
<div class="card">
  <p>نص 2</p>
</div>
```
ليه؟ من غير `</div>` المتصفح هيعتبر التاني جوه الأول، وتخطيطك هيبوّظ.

## a11y

- الـ `<div>` من غير دور (role) مش بيقول حاجة لقارئ الشاشة. لو بتعمل عنصر تفاعلي (زرار) بـ div، استخدم `<button>` الأصلي بدل ما تعمل زرار من div.
- لو لازم تستخدم `<div>` كمنطقة معينة، ضيف `role` و `aria-label` مناسبين. لكن الأفضل عنصر دلالي.
- متحطش محتوى مهم جوه div مخفي بـ `display: none` لو عايز قارئ الشاشة يقراه.

## tips

- لو بتكتب `<div class="header">` استبدلها فوراً بـ `<header>`.
- سمّي الـ classes حسب **الوظيفة** (`card`, `price`) مش الشكل (`red-box`, `big-blue`).
- افتح DevTools وفعّل شكل الـ outline عشان تشوف كل div بحدوده.
- أول سؤال تسأله لنفسك قبل كل `<div>`: «هل فيه عنصر بيعبّر عن اللي أنا بعمله؟».

## quiz

### إيه أنسب استخدام لـ `<div>`؟
- [ ] عنوان رئيسي في الصفحة
- [x] تجميع عناصر عشان نظبّط شكلها أو مكانها لما مفيش عنصر أنسب
- [ ] فقرة نص
- [ ] قائمة نقاط
الـ `<div>` حاوية عامة من غير معنى، فبنستخدمه للتجميع لما مفيش عنصر دلالي مناسب.

### أي الجمل صح عن `<div>`؟
- [ ] هو Inline وبيمشي مع النص
- [x] هو Block وبياخد عرض السطر كله
- [ ] مينفعش يتحط جوه div تانية
- [ ] بيحتاج وسم افتتاحي بس
الـ `<div>` عنصر Block، ولازم له وسم إغلاق، وممكن يتحط جوه div تانية.

### إيه اللي المفروض تستخدمه بدل `<div class="footer">`؟
- [ ] `<span>`
- [x] `<footer>`
- [ ] `<p>`
- [ ] `<b>`
`<footer>` عنصر دلالي بيعبّر عن تذييل الصفحة، وده أحسن من div عادي.
