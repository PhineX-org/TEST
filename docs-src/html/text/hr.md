## intro

بتقرا قصة، وفجأة الكاتب بيحط سطر فاضي وبعدين نجمتين `***` وبعدين يكمل بمشهد تاني في مكان تاني. العلامة دي بتقولك «هنا الموضوع أو المشهد اتغيّر». ده بالظبط اللي بيعمله `<hr>` (اختصار **Horizontal Rule**، وفي المواصفات الحديثة اسمه **Thematic Break**، يعني فاصل بين مواضيع).

الـ `<hr>` عنصر **فارغ (Void)**: مفيش جواه محتوى ومفيش وسم إغلاق. بتكتبه `<hr>` وبس، والمتصفح بيرسم خط أفقي عريض عرض الصندوق اللي هو فيه، وفيه مسافة فوقه وتحته.

أهم حاجة تعرفها: `<hr>` عنصر **دلالي**، يعني ليه معنى: «تغيّر في الموضوع». مش بنستخدمه عشان الشكل بس. لو عايز خط للزينة (خط تحت عنوان مثلاً) استخدم `border-bottom` في CSS. ولو عايز تفصل بين أقسام كبيرة في الصفحة، استخدم `<section>` أو العناوين `<h2>`، والـ `<hr>` للتغيّر الصغير جوه المحتوى (مشهد جديد في قصة، أو فاصل بين فقرات من مواضيع مختلفة).

> [!analogy] تخيّل شريط فيديو بيتنقل من مشهد لمشهد، وبيطلع شاشة سودا لثانية بين المشهدين. الشاشة السودا دي مش مشهد، هي إشارة إن «في تغيير». ده الـ `<hr>`.

> [!key] `<hr>` = **فاصل معنوي** بين مواضيع. لو عايز خط للزينة بس: استخدم CSS.

## try

جرّب تغيّر شكل الخط (لون وسُمك) بـ `style`، وجرّب تشيل `<hr>` وشوف إزاي المواضيع بتلزق في بعض.

```html
<p>كان في يوم من الأيام ولد اسمه كريم بيحب البرمجة.</p>
<hr>
<p>بعد عشر سنين، بقى كريم مبرمج كبير في شركة عالمية.</p>
<hr style="border: 0; border-top: 3px dashed #39ff14;">
<p>وفي يوم قرر يعلّم الناس مجاناً.</p>
```

## syntax

```html nolive
<p>الموضوع الأول</p>
<hr>
<p>الموضوع التاني</p>
```

- `<hr>` — عنصر **فارغ**: مفيش محتوى ولا وسم إغلاق.
- بيتحط **بين** عناصر Block (فقرات، أقسام)، مش جوه جملة.
- الكتابة `<hr />` شغالة برضه لكنها مش مطلوبة.

## use

- للفصل بين مشهدين أو موضوعين مختلفين جوه نفس المقال أو القصة.
- للفصل بين فقرتين اتغيّر بينهم الموضوع بشكل واضح.
- كفاصل بين مقدمة وباقي المحتوى أو بين محتوى وتذييل داخل مقال.
- في صفحات النص البسيط اللي مفيهاش تصميم كتير (تقارير، ملاحظات).

## avoid

- متستخدمهوش للزينة بس: استخدم `border` في CSS.
- متحطهوش بين كل فقرة وفقرة: هيبوّظ القراءة ويفقد معناه.
- متستخدمهوش مكان العناوين: لو بدأت قسم جديد، اكتب `<h2>` أو `<section>`.
- متستخدمهوش لعمل مسافة: استخدم `margin`.

## attributes

مالوش خصائص خاصة معتمدة، بيقبل الخصائص العامة ([[global-attributes]]) زي `class` و `style`.

### align {deprecated}
كانت بتحدد محاذاة الخط (`left` أو `center` أو `right`). **قديمة**: استخدم `margin` في CSS.

### color {deprecated}
كانت بتحدد لون الخط. **قديمة**: استخدم `border-color` أو `background` في CSS.

### noshade {deprecated}
كانت بتشيل الظل من الخط. **قديمة**: التحكم في الشكل صار بالـ CSS.

### size {deprecated}
كانت بتحدد سُمك الخط بالبكسل. **قديمة**: استخدم `height` أو `border-width` في CSS.

### width {deprecated}
كانت بتحدد عرض الخط. **قديمة**: استخدم `width` في CSS.

## examples

### 1) أبسط hr
فاصل بين فقرتين.

```html
<p>الفقرة الأولى عن موضوع مختلف تماماً.</p>
<hr>
<p>الفقرة التانية بتبدأ موضوع جديد.</p>
```

- الخط بياخد عرض الصندوق كله وفيه مسافة فوقه وتحته.

### 2) تغيير شكل الخط
الشكل الافتراضي بيختلف من متصفح لمتصفح، فبنظبطه بالـ CSS.

```html
<style>
  hr.neon {
    border: 0;
    height: 2px;
    background: linear-gradient(90deg, transparent, #39ff14, transparent);
  }
</style>
<p>فوق الخط</p>
<hr class="neon">
<p>تحت الخط</p>
```

- بنشيل الـ border الافتراضي ونعمل خط بتدرّج لوني.

### 3) فاصل بنجوم (زي الكتب)
نغيّر شكل الخط لنقط أو نجوم.

```html
<style>
  hr.stars { border: 0; text-align: center; overflow: visible; height: auto; }
  hr.stars::before { content: "* * *"; font-size: 20px; letter-spacing: 8px; color: #888; }
</style>
<p>انتهى المشهد الأول.</p>
<hr class="stars">
<p>بدأ المشهد التاني.</p>
```

- نفس العنصر ونفس المعنى، بس الشكل اتغيّر بالـ CSS.

### 4) hr جوه مقال
بين أجزاء المقال لو الموضوع اتغيّر.

```html
<article>
  <h2>رحلتي مع البرمجة</h2>
  <p>بدأت أتعلم HTML من سنتين.</p>
  <hr>
  <p>النهاردة بقيت بدرّس للمبتدئين.</p>
</article>
```

- الـ `<hr>` جوه `<article>` بيفصل بين فترتين زمنيتين.

### 5) hr مش بديل للعنوان
لو القسم له اسم، اكتب عنوان مش خط.

```html
<h2>أولاً: المقدمة</h2>
<p>كلام المقدمة.</p>

<h2>ثانياً: التفاصيل</h2>
<p>كلام التفاصيل.</p>
```

- العناوين بتدّي اسم للقسم وبتفيد التنقل بقارئ الشاشة، والخط لوحده لأ.

### 6) hr في القائمة؟ لأ
الـ `<hr>` ما ينفعش يتحط جوه `<ul>` مباشرةً.

```html
<ul>
  <li>عنصر 1</li>
  <li>عنصر 2</li>
</ul>
<hr>
<ul>
  <li>عنصر 3</li>
</ul>
```

- حطيناه بين قائمتين مش جوه القائمة.

## rules

- parents: أي عنصر بيقبل **Flow content** (زي `<body>` و `<div>` و `<section>` و `<article>` و `<main>`)، وكمان جوه `<select>` (لفصل مجموعات الخيارات).
- children: مفيش (Void).
- closing: مفيش وسم إغلاق.
- role: `separator`.
- dom: `HTMLHRElement`.
- layout: `display: block`، بياخد عرض الأب.

## mistakes

### استخدام hr للزينة
```html bad
<h1>مرحباً</h1>
<hr>
<h2>كورس HTML</h2>
<hr>
<p>الكلام</p>
<hr>
```
```html good
<style>
  h1 { border-bottom: 2px solid #39ff14; }
</style>
<h1>مرحباً</h1>
<h2>كورس HTML</h2>
<p>الكلام</p>
```
ليه؟ الـ `<hr>` ليه معنى («تغيير موضوع»)، فاستخدامه للزينة بيلخبط قارئ الشاشة.

### وسم إغلاق
```html bad
<hr></hr>
```
```html good
<hr>
```
ليه؟ `<hr>` عنصر فارغ مالوش وسم إغلاق.

### الاعتماد على الخصائص القديمة
```html bad
<hr width="50%" color="red" size="3">
```
```html good
<hr style="width: 50%; border: 0; border-top: 3px solid red;">
```
ليه؟ `width` و `color` و `size` و `align` و `noshade` قديمة. الأحدث والأضمن CSS.

## a11y

- قارئات الشاشة بتعلن `<hr>` كـ «فاصل» (separator)، فاستخدمه بس لو الفاصل ليه معنى.
- لو استخدمته للزينة، فكّر تخبّيه من قارئ الشاشة بـ `aria-hidden="true"` أو الأفضل: استبدله بـ border.
- متعتمدش على الخط لوحده في توصيل تغيّر الموضوع: اكتب عنوان لو القسم مهم.

## tips

- لو بتفكر تحط `<hr>`، اسأل: «هل الموضوع فعلاً اتغيّر؟». لو لأ، شيله.
- لو عايز تغيّر شكله استخدم `border` أو `height` و `background`.
- في الموبايل، خط بسيط ورفيع أنسب من خط تخين.
- `<hr>` جوه `<select>` بيفصل بين مجموعات الخيارات (متاح في المتصفحات الحديثة).
