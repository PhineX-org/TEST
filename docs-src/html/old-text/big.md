## intro

كان فيه في HTML القديم عناصر **تنسيق بحتة** زي `<big>` (بيكبّر الخط) و`<small>` (بيصغّر الخط) و`<tt>` (خط آلة كاتبة). الفكرة كانت «اكتب شكل النص بالوسم». لكن HTML اتغيّرت فلسفتها: الوسوم بتوصف **المعنى**، والـ CSS بيوصف **الشكل**. عشان كده `<big>` اتحذف من HTML5.

المتصفحات لسه بتعرضه (بيعمل `font-size: larger`)، لكن مفيش سبب تستخدمه. لو عايز نص أكبر: `font-size` في CSS. ولو عايز تبرز أهمية: `<strong>`. ولو عنوان: `<h1>`–`<h6>`. وملاحظة: `<small>` لسه موجود في HTML5 لكن بمعنى مختلف (نص جانبي مثل الحقوق).

> [!warn] ده عنصر قديم، اتجنّبه في الكود الجديد واستخدم البديل الحديث.

> [!key] `<big>` = `font-size: larger`. استخدم CSS بدل العنصر.

## try

```html
<p>ده نص عادي و<big>ده نص كبير</big> جواه.</p>
```

## syntax

```html nolive
<big>نص أكبر</big>
```

- `<big>` — **الوسم الافتتاحي** (قديم).
- النص — **المحتوى** بيتكبّر درجة.
- `</big>` — **الوسم الختامي**.

## use

- موجود في كود قديم محتاج تفهمه.
- للتعرّف على تاريخ تنسيق HTML.

## avoid

- متستخدمهوش: تنسيق بالـ CSS، والمعنى بعناصر دلالية.

## instead

استخدم CSS للشكل: `font-size`. ولو الغرض أهمية، استخدم `<strong>`، ولو عنوان استخدم عناصر العناوين.

```html
<style>.big { font-size: 1.4em; }</style>
<p>ده نص عادي و<span class="big">ده نص كبير</span> جواه.</p>
```

## examples

### 1) big مقابل CSS
نفس الأثر.

```html
<p>القديم: <big>نص كبير</big></p>
<p style="font-size:1.2em">الحديث: <span style="font-size:1.2em">نص كبير</span></p>
```

- `<big>` بيكبّر النص خطوة واحدة (`larger`).
- بـ CSS بتتحكم في الحجم بالظبط (`1.2em` أو `20px`).
- الـ CSS أدق وأسهل في التعديل من مكان واحد.

### 2) تكبير بحسب المعنى
strong وh2 بدل big.

```html
<h2>عنوان مهم</h2>
<p>لازم تنتبه لـ <strong>النقطة دي</strong> كويس.</p>
```

- العنوان الحقيقي `<h2>` بدل نص كبير بالإيد.
- `<strong>` بيبرز الأهمية ومعناه مفهوم لقارئ الشاشة.
- الحجم الافتراضي بيختلف حسب العنصر، وتغيّره بـ CSS لو حبيت.

## mistakes

### تكبير النص بـ big في عنوان
```html bad
<big>عنوان الصفحة</big>
```
```html good
<h1>عنوان الصفحة</h1>
```
ليه؟ العنوان لازم يبقى عنصر عنوان حقيقي، مش نص مكبّر.
