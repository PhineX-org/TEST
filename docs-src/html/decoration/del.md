## intro

لو استخدمت Word أو Google Docs وفعّلت «تتبع التغييرات» (Track Changes)، بتلاقي اللي اتحذف ظاهر بخط في النص، واللي اتضاف ظاهر بخط تحت. ده نفس فكرة `<del>` و`<ins>` في HTML: توثيق **تعديلات** في مستند. الـ `<del>` معناه «ده كان موجود واتشال».

الفرق الجوهري بينه وبين `<s>`: الـ `<s>` معلومة **ماعادتش صحيحة** (سعر قديم، عرض خلص) من غير ما يكون في تعديل موثّق. أما `<del>` فبيعبّر عن **عملية حذف** حصلت في المستند (نسخة قبل وبعد). مثلاً في مقال اتعدّل فيه موعد: «الاجتماع ~~الأحد~~ الإثنين».

وفيه خصائص بتوثّق التعديل: `cite` (رابط يشرح سبب التعديل) و`datetime` (إمتى اتحذف). للأسف المتصفحات **مش بتعرضهم** للمستخدم، لكن أدوات تانية (وزحف محركات البحث وأدوات القراءة) بتقدر تستخدمهم.

وفيه حاجة مميزة: `<del>` و`<ins>` عناصر **شفّافة** (Transparent)، يعني ينفع تلف بيهم مجموعة عناصر Block (فقرات مثلاً) طالما الأب بيقبل ده. فتقدر تعلّم على حذف فقرة كاملة أو كلمة.

> [!analogy] تخيّل معلم بيصحّح ورقة بقلم أحمر: بيشطب الكلمة الغلط وبيكتب الصح فوقها. الشطب هو `<del>` والإضافة هي `<ins>`.

> [!key] `<del>` = نص **اتحذف** في تعديل مستند. للمعلومة المنتهية بدون تعديل: `<s>`.

## try

شوف التعديل: الموعد القديم محذوف والجديد مضاف.

```html
<p>
  الاجتماع يوم <del datetime="2026-10-28">الأحد</del>
  <ins datetime="2026-10-28">الإثنين</ins> الساعة 10.
</p>
```

## syntax

```html nolive
<del cite="https://example.com/why" datetime="2026-10-28">النص المحذوف</del>
```

- `<del>` — **الوسم الافتتاحي**.
- `cite` — اختيارية: رابط يشرح سبب الحذف.
- `datetime` — اختيارية: وقت الحذف.
- `</del>` — **الوسم الختامي** إجباري.

## use

- لتوثيق نص اتشال من مستند.
- مع `<ins>` لإظهار الفرق بين نسخة قديمة وجديدة.
- لتعديلات في مقال بعد النشر (تصحيح).
- لسجلات التغييرات (Changelogs) والمقارنات.

## avoid

- متستخدمهوش للسعر القديم: استخدم `<s>`.
- متستخدمهوش للشكل بس.
- متحذفش معلومة مهمة بدون ما تدّي بديلها.
- متستخدمهوش كبديل لمحرر الدفوقات (Diff) للأكواد.

## attributes

### cite
رابط (URL) لصفحة أو مستند بيشرح **سبب** الحذف. المتصفح مش بيعرضه للمستخدم.

```html nolive
<del cite="https://example.com/fix">كلام غلط</del>
```

### datetime
وقت الحذف بصيغة صالحة (مثلاً `2026-10-28` أو `2026-10-28T10:30:00+03:00`).

```html nolive
<del datetime="2026-10-28T10:30:00+03:00">قديم</del>
```

### class
للتنسيق.

## examples

### 1) أبسط del
كلمة محذوفة.

```html
<p>الموعد <del>الأحد</del> اتغيّر.</p>
```

- الكلمة بتظهر بخط في النص (الشكل الافتراضي).
- بتدل على إن حاجة اتشالت.
- لو مفيش بديل، يفضّل تفسير سبب الحذف.

### 2) del مع ins
الاستخدام الأشهر.

```html
<p>
  السعر: <del>100</del> <ins>80</ins> جنيه.
</p>
```

- الاتنين بيحكوا قصة تعديل: السعر اتغيّر من 100 لـ 80.
- لو مجرد عرض بسعر قديم بدون تعديل مستند، استخدم `<s>`.

### 3) مع datetime وcite
توثيق كامل.

```html
<p>
  <del cite="https://example.com/correction" datetime="2026-10-28">
    ولد نيوتن عام 1700.
  </del>
  <ins datetime="2026-10-28">ولد نيوتن عام 1643.</ins>
</p>
```

- `cite` بيشرح سبب التصحيح، و`datetime` بيحدد إمتى.
- المتصفح مش بيعرضهم، لكن بيتخزنوا في الـ DOM.

### 4) حذف فقرة كاملة
`<del>` بيلف Block.

```html
<del>
  <p>الفقرة دي اتشالت من النسخة الجديدة.</p>
</del>
<ins>
  <p>الفقرة دي هي البديل.</p>
</ins>
```

- لأن `<del>` شفاف، بيقبل `<p>` جواه طالما الأب (هنا body) بيقبل Flow.
- ده بيفرّقه عن `<s>` اللي بيقبل Inline بس.

### 5) تنسيق مخصص
شكل أوضح للتعديلات.

```html
<style>
  del { background: #fee2e2; color: #991b1b; text-decoration: line-through; }
  ins { background: #dcfce7; color: #166534; text-decoration: none; }
</style>
<p>الكورس <del>مدفوع</del> <ins>مجاني</ins>.</p>
```

- لوّنّا المحذوف أحمر والمضاف أخضر زي Git diff.
- ده تنسيق شائع في سجلات التغييرات.

## rules

- parents: أي عنصر بيقبل **Phrasing content**، وكمان **Flow content** لو محتواه Flow (عنصر شفاف).
- children: **Transparent**: نفس نوع محتوى الأب.
- closing: الوسم الختامي `</del>` إجباري.
- role: `deletion`.
- dom: `HTMLModElement`.
- layout: `display: inline`، و`text-decoration: line-through`.

## mistakes

### del للسعر القديم
```html bad
<p>السعر: <del>200</del> 150</p>
```
```html good
<p>السعر: <s>200</s> 150</p>
```
ليه؟ ده سعر قديم مش تعديل مستند، فـ `<s>`.

### del بدون سبب أو بديل
```html bad
<p>الكورس <del>مجاني</del>.</p>
```
```html good
<p>الكورس <del>مدفوع</del> <ins>مجاني</ins>.</p>
```
ليه؟ الحذف من غير بديل يلخبط القارئ.

### datetime بصيغة غلط
```html bad
<del datetime="28/10/2026">قديم</del>
```
```html good
<del datetime="2026-10-28">قديم</del>
```
ليه؟ لازم صيغة ISO (سنة-شهر-يوم).

## a11y

- قارئات الشاشة ممكن تعلن «حذف» أو متعلنش (حسب الإعدادات). ضيف نص مخفي مثل «(محذوف)» لو مهم.
- متعتمدش على اللون وحده في التفرقة بين المحذوف والمضاف.
- `cite` و`datetime` مش بيتعرضوا: لو مهم للمستخدم اكتب التاريخ كنص.

## tips

- استخدم `<del>` و`<ins>` مع بعض دايماً.
- في صفحات الـ Changelog، التنسيق بالألوان بيوضح التغيّرات.
- لو مش محتاج توثّق تعديل، استخدم `<s>`.
