## intro

الـ `<b>` معناه **Bring Attention To**، يعني «لفّت الانتباه ليه». بيخلّي النص **عريض** (Bold) من غير ما يضيف أي معنى زيادة على الكلام. بمعنى تاني: الكلمة مش «أهم» من اللي حواليها، إنت بس عايز عين القارئ تقع عليها بسرعة.

الفرق الجوهري بينه وبين `<strong>`: الـ `<strong>` معناه **أهمية** (جدية أو عاجل أو تحذير)، والـ `<b>` معناه **لفت انتباه بس**. مثال: «**تحذير**: السخان ساخن» الكلمة دي مهمة فتبقى `<strong>`. أما «اشترينا **iPhone 17** و**Galaxy S26**» فأسماء المنتجات عاوزين نلفت النظر ليها بس من غير ما نقول إنها مهمة، فتبقى `<b>`.

استخدامات `<b>` الصح بحسب المواصفة: **الكلمات المفتاحية** في ملخص، **أسماء المنتجات** في مراجعة، **أول جملة** (Lead sentence) في مقال. وكل ده من غير إضافة معنى. ولو عايز ببساطة نص عريض لشكل بس، الأفضل `<span>` مع `font-weight: bold` في CSS (أو class تدّيه معنى زي `<b class="product">`).

ولأن الـ `<b>` مالوش معنى، قارئ الشاشة **مش بيغيّر** نبرة صوته. لو الكلمة مهمة فعلاً، استخدم `<strong>` عشان الأهمية تتوصل.

> [!analogy] تخيّل بتقرا كتاب بقلم تحديد (Highlighter): بتحدد الأسماء والمصطلحات عشان ترجعلها بسرعة. مش لأنها «أهم» من باقي الكلام، لكن لأنها بتلفت عينك. ده `<b>`.

> [!key] `<b>` = لفت انتباه **من غير** أهمية. للأهمية: `<strong>`. للتأكيد: `<em>`.

## try

جرّب تغيّر `<b>` لـ `<strong>` وشوف إن الشكل واحد لكن المعنى مختلف.

```html
<p>
  اشترينا <b>لابتوب Dell</b> و<b>ماوس Logitech</b> للمكتب الجديد.
</p>
```

## syntax

```html nolive
<p>اسم المنتج هو <b>PhineX Pro</b> وهو الأحدث.</p>
```

- `<b>` — **الوسم الافتتاحي**.
- النص — الكلمة أو العبارة اللي عايز تلفت الانتباه ليها.
- `</b>` — **الوسم الختامي** إجباري.

## use

- لأسماء المنتجات أو الأشخاص في مراجعة أو ملخص.
- للكلمات المفتاحية في ملخص أو فهرس.
- لأول جملة في مقال (Lead).
- لما تعوز عرض Bold من غير معنى إضافي.

## avoid

- متستخدمهوش للأهمية أو التحذير: استخدم `<strong>`.
- متستخدمهوش للتأكيد في الكلام: استخدم `<em>`.
- متستخدمهوش للعناوين: استخدم `<h1>` لـ `<h6>`.
- متستخدمهوش للتنسيق العام: استخدم CSS.
- متحطش `<b>` حوالين فقرة كاملة.

## attributes

مالوش خصائص خاصة، بيقبل **الخصائص العامة** ([[global-attributes]]).

### class
أحسن طريقة تدّي `<b>` معنى: `<b class="product">`. بتساعد في التنسيق وفي المعنى.

### lang
لو الكلمة بلغة تانية.

## examples

### 1) أبسط b
كلمة عريضة.

```html
<p>اسمي <b>أحمد</b> وبشتغل مبرمج.</p>
```

- الاسم ظاهر عريض.
- مفيش أهمية إضافية: مجرد لفت انتباه.
- لو حذفت `<b>` الجملة بتفضل بنفس المعنى بالظبط.

### 2) أسماء منتجات في مراجعة
الاستخدام الأشهر.

```html
<p>
  قارنت بين <b>iPhone 17</b> و<b>Galaxy S26</b> ولقيت إن الكاميرا أحسن في التاني.
</p>
```

- أسماء المنتجات بتلفت النظر عشان القارئ يمسح الفقرة بسرعة.
- مش «أهم» من باقي الجملة، لكن مفتاحية.

### 3) أول جملة في مقال
الجملة اللي بتفتح الموضوع.

```html
<article>
  <p><b>الـ HTML هي لغة بناء صفحات الويب.</b> بتتكون من عناصر ووسوم…</p>
</article>
```

- أول جملة بتلخّص المقال، والـ `<b>` بيلفت عين القارئ ليها.
- ده استخدام ذكرته المواصفة صراحةً.

### 4) b مقابل strong
نفس الشكل، معنى مختلف.

```html
<p><b>لفت انتباه</b> فقط.</p>
<p><strong>أهمية حقيقية</strong> وجدية.</p>
```

- الاتنين عريضين في المتصفح.
- لكن `<strong>` بيحمل معنى أهمية يفهمه قارئ الشاشة ومحركات البحث.

### 5) b مع class
بنديله معنى بالـ class.

```html
<style>
  b.kw { color: #0ea5e9; }
</style>
<p>بنتعلم <b class="kw">HTML</b> و<b class="kw">CSS</b> و<b class="kw">JavaScript</b>.</p>
```

- الـ class بيدّي كل الكلمات المفتاحية لون موحّد.
- بنقدر نغيّر شكلهم كلهم من مكان واحد.

### 6) إلغاء الـ bold
ممكن تشيل العرض بالـ CSS.

```html
<style>
  b { font-weight: normal; background: #fef08a; }
</style>
<p>الكلمة <b>دي</b> ليها خلفية بدل العرض.</p>
```

- الـ `<b>` بتتحول لخلفية صفرا بدل الخط العريض.
- المعنى (لفت انتباه) ما اتغيّرش، بس الشكل اتغيّر.

## rules

- parents: أي عنصر بيقبل **Phrasing content**.
- children: **Phrasing content**.
- closing: الوسم الختامي `</b>` إجباري.
- role: `generic`.
- dom: `HTMLElement`.
- layout: `display: inline`، و`font-weight: bolder`.

## mistakes

### b للأهمية
```html bad
<p><b>تحذير:</b> متلمسش السلك الكهربا.</p>
```
```html good
<p><strong>تحذير:</strong> متلمسش السلك الكهربا.</p>
```
ليه؟ التحذير أهمية حقيقية، فمكانه `<strong>`.

### b للعناوين
```html bad
<p><b>مقدمة</b></p>
<p>النص…</p>
```
```html good
<h2>مقدمة</h2>
<p>النص…</p>
```
ليه؟ العنوان لازم عنصر عنوان عشان قارئ الشاشة يعتبره قسم.

### فقرة كاملة بـ b
```html bad
<b>الفقرة كلها في Bold…</b>
```
```html good
<p class="bold">الفقرة كلها Bold…</p>
```
ليه؟ العرض الكتير بيبوّظ القراءة، والتنسيق ده CSS.

## a11y

- قارئ الشاشة بيقرا `<b>` بنفس النبرة العادية: ماتفترضش إنه هيعلن أي تغيير.
- لو الكلمة مهمة فعلاً، استخدم `<strong>`.
- متعتمدش على الـ Bold لوحده في توصيل معلومة مهمة.

## tips

- لو بتفكر تكتب `<b>`، اسأل: «هل ده مهم؟» (`strong`) أو «هل ده تأكيد؟» (`em`) أو «مجرد لفت انتباه؟» (`b`).
- الـ `class` على `<b>` بيخلّي كودك أوضح.
- لو مش لازم الكلمة تبقى عريضة، اعتبر `<span>` مع CSS.
