## intro

الـ `<strong>` معناه **أهمية قوية**. بتستخدمه لما جزء من الكلام يبقى **أهم** من اللي حواليه: تحذير، تعليمة لازم تتنفذ، رقم مهم، أو كلام عاجل. المتصفح بيعرضه عريض (Bold)، لكن الأهم من الشكل هو **المعنى**: إنت بتقول «ركّز هنا، ده مهم».

زي ما اتعلمنا في `<b>`: لو الكلام مجرد «لفت نظر» فـ `<b>`، لكن لو «مهم» فـ `<strong>`. والفرق مش في الشكل، في إن `<strong>` بيحمل معنى بتفهمه محركات البحث والأدوات المساعدة. ورغم إن قارئات الشاشة بتقراه بنفس النبرة في الغالب، لكن بعضها ممكن يعلن عنه حسب الإعدادات.

وفيه حاجة لطيفة: لو حطيت `<strong>` جوه `<strong>` الأهمية **بتزيد**. مثلاً «**لازم** تحفظ الملف **قبل** ما تقفل». وتقدر تستخدمه جوه فقرة كاملة عشان تعلّم إنها كلها مهمة (زي «**تحذير: السخان ساخن**»)، أو على كلمة واحدة.

واتفرق عن `<em>`: الـ `<em>` بيغيّر **معنى الجملة** بحسب أنهي كلمة بتشدّد عليها في النطق («أنا **بحبك**» مش «أنا بحبك **إنت**»)، أما `<strong>` بيقول إن **جزء** من الكلام مهم.

> [!analogy] تخيّل لافتة على الطريق: «**خطر**: منطقة حفر». الكلمة دي مكتوبة بحروف عريضة وحمرا عشان أي حد يلاحظها. ده `<strong>`: أهمية حقيقية مش تزويق.

> [!key] `<strong>` = **أهمية** وجدية (تحذير، عاجل). التأكيد على كلمة = `<em>`. لفت نظر بس = `<b>`.

## try

جرّب تحط `<strong>` جوه `<strong>` وشوف إزاي بيدل على أهمية أكبر.

```html
<p><strong>تحذير:</strong> متفصلش الجهاز أثناء التحديث.</p>
<p>لازم تدخل <strong>قبل</strong> الساعة <strong>10</strong>.</p>
```

## syntax

```html nolive
<p><strong>تحذير:</strong> الملف هيتمسح نهائياً.</p>
```

- `<strong>` — **الوسم الافتتاحي**.
- النص — الجزء المهم.
- `</strong>` — **الوسم الختامي** إجباري.

## use

- للتحذيرات والتنبيهات: «**تحذير**»، «**انتبه**».
- للتعليمات المهمة اللي لازم القارئ ينفذها.
- لكلام عاجل أو بتاريخ نهائي.
- لأرقام أو شروط مهمة في نص.

## avoid

- متستخدمهوش لمجرد التزيين: استخدم `<b>` أو CSS.
- متستخدمهوش في كل جملة: كتر الأهمية بتفقدها قيمتها.
- متستخدمهوش للعناوين.
- متستخدمهوش للتأكيد المنطوق: استخدم `<em>`.

## attributes

مالوش خصائص خاصة، بيقبل **الخصائص العامة** ([[global-attributes]]).

### class
للتنسيق، زي `class="warning"`.

### lang
لو الجزء المهم بلغة مختلفة.

## examples

### 1) تحذير
أشهر استخدام.

```html
<p><strong>تحذير:</strong> الحذف نهائي ومفيش رجوع.</p>
```

- الكلمة «تحذير» أهم من باقي الجملة فبتتعلّم بـ `<strong>`.
- الشكل عريض، والمعنى أهمية.
- لو شلت التنسيق بالـ CSS المعنى يفضل موجود.

### 2) كلمة مهمة في جملة
تعليمة محددة.

```html
<p>اكتب كلمة السر <strong>مرة واحدة فقط</strong> وبعدين اضغط حفظ.</p>
```

- الجملة كلها عادية إلا الجزء المهم.
- القارئ اللي بيمسح الصفحة هيلاحظ الجزء ده بسرعة.

### 3) تداخل لزيادة الأهمية
`<strong>` جوه `<strong>` يعني أهمية أكبر.

```html
<p>
  <strong>ممنوع <strong>تماماً</strong> التدخين.</strong>
</p>
```

- «ممنوع التدخين» مهمة، و«تماماً» أهم جوه الجملة.
- مستويات الأهمية بتتراكم مع التداخل.

### 4) فقرة تحذير كاملة
فقرة بكاملها مهمة.

```html
<style>
  .alert { background: #fee2e2; border-right: 5px solid #dc2626; padding: 10px; }
</style>
<p class="alert"><strong>انتبه: النسخة دي تجريبية وممكن تحتوي أخطاء.</strong></p>
```

- لفّينا نص الفقرة كله بـ `<strong>`، والـ CSS زوّد الشكل بخلفية وخط جانبي.
- الأهمية معنى في الـ HTML، والتلوين شغل CSS.

### 5) strong مع الرابط
ممكن تلف رابط مهم.

```html
<p>للتسجيل <a href="#"><strong>اضغط هنا الآن</strong></a> قبل انتهاء المهلة.</p>
```

- الـ `<strong>` جوه `<a>` بيخلّي نص الرابط مهم.
- الترتيب `<a>` برّه و`<strong>` جواه صحيح.

### 6) تغيير الشكل
المعنى ثابت، الشكل CSS.

```html
<style>
  strong { color: #dc2626; font-weight: 800; }
</style>
<p>الموعد النهائي <strong>الخميس</strong>.</p>
```

- لوّنا الأهمية بالأحمر.
- بتقدر تتحكم في الشكل بدون ما تغيّر المعنى.

## rules

- parents: أي عنصر بيقبل **Phrasing content**.
- children: **Phrasing content**.
- closing: الوسم الختامي `</strong>` إجباري.
- role: `strong`.
- dom: `HTMLElement`.
- layout: `display: inline`، و`font-weight: bolder`.

## mistakes

### strong للتزيين
```html bad
<p><strong>أهلاً</strong> <strong>بيك</strong> <strong>في</strong> <strong>موقعي</strong></p>
```
```html good
<p>أهلاً بيك في <strong>موقعي</strong>.</p>
```
ليه؟ لو كل حاجة مهمة، مفيش حاجة مهمة.

### strong بدل em
```html bad
<p>أنا <strong>مش</strong> قلت كده.</p>
```
```html good
<p>أنا <em>مش</em> قلت كده.</p>
```
ليه؟ ده تأكيد على كلمة في النطق (يغيّر معنى الجملة)، فمكانه `<em>`.

### strong للعنوان
```html bad
<p><strong>الأسئلة الشائعة</strong></p>
```
```html good
<h2>الأسئلة الشائعة</h2>
```
ليه؟ العناوين ليها عناصرها.

## a11y

- بعض قارئات الشاشة ممكن تعلن `<strong>` وبعضها لأ؛ متعتمدش عليه وحده لتحذير حرج.
- لتحذير حرج استخدم `role="alert"` أو نص واضح زي «تحذير:».
- خلّي التباين اللوني كافي لو لوّنت.

## tips

- كل ما قلّلت `<strong>` كل ما بقى أقوى.
- لو التحذير جوه صندوق، استخدم `role="alert"` (للحالات العاجلة) أو `role="note"`.
- الـ `<strong>` و`<b>` بيطلعوا بنفس الشكل: غيّر الشكل بـ CSS مش بتغيير العنصر.
