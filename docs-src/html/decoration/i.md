## intro

الـ `<i>` اتعلّم غالباً على إنه «مائل» (Italic)، وده الشكل اللي بيظهر بيه. لكن معناه الحقيقي في HTML5: **نص بنبرة أو صوت مختلف** عن الكلام اللي حواليه. يعني جزء من الكلام «مختلف» لسبب ما: كلمة بلغة تانية، مصطلح علمي، فكرة داخلية في دماغ شخصية في قصة، اسم سفينة.

أمثلة من المواصفة: **كلمة أجنبية** وسط جملة عربي (بنستخدم `lang`)، **أسماء علمية** للكائنات (*Homo sapiens*)، **مصطلح تقني** بيتعرّف أول مرة، **أفكار** شخصية في رواية («*ياترى هيرد عليا؟*» فكرت سارة»)، أو **أسماء سفن**. كل دول نص مختلف في الصوت أو المزاج.

نفرق بينه وبين `<em>`: الـ `<em>` معناه **تأكيد** (stress) بيغيّر معنى الجملة. الـ `<i>` مفيهوش تأكيد، هو بس نص «مختلف». ولو الكلام «مهم» فـ `<strong>`، ولو «عنوان كتاب» فـ `<cite>`.

وفيه استخدام شائع جداً للـ `<i>` مش مقصود بيه الميل: **الأيقونات** (Font Awesome وغيرها): `<i class="fa fa-home"></i>`. ده عادة قديمة ومنتشرة، لكنها مش الأفضل لأن الأيقونة مش «نص مختلف». لو بتستخدمها، حط `aria-hidden="true"` عليها عشان قارئ الشاشة يتجاهلها.

> [!analogy] تخيّل راوي قصة بيتكلم بصوته العادي، ولما يوصل لفكرة في دماغ البطل، بيغيّر نبرته شوية. التغيير ده هو `<i>`.

> [!key] `<i>` = نص **مختلف** في النبرة (مش تأكيد ولا أهمية). التأكيد: `<em>`. الأهمية: `<strong>`.

## try

جرّب تغيّر `lang` للكلمة الأجنبية أو تضيف مصطلح علمي.

```html
<p>
  قال لي صاحبي إن الحل <i lang="fr">c'est la vie</i> وبعدين ضحك.
</p>
<p>
  اسم الأسد العلمي هو <i>Panthera leo</i>.
</p>
```

## syntax

```html nolive
<p>الكلمة <i lang="en">Hello</i> إنجليزية.</p>
```

- `<i>` — **الوسم الافتتاحي**.
- `lang` — اختيارية: لغة النص لو أجنبي.
- النص — الجزء المختلف.
- `</i>` — **الوسم الختامي** إجباري.

## use

- لكلمات أو عبارات بلغة أجنبية وسط نص (مع `lang`).
- للأسماء العلمية للكائنات الحية.
- لمصطلح تقني عند تعريفه أو أول ذكر.
- لأفكار الشخصيات في الأدب.
- لأسماء السفن والمركبات.

## avoid

- متستخدمهوش للتأكيد: استخدم `<em>`.
- متستخدمهوش للأهمية: استخدم `<strong>`.
- متستخدمهوش لأسماء الكتب والأفلام: استخدم `<cite>`.
- متستخدمهوش للأيقونات إن أمكن: استخدم `<span>` أو `<svg>`.
- متستخدمهوش لمجرد جعل النص مائل: CSS.

## attributes

مالوش خصائص خاصة، بيقبل **الخصائص العامة** ([[global-attributes]]).

### lang
بتحدد لغة النص. مهمة مع الكلمات الأجنبية عشان قارئ الشاشة ينطقها صح.

```html nolive
<i lang="en">Hello</i>
```

### class
لتمييز نوع النص (`class="taxon"`، `class="thought"`).

## examples

### 1) كلمة أجنبية
مع تحديد اللغة.

```html
<p>
  بنقول <i lang="en">Good morning</i> بالإنجليزي و<i lang="fr">bonjour</i> بالفرنساوي.
</p>
```

- `lang` بيخلّي قارئ الشاشة ينطق الكلمة بلغتها.
- الشكل مائل افتراضياً.
- الكلمة غريبة على الجملة العربي فاتعلّمت بـ `<i>`.

### 2) اسم علمي
أسماء الكائنات الحية بتبقى مائلة.

```html
<p>الإنسان الحديث اسمه العلمي <i>Homo sapiens</i>.</p>
```

- الأسماء العلمية قاعدة تقليدية في العلوم تتكتب مائلة.
- الـ `<i>` أنسب من `<em>` لأنه مش تأكيد.

### 3) أفكار شخصية
في رواية أو قصة.

```html
<p>
  بصّت سارة للساعة. <i>ياترى هيجي ولا لأ؟</i> فكّرت وهي بتعدّل الطرحة.
</p>
```

- الفكرة الداخلية صوت مختلف عن السرد.
- الـ `<i>` بيعلّمه من غير ما يقول إنه مهم.

### 4) مصطلح تقني عند تعريفه
أول ذكر للمصطلح.

```html
<p>
  الصفحة بتتبني من <i>عناصر</i> (Elements)، وكل عنصر ليه وسم افتتاحي وختامي.
</p>
```

- الكلمة «عناصر» اتعلّمت لأنها مصطلح جديد.
- لو عايز تعرّفه رسمياً استخدم `<dfn>`.

### 5) أيقونة (استخدام شائع)
مثال لأنماط الأيقونات، مع إخفائها عن قارئ الشاشة.

```html
<style>
  .ico::before { content: "★"; color: #f59e0b; }
</style>
<button><i class="ico" aria-hidden="true"></i> أضف للمفضلة</button>
```

- الأيقونة جاية من CSS (`::before`)، و`aria-hidden="true"` بيخلّي قارئ الشاشة يقرا النص بس.
- ده استخدام شائع، لكن الأفضل `<span>` أو `<svg>` لأن الأيقونة مش «نص مختلف».

### 6) إلغاء الميل
تغيير الشكل بالـ CSS.

```html
<style>
  i.term { font-style: normal; border-bottom: 1px dotted #888; }
</style>
<p>الـ <i class="term">DOM</i> هو تمثيل الصفحة في الذاكرة.</p>
```

- شلنا الميل وحطينا خط منقط تحت المصطلح.
- المعنى (نص مختلف) ما اتغيّرش.

## rules

- parents: أي عنصر بيقبل **Phrasing content**.
- children: **Phrasing content**.
- closing: الوسم الختامي `</i>` إجباري.
- role: `generic`.
- dom: `HTMLElement`.
- layout: `display: inline`، و`font-style: italic`.

## mistakes

### i للتأكيد
```html bad
<p>أنا <i>مش</i> قلت كده.</p>
```
```html good
<p>أنا <em>مش</em> قلت كده.</p>
```
ليه؟ التأكيد المنطوق شغل `<em>`.

### i لعنوان كتاب
```html bad
<p>قرأت <i>مقدمة ابن خلدون</i>.</p>
```
```html good
<p>قرأت <cite>مقدمة ابن خلدون</cite>.</p>
```
ليه؟ عنوان العمل الفني ليه عنصر `<cite>`.

### كلمة أجنبية من غير lang
```html bad
<p>قال <i>Hello</i></p>
```
```html good
<p>قال <i lang="en">Hello</i></p>
```
ليه؟ من غير `lang` قارئ الشاشة هينطق الكلمة بالعربي غالباً.

## a11y

- حدد `lang` للكلمات الأجنبية عشان تتنطق صح.
- الأيقونات المصنوعة بـ `<i>`: حط `aria-hidden="true"` وخلّي نص بديل.
- متعتمدش على الميل لوحده لنقل معنى.

## tips

- لو بتحط أيقونات، اعتبر `<svg>` أو `<span>` بدل `<i>`.
- اسأل: «ده تأكيد؟» (em) «ده مهم؟» (strong) «ده عنوان عمل؟» (cite) «ده مختلف؟» (i).
- الأسماء العلمية والكلمات الأجنبية أنسب مكان للـ `<i>`.
