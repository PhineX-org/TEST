## intro

لما بتكتب الماية في الكيمياء، بتكتب H₂O: الرقم 2 مكتوب **تحت** الخط وبحجم أصغر. ده اسمه **Subscript** (نص منخفض). والعنصر اللي بيعمل ده في HTML هو `<sub>`. بيرفع النص شوية لتحت، وبيصغّره، فيبان زي ما في الكتب.

بنستخدمه في **الصيغ الكيميائية** (H₂O و CO₂ و C₆H₁₂O₆)، و**الرياضيات** (xᵢ و x₁ و x₂ للرموز السفلية)، و**الفهرسة** (a₁ و a₂ في المتتاليات)، وأحياناً في **ملاحظات** سفلية. ولو محتاج رموز معقدة (جذور، كسور، تكامل) استخدم `<math>` (MathML) أو مكتبة زي KaTeX، لأن `<sub>` و `<sup>` مناسبين للبسيط بس.

المهم إن `<sub>` ليه **معنى**: ده مش مجرد شكل، هو بيقول «النص ده بيتعامل كـ subscript حسب تقاليد الكتابة». فلو بس عايز تنزّل نص للتصميم (زي علامة تجارية)، استخدم CSS (`vertical-align`) بدل ما تلخبط المعنى.

وزي أي عنصر Inline، الـ `<sub>` ممكن يبوّظ ارتفاع السطر (line-height) شوية لأنه بينزّل النص. لو لقيت السطر اتزق، اظبط `line-height` على الأب أو على `sub`.

> [!analogy] تخيّل ورقة كيمياء: «H₂O». الرقم 2 مكتوب صغير تحت الحرف. لو كتبته بنفس الحجم وعلى نفس الخط هيبقى «H2O» ومش واضح إنه عدد ذرات. ده `<sub>`.

> [!key] `<sub>` = نص **منخفض** (H₂O). مقابله `<sup>` = نص **مرتفع** (x²).

## try

جرّب تكتب معادلة كيميائية تانية.

```html
<p>الماية: H<sub>2</sub>O</p>
<p>ثاني أكسيد الكربون: CO<sub>2</sub></p>
<p>الجلوكوز: C<sub>6</sub>H<sub>12</sub>O<sub>6</sub></p>
```

## syntax

```html nolive
<p>H<sub>2</sub>O</p>
```

- `<sub>` — **الوسم الافتتاحي**.
- النص — الجزء المنخفض (غالباً رقم أو حرف).
- `</sub>` — **الوسم الختامي** إجباري.

## use

- للصيغ الكيميائية (H₂O).
- للرموز الرياضية السفلية (x₁).
- للفهرسة (a₁، a₂).
- لملاحظات سفلية صغيرة بحسب التقاليد.

## avoid

- متستخدمهوش لمجرد تصغير نص: CSS.
- متستخدمهوش للمعادلات المعقدة: `<math>`.
- متستخدمهوش لروابط الحواشي: استخدم `<sup>`.
- متستخدمهوش لتزيين الشعار.

## examples

### 1) صيغة كيميائية
H₂O.

```html
<p>الماية صيغتها H<sub>2</sub>O.</p>
```

- الرقم 2 بيتنزّل ويتصغّر.
- من غير `<sub>` يبقى «H2O» ومش واضح.
- المعنى المقصود: عدد ذرات الهيدروجين.

### 2) رموز رياضية
أرقام سفلية لمتغيرات.

```html
<p>لو لدينا x<sub>1</sub> و x<sub>2</sub> فإن المجموع x<sub>1</sub> + x<sub>2</sub>.</p>
```

- الأرقام الصغيرة بتميّز المتغيرات عن بعض.
- ده نمط شائع في الرياضيات.

### 3) متتالية
الفهرسة.

```html
<p>المتتالية: a<sub>1</sub>, a<sub>2</sub>, a<sub>3</sub>, …, a<sub>n</sub></p>
```

- كل `a` ليه رقم سفلي بيمثّل ترتيبه.
- الحرف `n` في الآخر معناه «عدد عام».

### 4) مع sup معاً
مثال بيجمع المنخفض والمرتفع.

```html
<p>الصيغة: x<sub>i</sub><sup>2</sup> + y<sub>j</sub><sup>2</sup></p>
```

- `<sub>` بيحدد الفهرس، و`<sup>` بيحدد الأس.
- بس الترتيب مش مثالي بصرياً: للمعادلات المعقدة استخدم `<math>`.

### 5) تنسيق sub
تحكم في الشكل.

```html
<style>
  sub { font-size: 0.7em; color: #db2777; }
</style>
<p>الصيغة H<sub>2</sub>SO<sub>4</sub> (حمض الكبريتيك).</p>
```

- لوّنّا الأرقام السفلية بلون مميز.
- المعنى لسه منخفض.

### 6) مشكلة السطر
`sub` بيزق السطر، والحل.

```html
<style>
  sub, sup { line-height: 0; }
</style>
<p>سطر عادي<br>H<sub>2</sub>O وسط سطر طبيعي<br>سطر عادي</p>
```

- `line-height: 0` على `sub` و `sup` بيمنع تباعد السطور.
- ده حل شائع لمشكلة ارتفاع السطر.

## rules

- parents: أي عنصر بيقبل **Phrasing content**.
- children: **Phrasing content**.
- closing: الوسم الختامي `</sub>` إجباري.
- role: `subscript`.
- dom: `HTMLElement`.
- layout: `display: inline`، و`vertical-align: sub` مع `font-size: smaller`.

## mistakes

### sub للتصغير فقط
```html bad
<p>الكورس <sub>مجاني</sub></p>
```
```html good
<p>الكورس <span style="font-size:.8em">مجاني</span></p>
```
ليه؟ مفيش معنى subscript هنا.

### sub بدل sup
```html bad
<p>x<sub>2</sub> (للتربيع)</p>
```
```html good
<p>x<sup>2</sup> (للتربيع)</p>
```
ليه؟ الأس مكانه فوق مش تحت.

### استخدام unicode مع sub
```html bad
<p>H<sub>₂</sub>O</p>
```
```html good
<p>H<sub>2</sub>O</p>
```
ليه؟ الأفضل تكتب رقم عادي جوه `<sub>`، أو رمز Unicode بدون العنصر. الجمع بينهم بيعمل رقم أصغر من اللازم.

## a11y

- قارئ الشاشة ممكن يقرا «H2O» من غير توضيح.
- لو الصيغة مهمة، ضيف `aria-label="H2O ماء"` أو نص مخفي بصرياً.
- في المعادلات المعقدة، MathML أحسن.

## tips

- في الكيمياء، `<sub>` للأعداد، و`<sup>` للشحنات (Na⁺).
- لو بتكتب كتير معادلات، جرّب KaTeX أو MathML.
- راجع ارتفاع السطر.
