## intro

الـ `<mark>` هو **قلم الهايلايت** في HTML. بيظلّل النص بخلفية صفرا (وخط أسود) عشان يبرزه. لكن المعنى الحقيقي: «الجزء ده **ذو صلة** بحاجة بتعملها دلوقتي». يعني التظليل بيتحدد حسب **اللي المستخدم بيدوّر عليه أو بيقراه**، مش حسب أهمية الكلام في الأصل.

أشهر استخدام: **نتايج البحث**. لما تدوّر على كلمة «CSS» في صفحة، الكلمة بتتظلّل في كل مكان ظهرت فيه. الكلمة مش «مهمة» في الأصل، لكنها **ذات صلة** ببحثك. والاستخدام التاني: **اقتباس** بتعلّم فيه جزء معيّن لأنه المقصود من الاقتباس (مثلاً في مقال بتشرح إيه اللي كان مهم في فقرة اقتبستها).

والفرق بينه وبين العناصر التانية: الـ `<strong>` معناه **أهمية** في الكلام نفسه، والـ `<em>` **تأكيد منطوق**، والـ `<b>` **لفت نظر** بسبب نوع الكلمة. أما `<mark>` فهو **صلة بالسياق الحالي**. والصلة دي ممكن تتغيّر من لحظة للتانية: لو المستخدم دوّر على كلمة تانية يتحرك التظليل.

وكمان تقدر تتحكم في الشكل كله بالـ CSS (اللون والخلفية)، فمتخافش من لون الأصفر الافتراضي.

> [!analogy] تخيّل بتذاكر من كتاب وبتستخدم قلم هايلايت. بتظلّل الجزء اللي هتحتاجه في الامتحان. التظليل ده مش لأن الكلام أهم في الكتاب، لكن لأنه **ذو صلة بيك دلوقتي**. ده `<mark>`.

> [!key] `<mark>` = **صلة بالسياق** الحالي (كلمة بحث، جزء مقصود). الأهمية الأصلية: `<strong>`.

## try

اكتب كلمة في الحقل وهتتظلّل في الفقرة بـ `<mark>` (بالجافاسكربت).

```html
<input id="q" placeholder="دوّر على كلمة…" value="HTML">
<p id="t">HTML بتبني الهيكل، و CSS بتجمّل، و JavaScript بتتفاعل. تعلّم HTML الأول.</p>
<script>
  const t0 = t.textContent;
  function run() {
    const v = q.value.trim();
    t.innerHTML = v ? t0.split(v).join('<mark>' + v + '</mark>') : t0;
  }
  q.addEventListener('input', run);
  run();
</script>
```

## syntax

```html nolive
<p>تعلّم <mark>HTML</mark> الأول.</p>
```

- `<mark>` — **الوسم الافتتاحي**.
- النص — الجزء المظلّل.
- `</mark>` — **الوسم الختامي** إجباري.

## use

- لإبراز كلمة البحث في نتايج البحث.
- لتظليل جزء في اقتباس عشان لفت النظر ليه.
- لتمييز جزء ذو صلة بسؤال أو سياق المستخدم.
- في تطبيقات التعليم لتظليل الإجابة.

## avoid

- متستخدمهوش للتزيين.
- متستخدمهوش للأهمية: استخدم `<strong>`.
- متستخدمهوش للتأكيد: استخدم `<em>`.
- متظلّلش نص كبير: الهايلايت بيفقد قيمته.

## attributes

مالوش خصائص خاصة، بيقبل **الخصائص العامة** ([[global-attributes]]).

### class
مفيدة لتحديد أنواع التظليل (`class="match"`).

### id
لو عايز تتنقل بين نتايج التظليل بالجافاسكربت.

## examples

### 1) أبسط mark
كلمة مظلّلة.

```html
<p>تعلّم <mark>HTML</mark> قبل CSS.</p>
```

- الكلمة بتظهر بخلفية صفرا افتراضياً.
- الخلفية جاية من تنسيق المتصفح الافتراضي.
- المعنى: الكلمة دي ذات صلة بالقارئ.

### 2) نتيجة بحث
تظليل الكلمة المطلوبة.

```html
<ul>
  <li>دليل <mark>JavaScript</mark> للمبتدئين</li>
  <li>مقدمة في <mark>JavaScript</mark> الحديثة</li>
</ul>
```

- كلمة البحث مظلّلة في كل نتيجة.
- ده الاستخدام الأشهر ومكتوب في المواصفة.

### 3) اقتباس مظلّل
جزء مقصود في اقتباس.

```html
<blockquote>
  البرمجة هي <mark>فن حلّ المشاكل</mark> بالتفكير المنظم.
</blockquote>
```

- الجزء المظلّل هو اللي بنشير له في اقتباس.
- لو الكلام أصلاً مهم فيستخدم `<strong>`.

### 4) تغيير اللون
بتتحكم بالـ CSS.

```html
<style>
  mark { background: #bbf7d0; color: #064e3b; padding: 0 4px; border-radius: 4px; }
</style>
<p>التمرين <mark>مهم</mark> لقدرتك على الفهم.</p>
```

- غيّرنا الأصفر لأخضر فاتح مع حواف مدوّرة.
- المعنى لسه تظليل بالصلة.

### 5) تظليل بالجافاسكربت
نبني كلمة البحث ونظلّلها أوتوماتيك.

```html
<p id="doc">الويب فيه HTML و CSS و JS. الـ HTML أساس الويب.</p>
<button onclick="
  doc.innerHTML = doc.textContent.replaceAll('HTML','<mark>HTML</mark>');
">ظلّل HTML</button>
```

- الزرار بيستبدل كل كلمة HTML بنسخة مظلّلة.
- بنستخدم `<mark>` عشان المعنى يوصل لقارئ الشاشة.

### 6) تظليل بدون HTML (للمقارنة)
CSS Highlight API: بديل متقدم بيظلّل بدون تعديل الـ DOM.

```html nolive
<style>
  ::highlight(search) { background: yellow; color: black; }
</style>
<script>
  const r = new Range();
  // نحدد نص ونضيفه لـ CSS.highlights
  CSS.highlights.set('search', new Highlight(r));
</script>
```

- ده بيشتغل في المتصفحات الحديثة وبيخلّي التظليل بدون عناصر `<mark>`.
- لكن `<mark>` أبسط وأوضح معنى للمبتدئين.

## rules

- parents: أي عنصر بيقبل **Phrasing content**.
- children: **Phrasing content**.
- closing: الوسم الختامي `</mark>` إجباري.
- role: `mark`.
- dom: `HTMLElement`.
- layout: `display: inline`، خلفية صفرا ونص أسود افتراضياً.

## mistakes

### mark للأهمية
```html bad
<p><mark>تحذير:</mark> الجهاز ساخن.</p>
```
```html good
<p><strong>تحذير:</strong> الجهاز ساخن.</p>
```
ليه؟ التحذير أهمية في الكلام، مش صلة بالسياق.

### mark لتزيين
```html bad
<h2><mark>عنوان القسم</mark></h2>
```
```html good
<h2 class="hl">عنوان القسم</h2>
```
ليه؟ لو عايز خلفية للتزيين استخدم CSS.

### تظليل كل شيء
```html bad
<p><mark>كل الفقرة مظلّلة</mark></p>
```
```html good
<p>الفقرة فيها <mark>جزء واحد</mark> بس.</p>
```
ليه؟ لو كل حاجة مظلّلة مفيش حاجة بتبرز.

## a11y

- قارئات الشاشة غالباً **مش بتعلن** `<mark>` افتراضياً، فالتظليل ممكن ميوصلش.
- لو التظليل مهم للفهم، ضيف نص مخفي بصرياً «(مظلّل)» قبل وبعد.
- تأكد من التباين: نص أسود على أصفر عادةً كويس، لكن لو غيّرت الألوان اتأكد.

## tips

- لو بتبني بحث، تظليل الكلمة بـ `<mark>` أسهل حل.
- متنساش تشيل `<mark>` القديمة قبل تظليل جديد.
- لا تبني `<mark>` من نص المستخدم بـ `innerHTML` من غير تنظيف (ثغرة أمان XSS).
