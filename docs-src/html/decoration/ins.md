## intro

`<ins>` هو التوأم المعاكس لـ `<del>`: بيعلّم على نص **اتضاف** لمستند في تعديل. لو `<del>` معناه «ده اتشال»، فـ `<ins>` معناه «ده اتحط». بيظهر بخط تحته افتراضياً (زي الإضافات في تتبع التغييرات في Word).

بنستخدمهم مع بعض لتوثيق تعديل: «الاجتماع ~~الأحد~~ **الإثنين**». المتصفح بيعرض الأول بخط في النص والتاني بخط تحته. وعلشان كده بتلاقي مقالات إخبارية بتحط «تحديث:» أو «تم التصحيح:» وبتستخدمهم عشان تبيّن إيه اللي اتغيّر بعد النشر، بدل ما تستبدل الكلام بصمت (ده أكتر شفافية للقارئ).

زي `<del>` بالظبط، `<ins>` عنصر **شفّاف**: ينفع يلف Inline أو Block حسب الأب. وبيقبل `cite` (رابط يشرح الإضافة) و`datetime` (وقت الإضافة). ومن الآخر، المتصفحات مش بتعرضهم لكن بيتخزنوا في الـ DOM.

انتبه: متستخدمش `<ins>` بس عشان تعمل خط تحت، لأن الخط التحت بيتلخبط بالرابط. والأفضل `<mark>` أو `<em>` لو بتلفت الانتباه، و`<ins>` فقط لو حقيقي ده **إضافة** في مستند.

> [!analogy] مدرّس بيصحّح ورقة: بيشطب الكلمة الغلط (del) وبيكتب الصح فوقها (ins). الاتنين معاً هما قصة التعديل.

> [!key] `<ins>` = نص **اتضاف** في تعديل مستند. معاه دايماً `<del>` غالباً.

## try

جرّب تضيف `datetime` لإضافة جديدة.

```html
<p>
  الدرس <del>الجمعة</del>
  <ins datetime="2026-10-28">السبت</ins>.
</p>
<p><ins>تحديث: تم تأجيل الموعد.</ins></p>
```

## syntax

```html nolive
<ins cite="https://example.com/why" datetime="2026-10-28">النص المضاف</ins>
```

- `<ins>` — **الوسم الافتتاحي**.
- `cite` — اختيارية: رابط يشرح سبب الإضافة.
- `datetime` — اختيارية: وقت الإضافة.
- `</ins>` — **الوسم الختامي** إجباري.

## use

- لتوثيق نص اتضاف بعد النشر.
- مع `<del>` لإظهار التغيير.
- لتحديثات المقالات ("تحديث: …").
- لسجلات التغييرات والنسخ.

## avoid

- متستخدمهوش لمجرد خط تحت: CSS أو `<u>`.
- متستخدمهوش للتمييز: `<mark>`.
- متستخدمهوش للتأكيد: `<em>`.
- متضيفش إضافة بدون توثيق لو التعديل جوهري.

## attributes

### cite
رابط (URL) لصفحة بتشرح سبب الإضافة.

```html nolive
<ins cite="https://example.com/update">تحديث جديد</ins>
```

### datetime
وقت الإضافة بصيغة صالحة.

```html nolive
<ins datetime="2026-10-28T09:00:00+03:00">تحديث</ins>
```

### class
للتنسيق.

## examples

### 1) أبسط ins
نص مضاف.

```html
<p>الكورس <ins>مجاني</ins>.</p>
```

- الكلمة بتظهر بخط تحتها افتراضياً.
- معناها إن النص ده اتضاف.
- من غير `<del>` ممكن يتفهم إنه إضافة جديدة تماماً.

### 2) مع del
الاستخدام الأساسي.

```html
<p>الاجتماع يوم <del>الأحد</del> <ins>الإثنين</ins>.</p>
```

- الاتنين بيحكوا التعديل: الأحد اتشال والإثنين اتحط.
- ده أكتر شفافية من الاستبدال بصمت.

### 3) تحديث في مقال
بعد النشر.

```html
<article>
  <p>أعلنت الشركة عن الإصدار الجديد.</p>
  <ins datetime="2026-10-28">
    <p><strong>تحديث:</strong> تم إطلاق الإصدار رسمياً اليوم.</p>
  </ins>
</article>
```

- `<ins>` لف فقرة كاملة لأنه شفاف.
- `datetime` بيحدد إمتى اتضافت.
- القارئ يعرف إن التحديث ده اتضاف بعد النشر.

### 4) تنسيق ins
شكل مختلف.

```html
<style>
  ins { text-decoration: none; background: #dcfce7; color: #166534; padding: 0 3px; border-radius: 3px; }
</style>
<p>السعر <del>100</del> <ins>80</ins> جنيه.</p>
```

- شلنا الخط التحت وحطينا خلفية خضرا.
- نفس المعنى، شكل أنضف.

### 5) سجل تغييرات
نمط شائع.

```html
<h3>الإصدار 2.0</h3>
<ul>
  <li><ins>إضافة وضع ليلي</ins></li>
  <li><del>حذف الدعم القديم</del></li>
</ul>
```

- المضافات بـ `<ins>` والمحذوفات بـ `<del>`.
- ده مألوف في صفحات Release Notes.

## rules

- parents: أي عنصر بيقبل **Phrasing content**، وكمان **Flow content** لو محتواه Flow.
- children: **Transparent**: نفس نوع محتوى الأب.
- closing: الوسم الختامي `</ins>` إجباري.
- role: `insertion`.
- dom: `HTMLModElement`.
- layout: `display: inline`، و`text-decoration: underline`.

## mistakes

### ins للتأكيد
```html bad
<p>لازم <ins>تحفظ</ins> الملف.</p>
```
```html good
<p>لازم <em>تحفظ</em> الملف.</p>
```
ليه؟ مفيش إضافة موثّقة، ده تأكيد.

### ins بدل mark
```html bad
<p>الكلمة <ins>مهمة</ins>.</p>
```
```html good
<p>الكلمة <mark>مهمة</mark>.</p>
```
ليه؟ التمييز شغل `<mark>`.

### ins من غير تحديث واضح
```html bad
<p><ins>جملة جديدة.</ins></p>
```
```html good
<p><ins datetime="2026-10-28">تحديث: جملة جديدة.</ins></p>
```
ليه؟ الإضافة بدون سياق مش مفيدة.

## a11y

- قارئات الشاشة ممكن تعلن «إضافة» أو لأ.
- اكتب «تحديث:» أو «تعديل:» كنص عشان توصل للكل.
- متعتمدش على اللون.

## tips

- استخدم `<ins>` مع `datetime` لتحديثات الأخبار.
- لو الإضافة كبيرة، اعرضها في مربع «تحديث» مع `<ins>`.
- لو مفيش تعديل مستند، متستخدمش `<ins>`.
