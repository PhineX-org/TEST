## intro

الـ `<s>` بيرسم **خط في نص الكلام** (Strikethrough). لكن معناه مش «كلام اتحذف»، معناه «كلام **ماعادش صحيح أو مناسب**» لكن لسه موجود للمقارنة أو للتوضيح. أشهر مثال: **السعر القديم** في عرض: «~~100 جنيه~~ 70 جنيه». السعر القديم لسه ظاهر عشان القارئ يشوف الخصم، بس مش هو السعر الحالي.

الفرق بينه وبين `<del>`: الـ `<del>` بيعبّر عن **تعديل في مستند**، يعني إن في حاجة اتشالت من نسخة سابقة (زي تتبع التغييرات في وورد). أما `<s>` فهو **معلومة منتهية الصلاحية** مش بالضرورة اتحذفت من مستند. يعني قايمة مهام ملغية، أو عرض خلص، أو سعر قديم: كل دول `<s>`.

ولو الكلام ده بيتكلم عن تعديل فعلي (تغيير نسخة) فـ `<del>` (و`<ins>` للإضافة). وفي حالة الشك: لو الحاجة «ماعادتش صحيحة» استخدم `<s>`، ولو «اتغيّرت في المستند» استخدم `<del>`.

والشكل: خط في نص الكلام، وهو بيتحكم فيه الـ CSS بـ `text-decoration: line-through`. فيمكنك تعمل الشكل ده على أي عنصر، لكن `<s>` بيضيف **المعنى**.

> [!analogy] تخيّل قايمة مشتريات: بتشطب الحاجة اللي اشتريتها بخط، لكن لسه شايفها. الشطب مش معناه «الحاجة دي اتمسحت»، معناه «خلصت». ده `<s>`.

> [!key] `<s>` = معلومة **ماعادتش صحيحة** (سعر قديم، عرض خلص). `<del>` = حذف في مستند.

## try

جرّب تضيف سعر قديم مشطوب جنب السعر الجديد.

```html
<p>
  السعر: <s>100 جنيه</s> <strong>70 جنيه</strong>
</p>
```

## syntax

```html nolive
<p>السعر: <s>100</s> 70 جنيه</p>
```

- `<s>` — **الوسم الافتتاحي**.
- النص — المعلومة المنتهية.
- `</s>` — **الوسم الختامي** إجباري.

## use

- للسعر القديم في عروض الخصم.
- لعرض منتهي أو معلومة غير دقيقة.
- لقايمة مهام ملغية.
- لأي معلومة لسه ظاهرة لكن ماعادتش صحيحة.

## avoid

- متستخدمهوش لحذف فعلي من مستند: استخدم `<del>`.
- متستخدمهوش للشكل بس: CSS.
- متحطش جواه معلومة مهمة جداً من غير تعويض ظاهر.

## attributes

مالوش خصائص خاصة، بيقبل **الخصائص العامة** ([[global-attributes]]).

### class
للتنسيق، زي `class="old-price"`.

### lang
لو النص بلغة مختلفة.

## examples

### 1) سعر قديم وجديد
أشهر استخدام.

```html
<p>كورس HTML: <s>200 جنيه</s> <strong>مجاني</strong></p>
```

- السعر القديم مشطوب لكنه ظاهر للمقارنة.
- السعر الجديد في `<strong>` لأنه المهم.

### 2) عرض انتهى
معلومة ماعادتش صالحة.

```html
<p><s>خصم 50% لحد 31 أكتوبر</s> العرض انتهى.</p>
```

- الجملة اتشطبت لأنها ماعادتش صحيحة.
- الشطب بيوصّل للقارئ إن العرض خلص.

### 3) s مقابل del
المعنى مختلف.

```html
<p><s>ناقص خبز</s> (اشتريته)</p>
<p>الاجتماع <del>الأحد</del> <ins>الإثنين</ins>.</p>
```

- الأول: بند خلص، فـ `<s>`.
- التاني: تعديل في موعد، فـ `<del>` و`<ins>`.

### 4) تنسيق مخصص
تغيير شكل الخط.

```html
<style>
  s { color: #94a3b8; text-decoration-color: #dc2626; text-decoration-thickness: 2px; }
</style>
<p>كان بـ <s>500</s> بقى بـ 300 جنيه.</p>
```

- لوّنا النص رمادي والخط أحمر.
- المعنى لسه «معلومة منتهية».

### 5) قايمة مهام
قايمة فيها بنود خلصت.

```html
<ul>
  <li><s>اشتري لابتوب</s></li>
  <li><s>تعلم HTML</s></li>
  <li>تعلم CSS</li>
</ul>
```

- البنود المشطوبة خلصت، لكن لسه ظاهرة للتتبع.
- لو التطبيق تفاعلي، الأفضل `<input type="checkbox">` مع تنسيق.

## rules

- parents: أي عنصر بيقبل **Phrasing content**.
- children: **Phrasing content**.
- closing: الوسم الختامي `</s>` إجباري.
- role: `deletion`.
- dom: `HTMLElement`.
- layout: `display: inline`، و`text-decoration: line-through`.

## mistakes

### s لحذف في مستند
```html bad
<p>الاجتماع <s>الأحد</s> الإثنين</p>
```
```html good
<p>الاجتماع <del>الأحد</del> <ins>الإثنين</ins></p>
```
ليه؟ ده تعديل في الموعد: `<del>` و`<ins>`.

### s للشكل بس
```html bad
<p>الكلام ده <s>مش مشطوب فعلاً</s>.</p>
```
```html good
<p style="text-decoration: line-through">للشكل فقط.</p>
```
ليه؟ لو مفيش معنى «منتهي» فالشطب شكل CSS.

## a11y

- قارئات الشاشة غالباً ما بتعلنش الشطب، فالمعنى ممكن يضيع.
- لو المعلومة المشطوبة مهمة، اكتب نص بديل (مثلاً «السعر قبل الخصم: 100 جنيه»).
- ممكن تضيف نص مخفي بصرياً «(قديم)».

## tips

- دايماً اعرض البديل الصحيح جنب المشطوب.
- في الأسعار، الأحسن إضافة كلمة «كان» قبلها.
