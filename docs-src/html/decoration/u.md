## intro

الـ `<u>` بيرسم **خط تحت** النص. في الماضي كان اسمه Underline وكان بيستخدم لتسطير أي كلام. لكن في HTML5 اتغيّر معناه: بقى **Unarticulated Annotation**، يعني «علامة توضيحية مش مكتوبة بكلام». استخدامات المواصفة له: علامة على **غلطة إملائية** (زي اللي بتشوفه في Word)، أو علامة **اسم علم** في اللغة الصينية.

وعشان كده بتستخدمه في حالات قليلة جداً. السبب الأكبر: **الناس اتعودت إن الخط تحت = رابط**. لو سطّرت نص عادي، المستخدم هيضغط عليه ويتوقع يفتح حاجة. فالأفضل تتجنب `<u>` للتأكيد أو للتزيين، واستخدم `<em>` للتأكيد أو `<mark>` للتمييز أو CSS لو عايز شكل تحت الخط.

ولو بتبني محرر نصوص أو أداة تصحيح إملائي، فـ `<u>` ممكن يكون مناسب لعلامة الغلط (مع `text-decoration-style: wavy` وأحمر). وده بالظبط الاستخدام اللي المواصفة بتقصده.

أما الروابط `<a>` فبتتسطّر تلقائياً، ومتحتاجش `<u>`.

> [!analogy] تخيّل معلم بيصحّح كراسة: بيحط خط أحمر مموّج تحت الكلمة الغلط. الخط ده مش جزء من الكلام، هو علامة عليه. ده `<u>`.

> [!key] `<u>` = علامة على نص (غلط إملائي مثلاً). متستخدمهوش للتأكيد: الناس بتفتكره رابط.

## try

دي كلمة فيها غلطة إملائية معلَّمة بخط أحمر مموّج.

```html
<style>
  u.err { text-decoration: underline wavy red; }
</style>
<p>أنا بحب <u class="err">البرمجه</u> جداً.</p>
```

## syntax

```html nolive
<p>الكلمة <u>الغلط</u> متعلّمة.</p>
```

- `<u>` — **الوسم الافتتاحي**.
- النص — الجزء المعلَّم.
- `</u>` — **الوسم الختامي** إجباري.

## use

- لتعليم غلطة إملائية أو نحوية (في أدوات التصحيح).
- لعلامة اسم العلم في الصينية (Proper name mark).
- لأي علامة توضيحية غير نصية.

## avoid

- متستخدمهوش للتأكيد: استخدم `<em>` أو `<strong>`.
- متستخدمهوش للروابط: `<a>`.
- متستخدمهوش للتمييز: `<mark>`.
- متسطّرش نص عادي: المستخدم هيفتكره رابط.

## attributes

مالوش خصائص خاصة، بيقبل **الخصائص العامة** ([[global-attributes]]).

### class
أهم خاصية هنا: بتحدد نوع العلامة (`class="err"`).

### lang
لو الكلمة بلغة مختلفة.

## examples

### 1) أبسط u
خط تحت عادي.

```html
<p>كلمة <u>مسطّرة</u> في الجملة.</p>
```

- الخط تحت هو الشكل الافتراضي.
- المستخدم ممكن يفتكرها رابط.
- معناها «علامة غير نصية» مش تأكيد.

### 2) علامة غلط إملائي
الاستخدام الأنسب.

```html
<style>
  u.spell { text-decoration: underline wavy #dc2626; text-underline-offset: 3px; }
</style>
<p>كتبت الكلمة <u class="spell">اعتزار</u> بدل «اعتذار».</p>
```

- الخط الأحمر المموّج هو علامة الأدوات الإملائية المألوفة.
- المعنى: «الكلمة دي غلط» وده الاستخدام اللي المواصفة بتقصده.

### 3) الخطر: u قريب من رابط
مثال بيوريك الالتباس.

```html
<p>
  <a href="#">رابط حقيقي</a> و <u>نص مسطّر عادي</u>.
</p>
```

- الاتنين شكلهم متشابه، والمستخدم هيجرّب يضغط على التاني.
- ده سبب إننا بنتجنب `<u>` للتزيين.

### 4) بدائل أحسن للتمييز
بدل `<u>` للتأكيد.

```html
<p>لازم <em>تحفظ</em> قبل ما تقفل، و<mark>الحفظ التلقائي</mark> متعطّل.</p>
```

- `<em>` للتأكيد، و`<mark>` للتمييز.
- كلهم أوضح معنى من `<u>`.
- المستخدم مش هيفتكرهم روابط، لأنهم مش مسطّرين.
- قارئ الشاشة بيقدر يعلن `<em>` (نبرة)، لكن مش بيعلن `<u>`.

### 5) تغيير شكل الخط
نمط الخط وسُمكه.

```html
<style>
  u { text-decoration-style: dotted; text-decoration-color: #0ea5e9; text-decoration-thickness: 2px; }
</style>
<p>الكلمة <u>دي</u> بخط منقط أزرق.</p>
```

- `text-decoration-*` بتتحكم في شكل الخط.
- نفس العنصر ونفس المعنى.

## rules

- parents: أي عنصر بيقبل **Phrasing content**.
- children: **Phrasing content**.
- closing: الوسم الختامي `</u>` إجباري.
- role: `generic`.
- dom: `HTMLElement`.
- layout: `display: inline`، و`text-decoration: underline`.

## mistakes

### u للتأكيد
```html bad
<p>الموعد <u>الخميس</u> بالظبط.</p>
```
```html good
<p>الموعد <em>الخميس</em> بالظبط.</p>
```
ليه؟ الـ `<u>` بيتفهم رابط والتأكيد شغل `<em>`.

### u بدل a
```html bad
<u onclick="go()">اضغط هنا</u>
```
```html good
<a href="/go">اضغط هنا</a>
```
ليه؟ الروابط `<a>` وبتتسطّر تلقائياً.

## a11y

- قارئ الشاشة مش بيعلن `<u>` أصلاً، فالمعنى مش بيوصل.
- لو بتعلّم غلطة إملائية، ضيف طريقة تانية تعرّف بيها المستخدم (نص بديل أو تلميح).

## tips

- لو عايز تسطّر للشكل: `text-decoration` في CSS على `<span>`.
- متسطّرش غير الروابط في موقعك الأساسي.
