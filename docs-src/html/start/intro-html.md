## intro

كلمة HTML اختصار **HyperText Markup Language**، يعني «لغة ترميز النص الفائق». كلمة **HyperText** معناها نص فيه روابط تنقلك لنصوص تانية، وده أصل فكرة الويب كلها: صفحات مربوطة ببعض. وكلمة **Markup** معناها «علامات» بنحطها حوالين النص عشان نقول للمتصفح: ده عنوان، ودي فقرة، ودي صورة، ودي قايمة. يعني HTML مش بيقولك الحاجة **شكلها** إيه، هو بيقولك الحاجة دي **إيه**. وده الفرق بين **الهيكل** (Structure) و**الشكل** (Styling).

HTML **مش لغة برمجة**: مفيهاش شروط ولا حلقات ولا عمليات حسابية. هي لغة **وصف**: إنت بتكتب عناصر وخصائص، والمتصفح (Browser) هو اللي بيقراها ويرسم الصفحة. وده بيطمّنك كمبتدئ: ملف HTML هو **ملف نصي عادي** تقدر تكتبه في أي محرر نصوص، ولو غلطت المتصفح مبيعملش «Crash»، بيحاول يفهمك ويعرض اللي قدر عليه. كل اللي بتشوفه على الإنترنت، من فيسبوك لويكيبيديا، قايم على HTML.

التوثيق ده معمول عشان يمسك إيدك من أول سطر. كل **عنصر** (Element) في HTML ليه صفحة بتشرح: هو إيه، وليه اتعمل، وإزاي بيتكتب، وإمتى تستخدمه وإمتى لأ، وكل خصائصه، وأمثلة تجرّبها بنفسك وتعدّل فيها، وأخطاء المبتدئين الشائعة، وكويز في الآخر. وقبل العناصر في فصل اسمه «ابدأ من هنا» فيه المفاهيم الأساسية اللي هتحتاجها في كل صفحة (زي [[anatomy]] و [[block-inline]] و [[nesting-rules]]). الصفحة دي هي أول خطوة: هتشرحلك الفكرة العامة وإزاي تستخدم الموقع.

> [!analogy] تخيّل بيت بتبنيه: **HTML هو الهيكل والحيطان والأبواب والشبابيك** (إيه الموجود وفين). **CSS هو الدهان والديكور** (الألوان والمقاسات والترتيب). و**JavaScript هو الكهربا والمصعد** (الحاجات اللي بتتحرك وتستجيب). مينفعش تدهن حيطة لسه مبنتهاش، عشان كده بنبدأ بـ HTML.

> [!key] اختار العنصر **بمعناه** مش بشكله. لو عايز عنوان استخدم `<h1>` مش `<p>` بخط كبير، ولو عايز قايمة استخدم `<ul>` مش شرطات بإيدك. الشكل بيتغيّر بالـ CSS في أي وقت، لكن المعنى هو اللي بتعتمد عليه قارئات الشاشة ومحركات البحث.

## section: المتصفح بيعمل إيه بملف الـ HTML؟

لما بتفتح صفحة ويب (أو بتدوس مرتين على ملف `index.html` على جهازك) بيحصل ده بالترتيب:

1. المتصفح **بيجيب الملف** (من السيرفر على الإنترنت، أو من جهازك).
2. **بيقراه من فوق لتحت** ويفهم كل وسم وكل خاصية. العملية دي اسمها Parsing.
3. **بيبني شجرة** من العناصر اسمها **DOM**: العناصر الكبيرة فوق، وجواها اللي أصغر، زي شجرة العيلة.
4. لو لقى ملفات مربوطة (CSS أو صور أو سكربتات) **بيجيبها كمان**.
5. **بيحسب** مكان كل عنصر وشكله، وبعدين **بيرسمه** على الشاشة.

المهم تفهم إن اللي بتشوفه على الشاشة هو **نتيجة تفسير المتصفح** للكود، مش الكود نفسه. جرّب المثال ده: عدّل الكلام اللي جوه العناصر وشوف النتيجة بتتغير فوراً.

```html live
<h1>أهلاً بيك في HTML</h1>
<p>ده كلام عادي جوه فقرة.</p>
<p>وده <a href="https://example.com">رابط</a> لموقع تاني.</p>
```

- `<h1>` بيقول «ده عنوان رئيسي»، والمتصفح بيعرضه كبير وغامق من نفسه.
- `<p>` بيقول «دي فقرة»، والمتصفح بيسيب مسافة قبلها وبعدها.
- `<a>` بيقول «ده رابط»، والمتصفح بيلوّنه ويحط تحته خط ويخليه قابل للضغط.

كل ده من غير ما تكتب سطر تنسيق واحد، لأن المتصفح عنده شكل افتراضي لكل عنصر بناءً على **معناه**.

## section: HTML و CSS و JavaScript: التلاتة مع بعض

**HTML** هو **المحتوى والمعنى**: النص والصور والروابط والجداول والنماذج، وإيه نوع كل حاجة منهم. من غيره مفيش صفحة أصلاً.

**CSS** هو **الشكل**: الألوان والخطوط والمسافات وترتيب العناصر وتغيير الشكل على الموبايل. بتكتبه جوه عنصر `<style>` أو في ملف منفصل تربطه بـ `<link>`، أو في خاصية `style` على العنصر.

**JavaScript** هو **السلوك**: يخلّي الصفحة تتفاعل. زرار يعمل حاجة لما تدوس عليه، فورم يتأكد من الإدخال، قايمة تتفتح وتتقفل. بتكتبه جوه عنصر `<script>` أو في ملف منفصل.

جرّب المثال ده، التلاتة شغّالين مع بعض: الـ HTML عمل زرار وفقرة، والـ CSS لوّن الزرار، والـ JavaScript بيعدّ الضغطات.

```html live
<style>
  button { background: teal; color: white; border: 0;
           padding: 8px 16px; border-radius: 6px; }
</style>
<button id="b" type="button">دوس عليا</button>
<p id="n">عدد الضغطات: 0</p>
<script>
  var n = 0;
  document.getElementById('b').addEventListener('click', function () {
    n++;
    document.getElementById('n').textContent = 'عدد الضغطات: ' + n;
  });
</script>
```

في المستقبل هتتعلم CSS و JavaScript بتفصيل أكتر. دلوقتي ركّز على HTML: هو الأساس اللي الاتنين بيقفوا عليه.

## section: شكل أصغر صفحة HTML

أي صفحة ويب بتتكوّن من نفس الهيكل الأساسي. ده الشكل الكامل:

```html nolive
<!DOCTYPE html>
<html lang="ar" dir="rtl">
<head>
  <meta charset="UTF-8">
  <title>صفحتي الأولى</title>
</head>
<body>
  <h1>مرحباً</h1>
  <p>ده أول سطر ليا في HTML.</p>
</body>
</html>
```

- `<!DOCTYPE html>` — بتقول للمتصفح «الصفحة دي مكتوبة بـ HTML الحديث». لازم تبقى **أول سطر**. تفاصيلها في [[doctype]].
- `<html>` — العنصر **الجذر** (Root) اللي بيحتوي الصفحة كلها. بنحط عليه `lang="ar"` و `dir="rtl"` للعربي.
- `<head>` — **معلومات عن الصفحة** مبتظهرش جواها: الترميز بـ `<meta>`، وعنوان التبويب بـ `<title>`، وروابط الـ CSS بـ `<link>`.
- `<body>` — **اللي بيظهر للزائر**: العناوين والفقرات والصور والروابط وكل حاجة.

بعد ما تفتح الصفحة هتلاقي عنوان التبويب «صفحتي الأولى» (من `<title>`) والمحتوى في النص (من `<body>`). تقدر تجرّب نفس الصفحة كاملة هنا. لاحظ إن الـ console بيكتب معلومات عن المستند:

```html live
<!DOCTYPE html>
<html lang="ar" dir="rtl">
<head>
  <meta charset="UTF-8">
  <title>صفحتي الأولى</title>
</head>
<body>
  <h1>مرحباً</h1>
  <p>ده أول سطر ليا في HTML.</p>
  <script>
    console.log('doctype: ' + document.doctype.name);
    console.log('title: ' + document.title);
    console.log('lang: ' + document.documentElement.lang);
    console.log('mode: ' + document.compatMode);
  </script>
</body>
</html>
```

الـ `mode` هيطلع `CSS1Compat`، يعني المتصفح فهم الصفحة بالمعيار الحديث بفضل `<!DOCTYPE html>`. من غيرها كان هيدخل في «وضع الغرابة» (Quirks Mode) وبيعرض بسلوكيات قديمة. كمان لاحظ إن الصفحة دي ليها أجزاء بالترتيب: `<head>` الأول وبعده `<body>`، ومينفعش تعكسهم. وأي سطر في الأول بيبدأ بـ `<!--` ده تعليق، عنه في [[comment]].

## section: إزاي تستخدم التوثيق ده

التوثيق مرتب علشان تلاقي أي حاجة بسرعة وتتعلم بالتجربة. دي الأدوات اللي هتتعامل معاها:

### القايمة الجانبية (شجرة التصنيفات)
في الجنب هتلاقي شجرة فيها كل العناصر **مقسّمة حسب التصنيف**: «ابدأ من هنا»، «هيكل المستند»، «أقسام الصفحة»، «العناوين»، «القوائم»، «الروابط»… دوس على اسم التصنيف يفتح عناصره، ودوس على العنصر يفتح صفحته. التصنيفات مترتبة تقريباً بنفس ترتيب ما بتتعلمهم، فتقدر تمشي من فوق لتحت.

### مربع البحث
لو عارف اسم العنصر أو الفكرة اكتبها في مربع البحث. البحث بيدوّر في **اسم العنصر** و**العنوان العربي** و**الاسم الإنجليزي** و**الكلمات المفتاحية** وملخص كل صفحة. يعني تقدر تكتب «رابط» أو «link» أو «a» أو حتى «لينك» وتوصل لنفس الصفحة. وكمان بيتجاهل اختلافات بسيطة زي التشكيل أو الهمزة، فمتقلقش على الإملاء.

### إزاي صفحة العنصر مترتبة
كل صفحة عنصر بتمشي بنفس النظام، عشان تتعود وتعرف فين تدوّر:

- **مقدمة:** يعني إيه العنصر ده وليه موجود، مع تشبيه من الواقع.
- **جرّبها:** مثال حي صغير تعدّل فيه.
- **الصيغة (Syntax):** شكل الكود الكامل وشرح كل جزء.
- **إمتى أستخدمه / إمتى لأ:** عشان تعرف تختار العنصر الصح.
- **الخصائص (Attributes):** كل خاصية خاصة بالعنصر. والخصائص اللي بتتحط على أي عنصر مشروحة في [[global-attributes]].
- **أمثلة:** من الأبسط للأصعب، وآخر مثال بيبقى صفحة صغيرة حقيقية.
- **القواعد:** مين يتحط جوه مين، وهل بيتقفل، وإيه الـ role الضمني.
- **أخطاء شائعة:** كود غلط جنب كود صح وسبب الغلط.
- **إتاحة (a11y):** إزاي العنصر يخدم كل المستخدمين.
- **كويز ومراجع:** اختبر نفسك، ولو عايز تتعمق في مصادر رسمية.

### أمثلة «جرّبها» التفاعلية
المربعات اللي فيها كود وجنبها أو تحتها معاينة هي **أمثلة حية**. الكود **قابل للتعديل**: غيّر أي حاجة وشوف النتيجة تتحدّث قدامك. لو بوّظت الكود دوس على زرار **إعادة (Reset)** يرجّع الكود الأصلي. وفيه كام حاجة تعرفها عن المعاينة:

- أي `console.log` في السكربت **بيظهر تحت المعاينة**، فتقدر تشوف نتيجة الكود.
- الروابط **مبتفتحش** مواقع، والفورم **مبيتبعتش** فعلاً. الغرض منهم تجربة الشكل بس.
- الصور اللي مش موجودة بتتحوّل لمكان محجوز عليه اسمها.
- مفيش `alert()` في المعاينة؛ استخدم `console.log` أو غيّر في الصفحة نفسها.

نصيحتنا: **متكتفيش بالقراءة**. قبل ما تكمل كل مثال، غيّر فيه حاجة واحدة وتوقع إيه اللي هيحصل قبل ما تشوفه.

### الكويز، والمفضلة، والثيم، وحجم الخط
- **الكويز:** في آخر كل صفحة أسئلة اختيار من متعدد، وكل إجابة معاها شرح. حلّه بعد القراءة عشان تثبّت المعلومة.
- **⭐ المفضلة:** علّم النجمة على أي صفحة تحب ترجعلها كتير (العناصر اللي بتستخدمها كل يوم)، وهتلاقيها بعد كده بسهولة.
- **الثيم (فاتح وغامق):** بدّل بين الوضع الفاتح والداكن حسب ما يريّح عينك.
- **حجم الخط:** فيه أزرار لتكبير وتصغير الخط لو الكلام صغير عليك.

## section: الشارات (Badges): إزاي تقرا حالة العنصر

HTML عمره أكتر من 30 سنة، وكتير من عناصره اتغيّر أو اتشال. عشان كده كل صفحة عنصر عليها **شارة حالة** بتقولك تستخدمه ولا لأ:

- **Stable (مستقر):** العنصر جزء ثابت من HTML الحديث، ودعمه ممتاز في كل المتصفحات. ده اللي بتبني عليه شغلك. أغلب العناصر كده.
- **Deprecated (مهجور):** لسه بيشتغل، لكن المواصفة **بتنصح بعدم استخدامه** لأن فيه بديل أحسن. هتلاقي في صفحته قسم «البديل الحديث».
- **Obsolete (قديم ومتشال):** اتشال من المواصفة، زي `<font>` و `<center>` و `<marquee>`. ممكن تلاقيهم في كود قديم، لكن **متستخدمهومش** في أي حاجة جديدة. بنشرحهم عشان تفهم الكود القديم وتعرف بديله.
- **Experimental (تجريبي):** عنصر جديد **دعمه محدود** (مثلاً بيشتغل في متصفح واحد بس زي `<fencedframe>`). جرّبه، لكن متبنيش عليه حاجة أساسية قبل ما تتأكد من الدعم.

وجنب الشارة بتلاقي **شريط دعم المتصفحات**: «مدعوم في الكل» أو «دعم محدود» أو «غير مدعوم». معلومات تانية زي العرض الافتراضي للعنصر (Block ولا Inline، شوف [[block-inline]]) وهل هو عنصر فارغ (شوف [[void-elements]]) موجودة في أول كل صفحة.

## section: خطة التعلم المقترحة

متدخلش على العناصر بالترتيب الأبجدي، ده هيتعبك. ده مسار مجرّب من الأساسي للمتقدم، بنفس ترتيب التصنيفات في الشجرة. كل خطوة هتشتغل عليها وتعمل صفحة صغيرة قبل ما تروح للي بعدها:

1. **ابدأ من هنا:** اقرأ [[anatomy]] (تشريح العنصر)، وبعده [[block-inline]]، و[[nesting-rules]]، و[[void-elements]]، و[[global-attributes]]. دي أساس كل اللي بعد كده، ولما تخلّصها اقرأ [[entities]] و[[semantic-html]].
2. **هيكل المستند:** [[doctype]] و `<html>` و `<head>` و `<body>` و[[comment]]. وبعدها ممكن تعدّي على `<title>` و `<meta>` و `<link>` و `<style>`.
3. **أقسام الصفحة:** `<header>` و `<nav>` و `<main>` و `<section>` و `<article>` و `<aside>` و `<footer>`. دي بتقسّم الصفحة لأجزاء ليها معنى.
4. **النصوص:** العناوين `<h1>` لحد `<h6>`، والفقرة `<p>`، والحاويات `<div>` و `<span>`، و `<br>` و `<hr>`. وبعدها التزيين: `<strong>` و `<em>` و `<mark>`.
5. **القوائم:** `<ul>` و `<ol>` و `<li>`، وقوائم التعريفات `<dl>` مع `<dt>` و `<dd>`.
6. **الروابط:** `<a>` وخصائصه (`href` و `target` و `rel`)، وأنواع الروابط (داخلية وخارجية وإيميل).
7. **الصور والوسائط:** `<img>` ومعاه `alt` المهمة، وبعده `<figure>` و `<figcaption>` و `<picture>`، ثم `<audio>` و `<video>`.
8. **الجداول:** `<table>` و `<tr>` و `<th>` و `<td>`، وبعدها `<thead>` و `<tbody>` و `<caption>`.
9. **النماذج (Forms):** `<form>` و `<label>` و `<input>` و `<button>` و `<textarea>` و `<select>`. دي أكبر مرحلة، فاخد وقتك فيها.

بعد المراحل دي ابدأ في الباقي حسب احتياجك: `<details>` و `<dialog>` (عناصر تفاعلية)، و `<code>` و `<pre>` (عرض الكود)، و `<iframe>` و `<canvas>` (محتوى مدمج ورسم)، و `<script>` و `<template>` (ربط الـ JavaScript). وفي الآخر عناصر القديم لو احتجت تفهم كود قديم.

> [!tip] ممكن تحدّد لنفسك تحدي: بعد كل خطوة اعمل صفحة صغيرة من اللي اتعلمته. مثلاً بعد الخطوة 5 اعمل صفحة «وصفة أكل» فيها عنوان وفقرة وقايمة مكوّنات وقايمة خطوات. التطبيق هو اللي بيثبّت المعلومة، مش القراءة.

## examples

### 1) أول صفحة: عنوان وفقرة
أبسط مثال ممكن: عنصرين بس. العنوان `<h1>` والفقرة `<p>`. لاحظ إن كل عنصر ليه وسم يفتحه ووسم يقفله (`</h1>`)، وإن المتصفح هو اللي اختار الخط الكبير للعنوان. غيّر الكلام جواهم وشوف.

```html
<h1>اسمي أحمد</h1>
<p>أنا بتعلّم HTML ودي أول صفحة أعملها.</p>
```

- `<h1>` عنوان رئيسي، والصفحة الواحدة في العادة ليها `<h1>` واحد.
- `<p>` فقرة. جرّب تكتب فقرة تانية تحتها.
- جرّب تغيّر `<h1>` لـ `<h2>` (ولاحظ إن حجم العنوان صغر).

### 2) HTML من غير شكل ومعاه شكل
نفس الـ HTML بالظبط في الحالتين. الزرار بيشغّل وبيطفّي الـ `<style>`، فتشوف الفرق بين **الهيكل** و**الشكل**. المحتوى ومعناه ما اتغيّرش، اللي اتغيّر هو الألوان والمسافات بس.

```html
<style id="st">
  h1 { color: teal; border-bottom: 3px solid teal; }
  p { background: #fff3bf; padding: 8px; border-radius: 6px; }
  ul { color: crimson; }
</style>
<h1>قائمة المهام</h1>
<p>اللي لازم أعمله النهاردة:</p>
<ul>
  <li>أذاكر HTML</li>
  <li>أعمل صفحة بسيطة</li>
</ul>
<button id="t" type="button">شغّل / طفّي الـ CSS</button>
<script>
  var st = document.getElementById('st');
  document.getElementById('t').addEventListener('click', function () {
    st.disabled = !st.disabled;
    console.log('CSS disabled = ' + st.disabled);
  });
</script>
```

- من غير الـ CSS الصفحة لسه مفهومة: عنوان وفقرة وقايمة، لأن **المعنى** جاي من HTML.
- لو كنت كاتب العنوان كـ `<p>` بخط كبير، من غير CSS كان هيرجع فقرة عادية.
- ده السبب إننا نقول «HTML للمعنى والـ CSS للشكل».

### 3) المتصفح بيبني شجرة
المتصفح بيحوّل الكود لشجرة من العناصر. السكريبت هنا بيمشي على الشجرة ويطبع اسم كل عنصر بإزاحة تدل على مكانه. الإزاحة الأكبر معناها عنصر أعمق جوه أبوه.

```html
<div id="page">
  <header><h1>موقعي</h1></header>
  <main>
    <p>فقرة فيها <strong>كلمة مهمة</strong>.</p>
    <ul>
      <li>واحد</li>
      <li>اتنين</li>
    </ul>
  </main>
</div>
<script>
  function tree(el, depth) {
    console.log('..'.repeat(depth) + el.tagName.toLowerCase());
    Array.prototype.forEach.call(el.children, function (c) {
      tree(c, depth + 1);
    });
  }
  tree(document.getElementById('page'), 0);
</script>
```

- `div` هو الجذر، وجواه `header` و `main` (إخوات).
- `h1` جوه `header`، و `strong` جوه `p`، و `li` جوه `ul`.
- كل عنصر ليه **أب واحد**. التفاصيل دي في [[nesting-rules]].

### 4) نفس المعلومة بعنصرين مختلفين
ده تطبيق لقاعدة «المعنى قبل الشكل». الصفحة بتقول إن «HTML مهم»، مرة بـ `<strong>` (معناها: ده مهم فعلاً) ومرة بـ `<b>` (مجرد لفت نظر من غير أهمية). شكلهم واحد في المتصفح، لكن قارئ الشاشة بيفرّق.

```html
<p>
  تذكير: <strong>الامتحان بكره</strong> ومفيش تأجيل.
</p>
<p>
  الكلمة <b>HTML</b> مكتوبة بخط غامق بس عشان تلفت نظرك.
</p>
<p>
  وده <em>تركيز</em> على كلمة جوه الجملة.
</p>
```

- `<strong>` معناه «أهمية عالية»، و `<b>` معناه «لفت نظر بس».
- `<em>` معناه «تأكيد في النطق»، وشكله مائل.
- الشكل ممكن تغيّره بالـ CSS، لكن المعنى هو اللي بيفضل.

### 5) أهم شكل للصفحة: كل المراحل في صفحة صغيرة
دي «معاينة» للرحلة كلها: صفحة صغيرة فيها هيكل (header و main و footer)، ونصوص، وقايمة، ورابط، وصورة، وجدول، ونموذج. مش لازم تفهم كل سطر دلوقتي، ركّز بس على إن كل عنصر ليه **شغلة** واضحة، وإن كل حاجة جوه حاجة.

```html h=420
<style>
  header { background: #e8f5f0; padding: 6px 12px; }
  nav a { margin-inline-end: 10px; }
  table { border-collapse: collapse; }
  th, td { border: 1px solid #999; padding: 4px 10px; }
  footer { margin-top: 12px; color: gray; font-size: 14px; }
</style>
<header>
  <h1>موقع أحمد</h1>
  <nav><a href="#about">عني</a> <a href="#skills">مهاراتي</a></nav>
</header>
<main>
  <section id="about">
    <h2>عني</h2>
    <p>أنا <strong>أحمد</strong> وبتعلّم <em>HTML</em>.</p>
    <img src="me.jpg" alt="صورة أحمد" width="120" height="80">
  </section>
  <section id="skills">
    <h2>مهاراتي</h2>
    <ul><li>HTML</li><li>CSS</li><li>JavaScript</li></ul>
    <table>
      <tr><th>اللغة</th><th>المستوى</th></tr>
      <tr><td>HTML</td><td>مبتدئ</td></tr>
    </table>
  </section>
  <section>
    <h2>تواصل معايا</h2>
    <form>
      <label>إيميلك: <input type="email"></label>
      <button type="submit">ابعت</button>
    </form>
  </section>
</main>
<footer><p>كل الحقوق محفوظة</p></footer>
```

- `<header>` و `<nav>` و `<main>` و `<section>` و `<footer>` بتقسّم الصفحة لأقسام ليها معنى.
- `<img>` فيه `alt` يوصف الصورة، و `<a>` بيودّي للأقسام بالـ `href="#…"`.
- `<ul>` و `<table>` للبيانات المنظمة، و `<form>` مع `<label>` و `<input>` لاستقبال الإدخال.
- جرّب تمسح عنصر كامل (مثلاً الجدول) وشوف باقي الصفحة بتفضل شغّالة.

## mistakes

### نسيت DOCTYPE في أول الملف
```html bad
<html>
<head><title>صفحتي</title></head>
<body><p>أهلاً</p></body>
</html>
```
```html good
<!DOCTYPE html>
<html lang="ar" dir="rtl">
<head>
  <meta charset="UTF-8">
  <title>صفحتي</title>
</head>
<body><p>أهلاً</p></body>
</html>
```
من غير `<!DOCTYPE html>` المتصفح بيدخل في «وضع الغرابة» (Quirks Mode) وبيحاكي سلوك قديم، فبتتغيّر المقاسات والمسافات بشكل غريب ومختلف عن المتوقع. اكتبها دايماً أول سطر في الملف. وشوف كمان [[doctype]].

### الحروف العربي بتطلع رموز غريبة
```html bad
<head>
  <title>مرحباً</title>
</head>
```
```html good
<head>
  <meta charset="UTF-8">
  <title>مرحباً</title>
</head>
```
من غير `<meta charset="UTF-8">` المتصفح ممكن يخمّن الترميز غلط ويعرض الحروف العربي على شكل رموز غريبة. حطها في أول `<head>`، وخلّي الملف نفسه محفوظ بترميز UTF-8 (ده الافتراضي في أغلب المحررات الحديثة).

### استخدام HTML عشان الشكل بس
```html bad
<p><b>مقدمة الكورس</b></p>
<p>أهلاً بيك</p><br><br><br>
<p>الدرس الأول</p>
```
```html good
<h2>مقدمة الكورس</h2>
<p>أهلاً بيك</p>
<h2>الدرس الأول</h2>
```
الكود الأول بيقلّد العنوان بـ `<b>` وبيعمل مسافة بـ `<br>` متكررة. الشكل ممكن يطلع قريب، لكن المعنى ضايع: قارئ الشاشة مش هيعرف إن ده عنوان، ومحركات البحث مش هتفهم هيكل الصفحة. اختار العنصر بمعناه (`<h2>`)، والمسافات اتحكم فيها بالـ CSS.

### عنصر بيظهر جوه الـ head
```html bad
<head>
  <title>صفحتي</title>
  <h1>مرحباً</h1>
</head>
```
```html good
<head>
  <title>صفحتي</title>
</head>
<body>
  <h1>مرحباً</h1>
</body>
```
الـ `<head>` للمعلومات اللي مبتظهرش بس. أول ما المتصفح يشوف `<h1>` هيعتبر إن الـ head خلص وهيبدأ الـ body من عندها، فالكود هيشتغل بالصدفة لكن هيبقى مبوّظ لو حطيت بعده `<meta>` أو `<link>`. التفاصيل في [[nesting-rules]].

## tips

- **ابدأ بملف واحد:** اعمل فولدر جديد وجواه ملف `index.html`. اكتب فيه الكود، احفظه، وافتحه في المتصفح بالدوس عليه مرتين. بعد كل تعديل اعمل Refresh.
- **استخدم محرر كود:** Visual Studio Code مجاني وبيلوّن الكود وبيكمّل وسوم الإغلاق. اكتب `!` واضغط Tab وهيكتبلك هيكل الصفحة الكامل جاهز.
- **افتح DevTools:** اضغط F12 وشوف لوحة Elements. هتشوف شجرة الصفحة اللي المتصفح بناها، وتقدر تعدّل فيها وتجرّب بشكل مباشر.
- **متحفظش، افهم:** مش لازم تحفظ كل العناصر. الأهم تعرف **إيه الأنواع الموجودة** وتعرف تدوّر عليها هنا. أي حاجة هتستخدمها كتير هتحفظها من نفسها.
- **اكتب بإزاحة منظمة:** مسافتين أو أربعة جوه كل عنصر. الكود المنظم بيكشفلك غلطات الإغلاق بسرعة (شوف [[nesting-rules]]).
- **غلطة؟ عادي:** المتصفح مبيزعّقش. لو الصفحة شكلها غريب راجع الأقواس والإغلاقات، وجرّب [W3C Nu Html Checker](https://validator.w3.org/nu/) اللي بيشخّص الأخطاء.
- **المعيار بيتطوّر:** مفيش HTML6؛ المعيار الحالي بيتحدّث باستمرار، ولذلك دايماً راجع شارة الحالة والدعم قبل ما تستخدم عنصر جديد.

## quiz

### HTML بيستخدم في الأساس لإيه؟
- [ ] نخلّي الصفحة تتحرك وتتفاعل
- [x] نوصف هيكل الصفحة ومحتواها (إيه كل حاجة فيها)
- [ ] نلوّن الصفحة ونظبّط المسافات
- [ ] نخزّن بيانات المستخدمين

HTML بيحدد **المحتوى ومعناه**. الحركة والتفاعل شغل JavaScript، والألوان والمسافات شغل CSS.

### أي جملة من دول صح عن HTML؟
- [ ] لغة برمجة فيها شروط وحلقات
- [x] لغة وصف (ترميز)، وملفها نص عادي بيفهمه المتصفح
- [ ] محتاجة برنامج مدفوع عشان تتكتب
- [ ] لو غلطت فيها الصفحة بتقف وتطلّع خطأ

HTML لغة ترميز مش لغة برمجة، وتتكتب في أي محرر نصوص. والمتصفح بيتساهل مع الأخطاء ويحاول يعرض اللي يقدر عليه.

### إيه أول سطر في أي صفحة HTML حديثة؟
- [ ] `<html>`
- [ ] `<head>`
- [x] `<!DOCTYPE html>`
- [ ] `<body>`

الـ `<!DOCTYPE html>` بتيجي قبل كل حاجة، وهي اللي بتقول للمتصفح يستخدم المعيار الحديث بدل وضع الغرابة القديم.

### فين بنحط `<title>` و `<meta charset>`؟
- [ ] جوه `<body>`
- [ ] قبل `<!DOCTYPE html>`
- [x] جوه `<head>`
- [ ] جوه `<footer>`

الـ `<head>` مكان المعلومات اللي مبتظهرش جوه الصفحة: العنوان والترميز وروابط الـ CSS. اللي بيظهر للزائر بيتحط في `<body>`.

### شفت عنصر عليه شارة **Obsolete**. تعمل إيه؟
- [ ] أستخدمه عادي، ده الأحدث
- [x] أفهمه عشان لو قابلته في كود قديم، لكن متستخدمهوش في شغلي الجديد
- [ ] أستخدمه بس على الموبايل
- [ ] أعتبره تجريبي ودعمه محدود

Obsolete يعني العنصر اتشال من المواصفة. بنشرحه عشان تفهم الكود القديم وتعرف البديل الحديث. التجريبي (Experimental) هو اللي جديد ودعمه محدود.

### إيه الترتيب الصح لخطة تعلّم HTML المقترحة؟
- [ ] النماذج، ثم الجداول، ثم هيكل المستند
- [ ] الجداول، ثم الصور، ثم القوائم
- [x] هيكل المستند، ثم أقسام الصفحة، ثم النصوص، ثم القوائم، ثم الروابط، ثم الصور، ثم الجداول، ثم النماذج
- [ ] الترتيب مش مهم خالص

بنبدأ بالأساس (الهيكل والأقسام والنصوص) وبعدين الأنواع الأصعب. النماذج آخر مرحلة لأنها أكبر وأكتر حاجة بتحتاج فهم لباقي العناصر.
