## intro

أي ملف CSS في الدنيا مكوّن من حاجة واحدة بتتكرر: **القاعدة (Rule)**. والقاعدة شكلها ثابت:

`selector { property: value; }`

**المحدد (Selector)** بيقول «أنا بتكلم عن أنهي عناصر»، وبعده **كتلة الإعلانات** بين `{` و`}`، وجواها **إعلان (Declaration)** أو أكتر. كل إعلان = **خاصية (Property)** + نقطتين `:` + **قيمة (Value)** + فاصلة منقوطة `;`. مثلاً `color: red;` يعني «لون الكلام أحمر».

المتصفح بيقرا القاعدة من اليمين لليسار بالنسبة للمحدد، وبيطبّق الإعلانات واحد واحد. ولو في إعلان **غلط** (خاصية بتتكتب غلط أو قيمة مش مسموحة) المتصفح **بيتجاهل الإعلان ده بس** وبيكمّل الباقي من غير ما يوقف الصفحة. ده مريح، بس معناه إن الغلط بيعدّي بصمت، فاستخدم DevTools عشان تكتشفه.

> [!analogy] القاعدة زي أمر لعامل: **«كل الأبواب (محدد) اتدهن (خاصية) بالأخضر (قيمة)»**.

> [!warn] أكتر غلطة للمبتدئين: نسيان `;` بين الإعلانات. اللي بعدها بيتبلع والتنسيق بيبوظ.

## try

```html
<style>
  /* ده تعليق: المتصفح يتجاهله */
  p {
    color: #3d2c18;           /* خاصية: قيمة */
    background: #efe0bd;
    padding: 12px;
  }
</style>
<p>اقرا القاعدة جوه style وجرّب تغيّر القيم.</p>
```

## syntax

```css nolive
selector {
  property: value;
  property: value;
}

/* تعليق */
h1, h2 { color: #7a4a1d; }   /* قائمة محددات */
```

- `selector` — بيختار العناصر (`p`, `.card`, `#top`…).
- `{ }` — كتلة الإعلانات.
- `property: value;` — إعلان واحد.
- `/* */` — تعليق (بيشتغل على أكتر من سطر).
- المسافات والأسطر مش مهمة، لكن التنسيق الجيد بيريّح.

## examples

### 1) قاعدة بإعلانين
القاعدة بتختار كل `<h2>` وبتلوّنه وتعمله خط سفلي.

```html
<style>
  h2 { color: #b5551f; border-bottom: 3px solid #c9772f; }
</style>
<h2>عنوان</h2>
```

- المحدد: `h2`.
- إعلانين، كل واحد بينتهي بـ `;`.

### 2) قائمة محددات بفاصلة
لو عايز نفس التنسيق لأكتر من محدد، افصلهم بفاصلة وتكتب القاعدة مرة.

```html
<style>
  h1, h2, h3 { color: #3d7a5a; }
</style>
<h1>H1</h1><h2>H2</h2><h3>H3</h3>
```

- الفاصلة معناها «أو».
- ده بيقلل التكرار.

### 3) الاختصارات (Shorthand)
`padding` ممكن تتكتب بقيمة واحدة أو أربعة، والمتصفح بيوزّعها.

```html
<style>
  .a { padding: 20px; background:#d8b878; }
  .b { padding: 6px 30px; background:#bcd4a8; }
</style>
<div class="a">20px حوالين</div><br><div class="b">فوق/تحت 6 ، يمين/شمال 30</div>
```

- الاختصار بيكتب كذا خاصية في سطر.
- التفاصيل في [[padding]].

### 4) التعليقات والخطأ المتجاهَل
المتصفح تجاهل `colour` (غلط إملائي) وطبّق `background`. الغلط متبلّعش الباقي.

```html
<style>
  p {
    colour: red;          /* غلط: مفيش خاصية بالاسم ده */
    background: #efe0bd;  /* اشتغلت */
    padding: 10px;
  }
</style>
<p>الخلفية اتطبّقت، واللون لأ</p>
```

- الإعلان الغلط بيتتجاهل.
- استخدم DevTools عشان تشوفه مشطوب.

## mistakes

### نسيان الفاصلة المنقوطة

```css bad
p {
  color: #3d2c18
  padding: 10px;
}
```

```css good
p {
  color: #3d2c18;
  padding: 10px;
}
```

من غير `;` بعد `color` المتصفح بيعتبر السطرين إعلان واحد غلط، فبيتجاهلهم الاتنين.
